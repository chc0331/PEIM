# 구축 검증 기록 — 2026-09-06

## 확인한 결과

- 격리된 Python 3.11 환경에 Graphify 0.9.55와 PyYAML 6.0.3 설치. 정확한 의존성은 requirements.lock에 기록.
- Codex용 공식 스킬 프로젝트 등록. 전역 Codex 설정, 별도 API, Git 훅, 클라우드 배포 사용 안 함.
- 출처 문서 7개, 준비 방법 2개, 학습 전략 1개: 총 10개 문서 구조·출처·링크 검사 통과.
- 추출용 에이전트가 허용된 위키 10개만 읽고 의미 추출. 실제 Graphify 처리 후 27개 노드·43개 유향 관계 생성.
- Graphify가 동일 문서·개념을 합치면서 만든 자기참조 관계는 제거. 클러스터 결속도는 무향 투영으로 계산하여 유향 간선 중복 계산 방지.
- Graphify query, path, explain 확인. 회상 연습 → 시간제한 답안 훈련 경로 확인.
- 한글명·영문명·별칭 검색 결과가 같은 위키 문서를 가리킴.
- 실제 브라우저에서 HTML 그래프, 한글 검색, 노드 선택, 위키 원문 링크 표시 확인.
- 재실행 시 변경 문서·재추출 대상 0개. 학습 상태는 미학습 유지.

## 자동 검증

`tests/test_wiki.py`의 11개 테스트 통과:

1. 반복 정리의 중복 방지와 개인 기록 제외
2. 한영 별칭의 동일 페이지 검색
3. 중복 별칭·끊어진 링크 거절
4. 원자료 변경·삭제 감지
5. 근거 없는 출처 확인 상태 거절
6. 상충 상태 보존
7. 추출 도중 변경된 원문·누락 추출 거절
8. 개인 기록의 그래프 입력 거절
9. 문서 수정·삭제 반영과 관계 방향 보존
10. 렌더링 실패 시 이전 그래프 보존·갱신 필요 표시·복구
11. 변경 없는 재생성에서 노드·관계 증가 없음 및 미측정 사용량 표시

테스트는 임시 폴더의 합성 자료로 실행했으며 실제 학습 기록에 점수나 테스트 개념을 추가하지 않았다.

## 아직 확인하지 않은 사항

- 사용자의 첫 진단, 실제 답안 수준, 주력 경력 분야, 응시자격 및 목표 회차.
- Q-Net 2027~2030 출제기준 첨부 원문 전체와 향후 회차 일정.
- 실제 장기간 수업에서의 학습 효과·합격 가능성·토큰 절감률. 생성 문서 수나 그래프 중심성으로 추정하지 않는다.
- 대규모 코퍼스·새로운 문서 형식·패키지 업그레이드 호환성은 해당 시점에 검증한다.

문서 의미의 정확성·출처 충돌 판단은 강사가 수행한다. 구조 검증 통과는 사실 검증 완료를 의미하지 않는다. 시각화는 Graphify 기본 CDN 라이브러리에 의존한다.
