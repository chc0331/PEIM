# ISO/IEC42001과 CAT의 보증 범위

## 서브노트

### 한눈에 이해

하나의 모델 점수와 조직이 AI를 책임 있게 운영하는 체계는 다른 평가 대상입니다.

### 정의와 핵심 원리

ISO/IEC42001:2023은 조직의 AI경영시스템을 수립·구현·유지·지속개선하기위한요구와 지침을 제공하는 표준입니다. CAT는 TTA의인공지능 신뢰성검·인증체계로평가 대상·범위를 정해심사와 시험을 수행합니다.

- ISO공식 개요는 AI관련정책·목표·프로세스를 조직의 맥락안에두고PDCA로관리한다고설명합니다. AI개발·제공·사용조직에 적용할 수 있고위험과 기회·책임·투명성·추적성을관리합니다. 일반 보안관리와 AI의데이터·편향·설명·생애주기 위험을 연결합니다.
- 이번에읽은CAT 현행가 이드는제품·서비스의 AI위험 관리(ISO23894), 신뢰성확보조치(TR24028참고), 조직의 AI경영시스템(42001), AI사용거버넌스(38507)의서로 다른 범위를 제시합니다. 문서·절차 심사와 측정·기능 시험을 구분하며 인증이 특정 위험0의증명이아님을명시합니다.
- 실무준비는대상·적용 범위·AI목록·이해관계자·역할·정책·위험 평가·처리·운영 통제·감시·감사·개선의증거를 연결하는방향으로설명할 수 있습니다. 이것을42001조항 전문이나 필수서류목록으로 사칭하지 않습니다. 다른 인증을 받아도국내 법 의무는 별도 확인합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| AI RMF | 자발적위험 관리 프레임워크 | 인증 규격아님 |
| ISO42001 | 조직AI경영시스템 표준 | 원문 조항·범위 확인 |
| CAT | 정해진 대상·범위의 검인증 | 판본·심사·시험구분 |

### 적용 예제

**조직 인증과 챗봇 성능**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 업체가AI경영시스템 보증을 설명하는 가정

1. 인증서의 조직·제품·서비스 대상과 범위를 확인합니다.
2. 정책·위험·책임·운영 증거를 검토합니다.
3. 특정 챗봇의환각률·편향·보안시험 결과는 별도 검증합니다.
4. 2025기출 당시제도와 현행가 이드의용어·범위차이를기록합니다.

**결과·해석:** 관리체계의보증과 개별모델의 실제 품질을 구분합니다.

**전제·주의:** ISO42001유료전문·부속통제·인증 심사 세부항목은 미열람입니다.현행 CAT소개가2025당시요건전부를확인해주지는않습니다.

### 답안 골격과 혼동 방지

정의·대상 → PDCA운영 → RMF/ISO/CAT비교 → 심사·시험 증거 → 미열람경계

- ISO42001인증이면 모든 모델이 정확·안전하다고하지 않습니다.
- ISO소개만으로조항별적합판정을하지 않습니다.

### 내용을 가리고 회상

1. AI경영시스템과 모델 시험의 대상은 어떻게다릅니까?
2. CAT 범위를 먼저 확인해야 하는이유는무엇입니까?
3. PDCA에서개선의증거는 무엇입니까?

### 적용 기준과 근거

ISO42001판1(2023-12)공식소개와열람시현행 CAT가 이드만확인.표준 전문·2025CAT전판미열람.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [ISO/IEC42001:2023 AI Management System](https://www.iso.org/standard/42001) — ISO/IEC; 2023-12 판1; 확인 2026-11-05. 확인 범위: 공식 소개·공개 개요만 열람. 유료 표준 전문 및 인증 심사 조항 전체 미열람. 상세 준수 판정 금지.
- [인공지능 신뢰성 인증 CAT 가이드 일러두기](https://tta-trustworthy-ai.gitbook.io/cat) — TTA AI신뢰성센터; 열람시현행가이드; 확인 2026-11-05. 확인 범위: 공식가 이드직접 열람.제품·서비스/조직의 4범위와 심사·시험차이.표준 전문과 2025기출 당시모든 판본은 미열람.
- [NIST AI100-1: AI RMF1.0](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf) — NIST; 2023-01; 확인 2026-11-05. 확인 범위: 원문 PDF 열람. 신뢰성 7특성, GOVERN/MAP/MEASURE/MANAGE 및 Profiles. 자발적 프레임워크이며 인증 규격 아님.
