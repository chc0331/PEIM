# SOM의 경쟁·이웃 학습

## 서브노트

### 한눈에 이해

많은 특징을 가진 고객을 평면 지도에 놓고 비슷한 고객이 이웃에 오도록 정리하는 방법입니다. 지도의 가까움은 고객 특징의 유사성을 표현하려는 것이며 실제 지리 위치를 뜻하지 않습니다.

### 정의와 핵심 원리

고차원 입력을 보통 저차원 격자에 대응시키면서 입력의 이웃 구조를 보존하도록 학습하는 경쟁 기반 비지도 신경망입니다.

- 입력 벡터 x와 각 격자 노드의 가중치 벡터 w_j를 비교해 가장 가까운 노드(best matching unit, BMU)를 찾습니다. BMU와 격자상 이웃의 가중치 벡터를 입력 쪽으로 옮겨, 비슷한 입력이 가까운 노드에 대응하도록 학습합니다.
- 대표 갱신식은 w_j←w_j+α(t)h_cj(t)(x−w_j)입니다. α는 학습률, h는 BMU와 노드의 격자 거리로 정하는 이웃 함수이며 학습이 진행되면 이웃 폭과 학습률을 줄여 전역 정리에서 국소 미세조정으로 갑니다. 입력 scale과 지도 크기·초기화가 결과에 영향을 줍니다.
- 지도는 입력층·격자 출력 노드·노드별 prototype 가중치·이웃 관계·거리 척도로 구성됩니다. 지도 학습 ANN은 정답/손실 gradient를 중심으로 최적화하지만 SOM은 정답 라벨 없이 경쟁·이웃 학습을 합니다. 같은 신경망 계열이므로 SOM과 신경망 전체를 상호 배타적으로 비교하지 않습니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| SOM | BMU와 격자 이웃 갱신 | 군집·시각화·위상 보존 목표 |
| K-means | 가까운 중심만 갱신 | 격자 이웃 관계 없음 |
| 지도 ANN | 정답 손실·역전파 | 과업별 예측 성능 중심 |

### 적용 예제

**두 이웃 노드의 갱신**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** x=(1,1), w_c=(0,0), w_j=(2,0)이며 거리 동률 시 c를 BMU로 선택합니다. α=0.5, h_cc=1,h_cj=0.5입니다.

1. BMU는 (0,0)+0.5×1×(1,1)=(0.5,0.5)가 됩니다.
2. 이웃은 (2,0)+0.5×0.5×(−1,1)=(1.75,0.25)가 됩니다.
3. 이웃도 입력 방향으로 일부 이동하지만 BMU보다 작게 이동하여 지도의 연속성을 유도합니다.

**결과·해석:** 입력과 가장 가까운 노드를 고르는 단계가 경쟁입니다. 선택한 노드와 그 이웃을 함께 움직이는 단계가 협력입니다.

**전제·주의:** 위상 보존은 목표이지 모든 자료에서 거리와 이웃이 완벽히 보존된다는 보장은 아닙니다.

### 답안 골격과 혼동 방지

정의·입력/격자 구조 → BMU 경쟁 → 이웃 가중 갱신·감쇠 → 숫자 예제 → 지도 ANN·K-means 비교

- SOM을 지도 학습 분류기로만 설명하지 않습니다.
- MATLAB 함수 지원 종료와 알고리즘의 타당성을 혼동하지 않습니다.
