# 인터미턴트 컴퓨팅

## 서브노트

### 한눈에 이해

전원이 자주 끊기는 초저전력 장치가 다음에 켜질 때 이전 일을 안전하게 이어 가도록 설계합니다.

### 정의와 핵심 원리

인터미턴트 컴퓨팅은 에너지 하베스팅 등으로 전원이 불안정한 장치에 서 실행 상태를 비휘발성 저장소에 보존하거나 작업을 재구성하여 반복 정전에도 계산 진척과 데이터 일관성을 확보하는 기법입니다.

- 전압이임계값으로 내리면레지스터·스택등상태를 체크포인트로보존하고 재기동후복구하는방식과, 작업을 원자적인작은 태스크로 나누어완료된진척만커밋하는방식이 있습니다.저장 시점·에너지여유·복구 비용이 설계 핵심입니다.
- 전원이 쓰기중끊기면체크포인트자체가불완전할 수 있어이중버퍼·버전 번호·커밋마커등의 일관된기록 절차가 필요합니다.재실행되는코드는 멱등성을 검토하며 센서 읽기·패킷송신같은 외부 효과는 메모리롤백만으로취소되지않습니다.
- 기존 배터리장치와 달리정전을예외가 아닌정상 조건으로 다룹니다.작업크기가한번에확보할 수 있는 에너지보다크면영구재시작에 빠질수 있습니다.비휘발성메모리의 쓰기내구성·원자성·지연·보안상태 보호를 함께 고려합니다.
- 체크포인트 저장에 쓰는 에너지 자체가 남은 에너지보다 작아야 하므로 임계전압에는 저장 비용과 최소 동작전압의 여유를 반영합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 체크포인트 | 실행 상태 저장·복원 | 저장 비용과 일관성 |
| 태스크 기반 | 완료단위만 커밋 | 태스크분해와외부 효과 |
| 상시전원 | 연속실행 가정 | 정전복구의 전제가 다름 |

### 적용 예제

**중복 송신을 피하는 센서**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 태양광센서가 측정후서버에 값 전송;응답전정전

1. 측정 값과 고유번호를 안전하게기록합니다.
2. 서버는 번호로 중복 요청을 식별하여 같은 측정의 중복 반영을 막습니다.
3. 장치는 응답 확인후전송완료상태를 커밋합니다.
4. 정전위치별재시작을 가정해미송신·재송신·부분기록을 점검합니다.

**결과·해석:** 단순 PC복원에 더해외부세계와의진척일관성을다룹니다.

**전제·주의:** 원학회의 색인 본문으로 에너지 인지 체크포인트 원리를 확인했습니다. 태스크 방식·외부 효과의 정합성은 별도 원논문 추가 확인이 필요합니다.

### 답안 골격과 혼동 방지

전원 모델 → 체크포인트·태스크 원리 → 일관성문제 → 센서예 → 전력·내구성한계

- 정전때마다모든 상태를 저장할에너지가있다고가정하지 않습니다.
- 재실행을 무조건 안전하다고보지않습니다.

### 적용 기준과 근거

USENIX HotPower2008 원논문의 공식 색인 본문에서 에너지 인지 체크포인트를 확인했으나 원문 전체 직접 열람은 접근 실패했습니다. 일반 메모리 문서를 해당 주제의 근거로 대체하지 않았습니다.
