# 인터미턴트 컴퓨팅

## 서브노트

### 한눈에 이해

전원이 자주 끊기는 초저전력 장치가 다음에 켜질 때 이전 일을 안전하게 이어 가도록 설계합니다.

### 정의와 핵심 원리

인터미턴트 컴퓨팅은 에너지 하베스팅 등으로 전원이 불안정한 장치에서 쓰는 방식입니다. 비휘발성 저장소에 실행 상태를 저장하거나 작업을 작은 단위로 나눠, 전원이 여러 번 끊겨도 계산을 이어 가고 데이터를 일관되게 유지합니다.

- 전압이 임계값까지 떨어지면 레지스터와 스택 등을 체크포인트에 저장하고, 다시 켜졌을 때 복구할 수 있습니다. 작업을 작은 단위로 나눠 끝난 단위만 확정하는 방법도 있습니다. 저장 시점, 남은 에너지와 복구 비용을 함께 계산합니다.
- 저장 중 전원이 끊기면 체크포인트가 일부만 남을 수 있습니다. 이중 버퍼, 버전 번호, 기록 완료 표지로 완전한 기록을 구분합니다. 재실행해도 결과가 중복으로 반영되지 않는지 검토합니다. 센서 읽기나 패킷 송신처럼 장치 밖에 미친 영향은 메모리 상태를 되돌려도 사라지지 않습니다.
- 정전이 자주 발생한다는 전제로 설계합니다. 한 작업을 끝낼 에너지를 확보하지 못하면 켜질 때마다 처음부터 같은 작업을 반복할 수 있습니다. 비휘발성 메모리의 쓰기 내구성과 시간, 기록의 원자성과 보안도 확인합니다.
- 체크포인트 저장에 쓰는 에너지 자체가 남은 에너지보다 작아야 하므로 임계전압에는 저장 비용과 최소 동작전압의 여유를 반영합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 체크포인트 | 실행 상태 저장·복원 | 저장 비용과 일관성 |
| 태스크 기반 | 완료 단위만 커밋 | 태스크 분해와 외부 효과 |
| 상시 전원 | 연속 실행 가정 | 정전 복구의 전제가 다름 |

### 적용 예제

**중복 송신을 피하는 센서**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 태양광으로 동작하는 센서가 측정값을 서버에 보냅니다. 장치가 응답을 받기 전에 전원이 끊깁니다.

1. 측정값과 고유 번호를 함께 기록합니다.
2. 서버는 번호로 중복 요청을 식별하여 같은 측정의 중복 반영을 막습니다.
3. 장치는 응답을 확인한 뒤 전송 완료 상태를 저장합니다.
4. 정전 위치별 재시작을 가정해 미송신·재송신·부분 기록을 점검합니다.

**결과·해석:** 단순 PC 복원에 더해 외부 세계와의 진척 일관성을 다룹니다.

**전제·주의:** 원 학회의 색인 본문으로 에너지 인지 체크포인트 원리를 확인했습니다. 태스크 방식·외부 효과의 정합성은 별도 원 논문 추가 확인이 필요합니다.

### 답안 골격과 혼동 방지

전원 모델 → 체크포인트·태스크 원리 → 일관성 문제 → 센서 예 → 전력·내구성 한계

- 정전 때마다 모든 상태를 저장할 에너지가 있다고 가정하지 않습니다.
- 재실행을 무조건 안전하다고 보지 않습니다.

### 내용을 가리고 회상

1. 전원이 다시 켜져 같은 작업을 실행할 때 멱등성이 필요한 이유는 무엇입니까?
2. 체크포인트 저장에도 원자성이 필요한 이유는 무엇입니까?
3. 한 작업의 크기는 한 번에 확보할 수 있는 에너지와 어떤 관련이 있습니까?

### 적용 기준과 근거

USENIX HotPower2008 원논문의 공식 색인 본문에서 에너지 인지 체크포인트를 확인했으나 원문 전체 직접 열람은 접근 실패했습니다. 일반 메모리 문서를 해당 주제의 근거로 대체하지 않았습니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [Getting Things Done on Computational RFIDs with Energy-Aware Checkpointing](https://static.usenix.org/events/hotpower08/tech/full_papers/ransford/ransford_html/) — Benjamin Ransford et al. / USENIX; 2008; 확인 2026-11-05. 확인 범위: 원학회 검색 노출 본문의 체크포인트·전압 측정 설명 확인. 직접 open은 접근실패로 전문 열람 아님.
