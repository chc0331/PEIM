# 디지털 포렌식·아티팩트·슬랙·카빙·안티포렌식

## 서브노트

### 한눈에 이해

흔적을 많이 모으는 것보다 원본을 훼손하지 않고, 어떤 과정으로 해석했는지 재현 가능하게 남기는 일이 핵심입니다.

### 정의와 핵심 원리

디지털포렌식은디지털자료를 식별·수집·보존·검사·분석·보고하여 사건사실을규명하는활동입니다. 아티팩트는OS·응용·통신사용등이 남긴흔적이며 존재만으로행위자·고의·정확시각을단정하지 않습니다.

- 계획과 권한 확인 → 휘발성우선순위를고려한수집 → 원본 보존·이미징·해시·인계기록 → 검사와 복원 → 상관분석 → 보고로 설명합니다. NIST800-86의수집·검사·분석·보고 구조와 법집행절차는 분리하며 해시일치가수집의 적법성까지자동보장하지는않습니다.
- 파일슬랙은할당단위안의논리적파일끝이 후 남는공간입니다. 비할당영역과 다르며과거잔존데이터가 능성은파일시스템·초기화·SSDTRIM에좌우됩니다. 카빙은정상메타데이터없이내용특징으로파일을복원하는기법으로 조각화·압축·암호화·오탐에취약합니다.
- 교육상카빙을헤더/푸터서명, 고정 크기·최대 크기, 파일내부 구조 검증, 내용·조각분류의 네접근으로 비교할 수 있으나기출이지정한 원분류는 확인하지못했습니다. 안티포렌식은삭제·암호화·타임스탬프조작·로그훼손등이며 독립로그·시각동기·중앙보존·교차증거로 대응합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 메타데이터 복원 | 파일시스템 기록이 용 | 기록손상시한계 |
| 카빙 | 본문서명·구조·내용 | 조각화·오탐검증 |
| 아티팩트분석 | OS·앱·네트워크흔적 | 시각·버전·대안설명 |

### 적용 예제

**삭제 파일과 접속 시각 조사**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 디스크이 미지·중앙프록시로그·브라우저DB 가정

1. 수집 권한·대상·시간대·도구 버전·해시를기록합니다.
2. 사본에서 파일구조와 카빙후보를검사합니다.
3. 브라우저·로그·파일 시각을교차비교하고 불일치를기록합니다.
4. 사용자직접 행위·백그라운드 동기화등대안설명을 평가합니다.

**결과·해석:** 복원파일과행위주장을분리하고 근거·제약이있는 보고서를 만듭니다.

**전제·주의:** 카빙4분류와 국내 증거능력·컴플라이언스요건의 원문은 미확인입니다.

### 답안 골격과 혼동 방지

정의·유형 → 원본 보존·증거연속성 → 4단계 → 카빙·슬랙 → 안티포렌식대응

- 포렌식도구 출력을 무오류로 보지않습니다.
- 타임스탬프하나로범인을확정하지 않습니다.

### 내용을 가리고 회상

1. 해시가보장하는것과보장하지 않는것은무엇입니까?
2. 슬랙과비할당영역은 어떻게다릅니까?
3. 카빙오탐은무엇으로검증합니까?

### 적용 기준과 근거

명시한 출처 판본의 원리를 설명하며 제품별 구현 차이는 별도 확인합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [NIST SP800-86 Integrating Forensics into Incident Response](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-86.pdf) — Karen Kent et al. / NIST; 2006-08; 확인 2026-11-05. 확인 범위: 수집·검사·분석·보고, 파일·OS·네트워크·응용 데이터 설명 열람. 법적 증거능력 보장 문서 아님.
