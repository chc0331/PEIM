# 차등 맨체스터 부호화

## 서브노트

### 한눈에 이해

비트 중간에는 항상 신호를 뒤집어 클록을 맞춥니다. 비트 시작에서도 신호가 바뀌는지에 따라 0과 1을 구분합니다.

### 정의와 핵심 원리

차등 맨체스터는 비트 중앙의 전이로 동기를 맞추고, 비트 시작의 전이 유무로 데이터를 나타내는 선로 부호입니다. 신호의 절대 높이보다 직전 신호에서 바뀌었는지가 중요합니다.

- 반드시 사용 규약을 먼저 선언합니다. 본 예는 0 = 비트 시작 전이, 1 = 시작 전이 없음으로 두고 중간 전이는 모든 비트에 둡니다. 다른 규약·초기 레벨을 쓰는 문제는 그 조건에 맞춰 다시 그립니다.
- 중간 전이는 수신기의 클록 복구를 돕고 긴 0·1 연속에서도 전이가 사라지지 않습니다. 전체 파형의 극성이 반전되어도 전이 유무는 유지되어 데이터 판단에 유리합니다. 이는 잡음·지터·전이 누락까지 모두 복구한다는 뜻은 아닙니다.
- NRZ와 비교하면 더 잦은 신호 변화와 필요한 대역폭의 부담이 있습니다. 일반 맨체스터는 중앙 전이의 방향으로 데이터를 구분하는 반면 차등 방식은 시작 전이 유무를 사용하므로 두 부호의 판독 기준을 섞으면 안 됩니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| NRZ | 레벨 또는 이전 레벨과의 차이 | 같은 값이 길게 이어지면 동기 문제 발생 가능 |
| Manchester | 중앙 전이 방향 | 자체 동기화, 극성 규약 필요 |
| Differential Manchester | 시작 전이 유무와 항상 발생하는 중앙 전이 | 극성이 반전돼도 판독 가능, 대역폭 부담 |

### 적용 예제

**1010 직접 부호화**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 첫 비트 직전의 레벨은 L입니다. 1이면 시작 레벨을 유지하고, 0이면 시작 레벨을 뒤집습니다.

1. 첫 번째 비트 1은 시작 레벨 L을 유지하고 중앙에서 H로 바뀝니다. 반비트열은 LH입니다.
2. 두 번째 비트 0은 직전 H에서 시작 레벨 L로 바뀌고 중앙에서 다시 H로 바뀝니다. 반비트열은 LH입니다.
3. 세 번째 비트 1은 시작 레벨 H를 유지하고 중앙에서 L로 바뀝니다. 반비트열은 HL입니다.
4. 마지막 비트 0은 직전 L에서 시작 레벨 H로 바뀌고 중앙에서 다시 L로 바뀝니다. 반비트열은 HL입니다.
5. 반비트열 LH LH HL HL의 시작 부분을 각 직전 레벨과 비교하면 1010을 복원할 수 있습니다.

**결과·해석:** 파형은 초기 레벨과 규약을 함께 적어야 유일하게 재현됩니다.

**전제·주의:** 규약과 초기 레벨에 따른 교육용 예시입니다. 수신기 제품별 idle 레벨·프리앰블·오류 처리는 해당 문서를 확인합니다.

### 답안 골격과 혼동 방지

규약과 초기 레벨 → 비트별 두 반비트 → 중앙 전이와 시작 전이 → 일반 맨체스터와 비교 → 대역폭과 잡음

- H나 L의 높이만으로 1과 0을 판정하지 않습니다.
- 데이터 값은 비트 시작의 전이 유무로 읽고, 중앙 전이는 클록을 맞추는 데 사용합니다.

### 내용을 가리고 회상

1. 신호의 초기 레벨을 반대로 잡아도 복호한 값이 같을 수 있는 이유는 무엇입니까?
2. 0과 1을 구분하는 규약을 먼저 밝혀야 하는 이유는 무엇입니까?
3. 반비트열 LH LH HL HL에서 1010을 어떻게 확인합니까?
