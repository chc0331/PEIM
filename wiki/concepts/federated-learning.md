# 연합학습의 FedAvg와 분산 최적화

## 서브노트

### 한눈에 이해

여러 기관이 원자료를 한곳에 모으기 어려워도 각자 자료에서 모델을 학습하고 업데이트를 합칠 수 있습니다. 다만 원본을 안 보냈다는 사실만으로 업데이트에서 정보가 새지 않는다는 보장은 없습니다.

### 정의와 핵심 원리

여러 참여자가 로컬 자료를 유지한 채 모델 업데이트를 교환하여 공동 모델을 학습하는 분산 학습 방법입니다.

- 서버가 초기 모델을 정해 참여자에게 보냅니다. 각 참여자는 자기 데이터로 모델을 학습해 갱신값을 보냅니다. FedAvg는 그 라운드에 참여한 n_k개 표본의 모델 w_k를 w=Σ(n_k/Σn_j)w_k로 가중 평균합니다. 모델 구조와 파라미터의 위치가 같아야 합니다.
- FedSGD는 참여자가 계산한 기울기를 모읍니다. FedAvg는 각 참여자가 여러 번 갱신한 뒤 모델을 합쳐 통신 라운드를 줄일 수 있습니다. 기관마다 데이터 분포와 표본 수가 다르고 이탈이나 응답 지연이 생기면 수렴과 기관별 성능에 차이가 날 수 있습니다. 참여 방식, 서버 최적화, 정규화와 개인화를 검토합니다.
- 집계 업데이트도 정보 유출·오염 가능성이 있어 secure aggregation·차분 프라이버시·암호 기술·검증을 별도로 검토합니다. secure aggregation은 개별 업데이트를 숨기는 역할이고 DP는 출력/학습 과정의 기여 정보 제한을 목표로 하며 정확도·통신·위협 모델의 절충이 있습니다. 보안 세부는 별도 원문 확인 범위입니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 중앙 학습 | 원자료를 모아 최적화 | 자료 이동·보호 부담 |
| FedSGD | 로컬 gradient 집계 | 통신 빈도 큼 |
| FedAvg | 여러 지역 학습 뒤 가중 평균 | 통신 감소·client drift |

### 적용 예제

**FedAvg 표본 가중 평균**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** A기관은 100명, B기관은 300명의 자료로 같은 파라미터를 학습했습니다. 학습 결과는 각각 2와 4입니다.

1. 전체 표본 수는 400이고 가중치는 A 1/4, B 3/4입니다.
2. 서버의 가중 평균은 (100×2+300×4)/400=3.5입니다. 두 기관에 같은 가중치를 주면 평균은 3입니다.
3. 새 모델을 배포하고 기관별 holdout 성능을 봅니다. 큰 기관의 평균 개선이 작은 기관의 악화를 숨길 수 있습니다.

**결과·해석:** 집계의 분모·표본 가중치와 참여자별 성능 관리가 중요합니다.

**전제·주의:** 서로 다른 파라미터 구조를 단순 평균하거나 표본 수 공개가 언제나 허용된다고 가정하지 않습니다.

### 답안 골격과 혼동 방지

정의·중앙 대비 → 배포→지역학습→집계 → FedSGD/FedAvg → 가중 평균 계산 → non-IID·통신·보호 한계

- 원자료 비이동을 완전한 프라이버시 보장으로 쓰지 않습니다.
- 각 기관에 동일 가중치와 표본수 가중치를 섞지 않습니다.

### 적용 기준과 근거

FedAvg 원 논문 초록과 집계 원리를 확인했습니다. FedProx/secure aggregation/DP 등 개별 알고리즘의 보장·공격 모델은 별도 1차 원문 미확인으로 부분 처리합니다.
