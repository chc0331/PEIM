# 트랜잭션과 병행제어

## 서브노트

### 한눈에 이해

두 직원이 같은 재고를 동시에 읽고 각각 판매하면 재고가 한 번만 줄 수 있습니다. 트랜잭션은 한 업무의 경계이고 병행제어는 여러 업무가 겹쳐도 허용된 결과를 만드는 장치입니다.

### 정의와 핵심 원리

트랜잭션은 원자성·일관성·격리성·지속성(ACID)을 갖는 논리적 작업 단위이며 병행제어는 동시 실행의 충돌을 조정합니다.

- 원자성은 전부 반영 또는 취소, 지속성은 커밋한 변경의 복구 가능성입니다. 일관성은 정의한 제약을 지키는 상태 간 전이이고 격리성은 다른 트랜잭션의 중간 상태를 보지 않도록 정한 보장입니다. ACID의 C와 CAP의 C는 의미가 다릅니다.
- 2단계 잠금은 잠금 획득 단계 후 해제 단계로 가며 충돌 직렬가능성을 확보하지만 대기와 교착이 생길 수 있습니다. 타임스탬프 순서는 충돌 작업의 시간 순서를 강제하고, 낙관적 제어는 읽기·계산 후 커밋 전 충돌을 검증하여 실패 시 재시도합니다.
- MVCC는 행의 여러 버전과 snapshot으로 읽기/쓰기 간 대기를 줄입니다. 버전이 있다고 lost update나 write skew가 모든 격리 수준에서 자동 제거되지는 않습니다. 짧은 트랜잭션·일관된 잠금 순서·교착 감지/재시도·오래된 버전 정리가 운영의 핵심입니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 잠금 기반 | 충돌 전에 자원 접근 조정 | 대기·교착 |
| 낙관 검증 | 충돌을 나중에 검출 | 충돌이 많으면 재시도 증가 |
| MVCC | 버전별 snapshot 읽기 | 저장량·정리·격리 설정 |

### 적용 예제

**재고 lost update**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 재고 10을 A와 B가 읽고 각각 1개 판매합니다.

1. A가 9를 쓰고 B도 9를 쓰면 두 판매 뒤 재고가 9가 되는 lost update입니다.
2. UPDATE 재고 SET 수량=수량-1 WHERE 상품=1 AND 수량>0처럼 DB 내 원자 갱신과 제약을 사용합니다.
3. 업무가 여러 행에 걸치면 동일 트랜잭션으로 묶고 적절한 격리·잠금 또는 충돌 재시도를 설계합니다.

**결과·해석:** 두 판매가 정상 커밋하면 재고 8이 되어야 합니다.

**전제·주의:** 원자 증가/감소 하나의 해결책을 임의의 복잡한 업무 불변식에 그대로 일반화하지 않습니다.

### 답안 골격과 혼동 방지

ACID와 병행제어 필요성 → 대표 이상 현상 → 잠금/시간순서/검증/MVCC → 재고 사례 → 교착·기아·재시도 대책

- 격리성이 무조건 모든 실행을 실제 한 줄로 세운다는 뜻은 아닙니다.
- 낮은 격리와 업무 코드의 읽기-쓰기 조합을 함께 봅니다.

### 적용 기준과 근거

ACID·MVCC·격리 구현은 공식 문서를 확인했습니다. 일반 2PL/타임스탬프/낙관 검증의 상세 알고리즘 전체는 추가 교재 확인 범위입니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [PostgreSQL 18: Concurrency Control](https://www.postgresql.org/docs/18/mvcc.html) — PostgreSQL Global Development Group; PostgreSQL 18; 확인 2026-11-05. 확인 범위: 실제 열람: 동시 접근 목적, MVCC·격리·명시적 잠금·교착·직렬화 실패 처리 구성. 잠금/타임스탬프/낙관 검증 일반 분류 중 제품 구현 범위를 넘는 부분은 교재와 구분합니다.
- [PostgreSQL 16: Transaction Isolation](https://www.postgresql.org/docs/16/transaction-iso.html) — PostgreSQL Global Development Group; PostgreSQL 16; 확인 2026-11-05. 확인 범위: 실제 열람: SQL 네 단계와 이상현상 표, PostgreSQL RU=RC, RR에서 팬텀 방지·직렬화 이상 가능, SSI 재시도. 표준 최소 보장과 구현 차이를 명시합니다.
