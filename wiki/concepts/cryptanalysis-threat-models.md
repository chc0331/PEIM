# 암호 공격 모델과 암호문 공격

## 서브노트

### 한눈에 이해

공격자가 암호문만 갖는지, 원문을 알거나 암·복호 장치에 질의할 수 있는 지에 따라 요구되는 안전성을 다르게 평가합니다.

### 정의와 핵심 원리

암호 분석 공격 모델은 공격자가획득하는정보와 질의능력을정의한조건입니다. 암호문 단독공격은 암호문만 으로평문또는키에 관한정보를 얻으려는모델이고 알려진 평문·선택 평문·선택 암호문은 추가 정보·오라클능력이있습니다.

- ciphertext-only는 암호문 통계·구조를 이용하고 known-plaintext는 원문/암호문쌍을가집니다. chosen-plaintext는 선택한 원문의 암호화 결과를 받고chosen-ciphertext는 제한조건하에서선택 암호문의 복호 결과·반응을얻습니다. 오라클은실제 서버의 에러·시간·API일수 있습니다.
- 단순한키 길이보다안전한 스킴과무결성·오류 처리가 중요합니다. 패딩오류를 구별해주는응답은 평문 복원에 정보를 제공할 수 있어인증 암호·균일한오류·상수시간·질의통제등검증된방식을 사용합니다. 암호문을 바꿔도검출못하는모드는 공격 표면을 넓힙니다.
- Kerckhoffs원칙관점에서알고리즘을 숨기는것만안전성의 근거로 두지않고키를 보호합니다. 부채널·키 탈취·약한난수는수학적분석과 다른 경로이며 프로토콜·구현·운영을 함께 검토합니다. 모델의 가정밖위협까지 안전하다고확장하지 않습니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 암호문 단독 | C만관측 | 분포·패턴노출 |
| 알려진/선택 평문 | P, C쌍/암호화질의 | 구별·구조 분석 |
| 선택 암호문 | 복호반응질의 | 인증·패딩·오류 통제 |

### 적용 예제

**오류 메시지의 정보 노출**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 변조암호문에 패딩오류와 인증 오류를 다르게응답하는가정

1. 공격자가무엇을반복질의하고 관측하는지정의합니다.
2. 오류 종류·응답 시간차이가정보를 주는지안전한 환경에 서 평가합니다.
3. 검증된AEAD와 권장복호 절차로 태그검증전평문사용을막습니다.
4. 오류통일만으로충분한지구현·라이브러리 정책을 검토합니다.

**결과·해석:** 공격 모델을 명확히하면 암호 알고리즘과 운용스킴의방어범위를 구분할 수 있습니다.

**전제·주의:** 교육용위협 분석이며 특정 시스템 침입 절차를 제공하지 않습니다.선택 암호문보장의상세증명은원규격을 추가 확인합니다.

### 답안 골격과 혼동 방지

모델정의 → 네조건비교 → 오라클·오류 사례 → AEAD·구현 대응 → 가정 한계

- 암호문 단독공격을 암호문을 변조하는공격하나로한정하지 않습니다.
- 키 길이만으로모든 공격 모델 안전을 선언하지 않습니다.

### 적용 기준과 근거

명시한 출처 판본의 원리를 설명하며 제품별 구현 차이는 별도 확인합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [RFC8017: PKCS#1 v2.2](https://www.rfc-editor.org/rfc/rfc8017.html) — K. Moriarty et al. / IETF; 2016-11; 확인 2026-11-05. 확인 범위: RSA 원시연산·암호화·서명 스킴 구분 열람. 작은 정수 예시는 교육용.
- [RFC8446: TLS1.3](https://www.rfc-editor.org/rfc/rfc8446.html) — Eric Rescorla / IETF; 2018-08; 확인 2026-11-05. 확인 범위: 핸드셰이크·구형 알고리즘 제거·0-RTT 재전송 위험 설명 열람.
- [NIST SP800-38A: Block Cipher Modes](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-38a.pdf) — Morris Dworkin / NIST; 2001-12; 확인 2026-11-05. 확인 범위: ECB/CBC/CFB/OFB/CTR 원문과 식 열람. 기밀성 모드이 므로 단독 무결성 보장 없음.
