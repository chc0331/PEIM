# 암호 공격 모델과 암호문 공격

## 서브노트

### 한눈에 이해

공격자가 암호문만 갖는지, 평문을 알거나 암호화·복호화 장치에 질의할 수 있는지에 따라 요구되는 안전성을 다르게 평가합니다.

### 정의와 핵심 원리

암호 분석 공격 모델은 공격자가 획득하는 정보와 질의 능력을 정의한 조건입니다. 암호문 단독 공격은 암호문만으로 평문 또는 키에 관한 정보를 얻으려는 모델이고 알려진 평문·선택 평문·선택 암호문은 공격자가 아는 평문이나 오라클에 질의할 수 있는 범위에 따라 나뉩니다.

- ciphertext-only는 암호문 통계·구조를 이용하고 known-plaintext는 평문과 그에 대응하는 암호문 쌍을 이용합니다. chosen-plaintext는 공격자가 고른 평문의 암호화 결과를 얻고, chosen-ciphertext는 정해진 조건에서 선택한 암호문의 복호 결과나 반응을 얻습니다. 서버 API의 응답, 오류 종류, 처리 시간이 오라클로 작용할 수 있습니다.
- 단순한 키 길이보다 안전한 스킴과 무결성·오류 처리가 중요합니다. 패딩 오류를 구별해 주는 응답은 평문 복원에 정보를 제공할 수 있어 인증 암호·균일한 오류·상수 시간·질의 통제 등 검증된 방식을 사용합니다. 암호문을 바꿔도 검출 못 하는 모드는 공격 표면을 넓힙니다.
- Kerckhoffs 원칙 관점에서 알고리즘을 숨기는 것만 안전성의 근거로 두지 않고 키를 보호합니다. 부채널·키 탈취·약한 난수는 수학적 분석과 다른 경로이며 프로토콜·구현·운영을 함께 검토합니다. 모델의 가정 밖 위협까지 안전하다고 확장하지 않습니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 암호문 단독 | 암호문(C)만 관측 | 분포·패턴 노출 |
| 알려진/선택 평문 | 평문·암호문 쌍 또는 암호화 질의 | 구별·구조 분석 |
| 선택 암호문 | 복호 질의에 대한 반응 | 인증·패딩·오류 통제 |

### 적용 예제

**오류 메시지의 정보 노출**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 서버가 변조한 암호문을 받으면 패딩 오류와 인증 오류에 서로 다른 응답을 보냅니다.

1. 공격자가 무엇을 반복 질의하고 관측하는지 정의합니다.
2. 오류 종류·응답 시간 차이가 정보를 주는지 안전한 환경에서 평가합니다.
3. 검증된 AEAD와 권장 복호 절차로 인증 태그 검증 전 평문 사용을 막습니다.
4. 오류 통일만으로 충분한지 구현·라이브러리 정책을 검토합니다.

**결과·해석:** 공격 모델을 명확히 하면 암호 알고리즘과 운용 스킴의 방어 범위를 구분할 수 있습니다.

**전제·주의:** 교육용 위협 분석이며 특정 시스템 침입 절차를 제공하지 않습니다. 선택 암호문 보장의 상세 증명은 원 규격을 추가 확인합니다.

### 답안 골격과 혼동 방지

공격 모델 정의 → 네 가지 조건 비교 → 오라클·오류 사례 → AEAD·구현 대응 → 가정 한계

- 암호문 단독 공격을 암호문을 변조하는 공격 하나로 한정하지 않습니다.
- 키 길이만으로 모든 공격 모델 안전을 선언하지 않습니다.

### 내용을 가리고 회상

1. 알려진 평문과 선택 평문의 차이는 무엇입니까?
2. 오류 응답이 어떻게 공격에 쓰이는 정보가 됩니까?
3. 알고리즘 공개와 키 보호를 구분하는 이유는 무엇입니까?

### 적용 기준과 근거

명시한 출처 판본의 원리를 설명하며 제품별 구현 차이는 별도 확인합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [RFC8017: PKCS#1 v2.2](https://www.rfc-editor.org/rfc/rfc8017.html) — K. Moriarty et al. / IETF; 2016-11; 확인 2026-11-05. 확인 범위: RSA 원시연산·암호화·서명 스킴 구분 열람. 작은 정수 예시는 교육용.
- [RFC8446: TLS1.3](https://www.rfc-editor.org/rfc/rfc8446.html) — Eric Rescorla / IETF; 2018-08; 확인 2026-11-05. 확인 범위: 핸드셰이크·구형 알고리즘 제거·0-RTT 재전송 위험 설명 열람.
- [NIST SP800-38A: Block Cipher Modes](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-38a.pdf) — Morris Dworkin / NIST; 2001-12; 확인 2026-11-05. 확인 범위: ECB/CBC/CFB/OFB/CTR 원문과 식 열람. 기밀성 모드이 므로 단독 무결성 보장 없음.
