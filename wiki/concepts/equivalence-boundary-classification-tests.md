# 동등분할·경계값·분류트리 테스트케이스

## 서브노트

### 한눈에 이해

같은 결과가 나와야 하는 입력은 한 집합으로 묶습니다. 결과가 바뀌는 경계에서는 바로 양쪽 값을 시험합니다.

### 정의와 핵심 원리

동등분할은 동일한 처리 결과가 기대되는 입력 집합을 나누어 대표값을 선정하고, 경계값 분석은 순서가 있는 분할의 경계와 인접값을 시험합니다. 분류트리는 입력 특성을 계층적으로 분류하고 유효 조합을 선택하는 기법입니다.

- 139회 학점 명세의 정수 분할은 x<0→ERROR, 0~59→F, 60~69→D, 70~79→C, 80~89→B, 90~100→A, x>100→ERROR입니다. 대표값 -1,30,65,75,85,95,101은 각 분할을 한 번씩 검증합니다.
- 전이 경계의 바로 전/후를 포함하는 집합은 {-1,0,59,60,69,70,79,80,89,90,100,101}입니다. 더 엄격한 3값 BVA를 쓰면 각 분할 끝점 양 이웃까지 포함하므로 {-1,0,1,58,59,60,61,68,69,70,71,78,79,80,81,88,89,90,91,99,100,101}처럼 선택하고 어떤 규칙을 썼는지 밝힙니다.
- 137회 명세는 정수 여부→정수이면 범위를 분류합니다. {비정수}, {정수<10}, {10≤정수≤100}, {정수>100} 네 분할의 대표값은 1.5→Invalid Input,9→Fail,50→Pass,101→Fail입니다. 유효 경계는 9/10과100/101이며 10·100은 Pass입니다.
- 분류트리는 루트 입력 아래 타입(정수/비정수), 정수의 범위(10미만/10~100/100초과)를 놓고 불가능한 조합을 제외합니다. 비정수의 범위 판단은 하지 않습니다. 입력창의 문자열 파싱·공백 처리는 명세에 없으면 가정 또는 확인사항으로 구분합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 동등분할 | 각 분할 대표값 | 분할 누락과 유효/무효 입력 점검 |
| 경계값 | 전이 주변의 인접값 | <와≤ 등의 경계 결함 탐지 |
| 분류트리 | 입력 특성·클래스·조합 | 불가능 조합과 조합 범위를 명시 |

### 적용 예제

**강사 창작 적용 예시: 137회 입력값 실행표**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 입력은 9,10,50,100,101,1.5입니다.

1. 기대값을 각각 Fail,Pass,Pass,Pass,Fail,Invalid Input으로 적습니다.
2. 각 테스트 케이스가 어떤 입력 유형과 범위를 확인하는지 표시합니다.
3. 기대와 실제 결과가 다르면 입력값, 두 결과, 시험한 버전을 함께 기록합니다.

**결과·해석:** 대표값과 경계 검증을 구분한 재현 가능한 테스트가 됩니다.

**전제·주의:** 139회는 정수형만 명시하므로 비정수의 ERROR 처리까지 공식 요구로 추가하지 않습니다.

### 답안 골격과 혼동 방지

입력 조건과 분할·기대값 표 → 139회 7분할·경계 집합 → 137회 타입 우선 분류트리와 테스트

- 60은 F가 아닌 D,90은 A입니다.
- 3값 BVA를 적어 놓고 끝점 인접값을 빠뜨리지 않습니다.

### 내용을 가리고 회상

1. 139회 x=59,60,100,101의 출력은 무엇입니까?
2. 137회 비정수 입력을 먼저 구분해야 하는 이유는 무엇입니까?
3. 동등분할 100%가 모든 값 시험을 뜻합니까?
