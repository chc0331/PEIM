# 혼동행렬·정밀도·재현율·F1과 PR/ROC

## 서브노트

### 한눈에 이해

정상 요청이 대부분이면 전부 정상이라 답해도 정확도가 높을 수 있습니다. 양성을 잘 찾는지, 양성 경보가 얼마나 맞는지와 오탐 비용을 따로 보아야 합니다.

### 정의와 핵심 원리

정답과 예측의 일치·오류 유형을 집계하고 임계값·자료 분포·업무 비용에 맞는 지표로 모델을 평가하는 방법입니다.

- 양성 클래스를 먼저 정합니다. Accuracy=(TP+TN)/N, Precision=TP/(TP+FP), Recall=TP/(TP+FN), F1=2TP/(2TP+FP+FN)입니다. F1은 정밀도·재현율의 조화평균으로 TN을 직접 쓰지 않습니다. 분모0 처리와 다중클래스 macro/micro/weighted 평균을 선언합니다.
- ROC는 FPR=FP/(FP+TN)을 x축, TPR=Recall을 y축으로 임계값에 따른 순위를 평가합니다. PR은 Recall x축·Precision y축이며 양성 비율에 민감하고 희소 양성의 검출 품질을 읽는 데 유용합니다. AUROC와 AUPRC/AP는 정의·적분 방식이 다를 수 있으므로 동일 숫자로 비교하지 않습니다.
- 회귀에서 MAE는 절대 오차의 평균, MSE는 오차를 각각 제곱한 값의 평균, RMSE는 √MSE입니다. 제곱을 쓰는 지표는 큰 오차의 영향을 더 크게 받습니다. MAE와 RMSE는 예측값과 같은 단위를 씁니다. 독립 시험 자료에서 신뢰구간, 집단별 성능, 실제 임계값의 비용도 확인합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| Precision | 양성 예측 중 실제 양성 | 오탐 비용이 클 때 |
| Recall | 실제 양성 중 검출 | 미탐 비용이 클 때 |
| ROC·PR | FPR-TPR / Recall-Precision | 희소 양성·기저율 고려 |

### 적용 예제

**136회 혼동행렬 계산**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** TP=100, FP=5, FN=7, TN=9. % 표시 후 소수점을 버립니다.

1. N=121, Accuracy=109/121×100=90.082…→90%, Precision=100/105×100=95.238…→95%입니다.
2. Recall=100/107×100=93.457…→93%입니다.
3. F1=200/(200+5+7)×100=94.339…이므로 소수점을 버리면 94%입니다. 앞에서 이미 절사한 정밀도 95%와 재현율 93%를 다시 쓰지 않습니다.

**결과·해석:** 정확도 90%, 정밀도 95%, 재현율 93%, F1 94%입니다.

**전제·주의:** 각 비율의 분모는 서로 다르며 반올림이 아니라 최종 결과에서 소수점을 버립니다.

### 답안 골격과 혼동 방지

양성·혼동행렬 → 4지표 식·분모 → 원문 수치 계산 → PR/ROC 축·차이 → 임계값·불균형·회귀 지표

- FP와 FN을 바꾸지 않습니다.
- 정확도나 AUC 한 숫자만으로 모델을 선정하지 않습니다.
