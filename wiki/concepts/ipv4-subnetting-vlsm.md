# IPv4 서브네팅·슈퍼네팅·VLSM 계산

## 서브노트

### 한눈에 이해

주소를 부서 인원에 맞는 크기의 방으로 나누되, 각 방의 시작 위치를 정해진 경계에 맞춥니다.

### 정의와 핵심 원리

서브네팅은 프리픽스를 늘려 주소 블록을 분할하고, 슈퍼네팅은 연속되고 정렬된 블록을 짧은 공통 프리픽스로 집성합니다. VLSM은 호스트 요구에 맞춰 서로 다른 길이의 마스크를 사용합니다. 관련 개념을 계산 단원으로 묶었으며 서로의 동의어는 아닙니다.

- IPv4 /p의 전체 주소 수는 2^(32-p)입니다. 일반 LAN의 사용 가능 수는 네트워크·브로드캐스트를 뺀 2^h-2입니다. /31 점대점·/32 예외를 일반 LAN에 적용하지 않습니다.
- 고정 4분할은 2비트를 빌립니다. 192.168.100.0/24 → /26, 255.255.255.192, 64주소·62호스트입니다. 경계는 .0, .64, .128, .192이며 각 호스트는 .1~.62, .65~.126, .129~.190, .193~.254입니다.
- VLSM은 큰 요구부터 최소 2의 거듭제곱을 산정합니다. 500 → 512(/23), 250 → 256(/24), 125 → 128(/25) 두 개입니다. 512+256+128+128=1024로 /22에 정확히 들어갑니다. 인원 합에8을 더하는 방법은 블록별 반올림을 반영하지 못합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 개발500 | 192.168.0.0/23;255.255.254.0 | 호스트192.168.0.1~1.254;BC1.255 |
| 영업250 | 192.168.2.0/24;255.255.255.0 | 호스트192.168.2.1~2.254;BC2.255 |
| 인사125 | 192.168.3.0/25;255.255.255.128 | 호스트192.168.3.1~3.126;BC3.127 |
| 보안125 | 192.168.3.128/25;255.255.255.128 | 호스트192.168.3.129~3.254;BC3.255 |

### 적용 예제

**139-4-6 네 부서 배분**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 192.168.0.0/22;500·250·125·125호스트

1. 전체는192.168.0.0~192.168.3.255, 마스크255.255.252.0입니다.
2. 개발을 /23의 세 번째 옥텟0 경계부터 배치합니다.
3. 다음 주소192.168.2.0에 영업 /24를 배치합니다.
4. 남은192.168.3.0/24를 .0/25와 .128/25로 나눕니다.
5. 각 경계·중첩 없음·510/254/126/126 수용량과 총1024주소를 검산합니다.

**결과·해석:** 네 부서 수용 가능, 주소 블록 여유0, 호스트 여유 합 16개입니다.

**전제·주의:** 게이트웨이·프린터·증설이 별도 라면 추가 요구를 먼저 반영합니다. 제시 순서는 유일해가 아닙니다.

### 답안 골격과 혼동 방지

분할·집성 정의 → 호스트 수 식 → 큰 부서부터 정렬 → 마스크·호스트·BC 표 → 중첩·확장 검산

- /22를1024호스트라고 쓰지 않습니다.
- 125명에 /26은 부족합니다.
- 임의 시작 주소·브로드캐스트 할당은 오류입니다.

### 내용을 가리고 회상

1. /24를 네 블록으로 나눈 마스크·호스트 수는 얼마입니까?
2. 500명에 /23이 필요한 이유를 식으로 설명하십시오.
3. 연속된 두 블록 집성에도 경계 확인이 필요한 이유는 무엇입니까?

### 적용 기준과 근거

RFC4632의 CIDR 원리와 일반 LAN 조건. 기출 주소배분은 Python ipaddress로 중첩·경계·수용량 직접 검산.

**내용 검토 상태: 출처 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [RFC4632: Classless Inter-domain Routing](https://www.rfc-editor.org/rfc/rfc4632.html) — V. Fuller; T. Li / IETF; 2006-08; 확인 2026-11-05. 확인 범위: IPv4 프리픽스·집성 원문 열람. 서브넷 계산은 자체 검산.
