# AI 리스크·적대적 학습 공격·모델 전도

## 서브노트

### 한눈에 이해

모델이 틀릴 수 있다는 품질 문제와 공격자가 데이터·입력·출력을 이용해 의도적으로 실패시키는 위협을 구분합니다.

### 정의와 핵심 원리

AI리스크는사용맥락에서AI가 야기할 수 있는 피해의가능성과영향입니다. 적대적ML은 공격자의목표·지식·능력·생애주기위치에따라 오염·회피·기밀추론·모델 탈취·오용등을 분석합니다.

- 학습 단계poisoning은 데이터·라벨·모델 업데이트등을 조작해전체성능저하나조건부백도어를유도합니다. 추론 단계evasion은 입력을 조작해오분류·우회를노립니다. model extraction은 질의·응답등으로기능을 복제하고 membership inference는 특정 기록의 학습 참여 여부를추정합니다. 기출의4분류는 분류축을먼저 명시합니다.
- 모델 전도/model inversion은 출력·파라미터등에서입력 특성이나 민감 자료를 추론·복원하는공격입니다. 전도 결과가 항상 특정 개인의실제 원본과 일치한다는뜻은아닙니다. 접근제한·출력 정밀도/질의량·DP·학습 최소화·공격 평가를 상황에 맞게적용합니다.
- 보안 위험은 오염·탈취·프롬프트주입·권한남용, 프라이버시 위험은 학습 자료·입출력 누출·재식별, 사회 위험은 차별·허위정보·조작·의존·권력집중등으로구분합니다. provenance·검증집합·강건성평가·데이터정제·접근 분리·운영 감시와 피해 구제를전생애주기에 연결합니다.
- 파운데이션 모델 구현에서는 학습 자료·출력의 개인정보와 지식재산권 및 적용되는 이용조건을 검토합니다. 학습·미세조정·추론의 전력·물 사용과 환경영향을 측정하거나 추정하고, 편향·허위정보·접근격차 등 사회적 영향을 평가합니다. 모델의 개념·특징·기반기술은 [파운데이션·언어·멀티모달 모델](foundation-language-multimodal-models.md)의 정의와 핵심 원리를 함께 확인합니다. 이는 운영상 검토 방향이며 개별 법적 결론이 아닙니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 오염 | 학습 자료·업데이트변조 | 출처·검증·강건 집계 |
| 회피 | 추론 입력조작 | 위협 모델·강건성·입력 통제 |
| 프라이버시 공격 | 참여·특성·원문 추정 | 출력·질의·DP·수집제한 |

### 적용 예제

**고객분류 모델의 누출 평가**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 확률벡터를무제한공개하는API 가정

1. 공격자가어떤출력·지식·질의량을얻는지정의합니다.
2. 회원추론·전도·추출을별도로시험하고 실제 원본일치여부를검증합니다.
3. 필요이상의출력·반복질의와 접근 권한을 줄입니다.
4. 유용성저하와잔여위험을 측정하며 모니터링합니다.

**결과·해석:** 공격 목표·관측·방어효과를 분리하고 단일방어의한계를 기록합니다.

**전제·주의:** 공격 분류는 문헌별로 다릅니다.방어가특정 위협 모델밖에서도완전보호한다는보장은없습니다.

### 답안 골격과 혼동 방지

리스크범주 → 공격생애주기도 식 → 4공격비교 → 전도·회원추론구분 → 다층대응

- 모든 AI오류를 적대적공격이라 하지 않습니다.
- 전도와 모델 파라미터추출을동일시하지 않습니다.

### 내용을 가리고 회상

1. 오염과 회피는 어느단계가 다릅니까?
2. 회원추론과 전도는 무엇을알아내려합니까?
3. 보안·프라이버시·사회적위험을 한사례에서 구분하십시오.
