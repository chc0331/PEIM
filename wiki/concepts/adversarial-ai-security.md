# AI 리스크·적대적 학습 공격·모델 전도

## 서브노트

### 한눈에 이해

모델은 공격이 없어도 틀릴 수 있습니다. 적대적 공격에서는 공격자가 데이터·입력·출력에 손을 대거나 이를 관찰해 원하는 결과를 얻으려 합니다.

### 정의와 핵심 원리

AI 위험은 AI를 특정 용도로 사용할 때 발생할 수 있는 피해의 가능성과 영향입니다. 적대적 머신러닝은 공격자의 목표·지식·능력과 공격이 일어나는 단계를 바탕으로 오염, 회피, 기밀 정보 추론, 모델 탈취와 오용 등을 분석합니다.

- 학습 단계의 오염 공격(poisoning)은 데이터·라벨·모델 업데이트 등을 조작해 전체 성능을 낮추거나 특정 입력에서만 작동하는 백도어를 심습니다. 추론 단계의 회피 공격(evasion)은 입력을 바꿔 오분류나 통제 우회를 노립니다. 모델 추출(model extraction)은 모델의 구조나 파라미터를 알아내려는 공격입니다. 멤버십 추론(membership inference)은 특정 표본이 모델의 학습 데이터에 들어 있었는지 추정합니다. 기출에 네 가지를 적을 때는 먼저 어떤 기준으로 분류했는지 밝힙니다.
- 모델 전도(model inversion)는 모델 출력이나 파라미터 등을 바탕으로 입력의 특성이나 민감한 자료를 추정·복원하는 공격입니다. 복원 결과가 특정 개인의 실제 원본과 항상 일치하지는 않습니다. 접근 제한, 출력 정밀도·질의량 제한, 차분 프라이버시(DP), 학습 자료 최소화와 공격 검증을 상황에 맞게 적용합니다.
- 보안 위험에는 오염·탈취·프롬프트 주입·권한 남용, 프라이버시 위험에는 학습 자료나 입출력의 유출·재식별, 사회적 위험에는 차별·허위 정보·조작·의존·권력 집중 등이 있습니다. 자료의 출처·변경 이력을 남기고, 검증 집합·강건성 평가·데이터 정제·접근 분리·운영 감시와 피해 구제를 생애 주기별로 적용합니다.
- 파운데이션 모델을 구현할 때는 학습 자료와 출력의 개인정보·지식재산권과 이용 조건을 검토합니다. 학습·미세 조정·추론에 드는 전력과 물 사용량, 환경 영향을 측정하거나 추정하고, 편향·허위 정보·접근 격차 등 사회적 영향을 평가합니다. 모델의 개념·특징·기반 기술은 [파운데이션·언어·멀티모달 모델](foundation-language-multimodal-models.md)의 정의와 핵심 원리를 함께 확인합니다. 운영상 검토 항목이며 법적 판단은 개별 사안에 맞춰 합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 오염 | 학습 자료·업데이트 변조 | 출처 확인·검증·강건한 집계 |
| 회피 | 추론 입력 조작 | 위협 모델·강건성·입력 통제 |
| 프라이버시 공격 | 학습 데이터 포함 여부·특성·원문 추정 | 출력과 질의 제한·DP·수집 제한 |

### 적용 예제

**고객분류 모델의 누출 평가**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 예측 결과의 확률 벡터를 질의 횟수 제한 없이 돌려주는 API를 가정합니다.

1. 공격자가 볼 수 있는 출력, 미리 아는 정보, 질의 가능 횟수를 정합니다.
2. 멤버십 추론은 실제 학습 집합을 기준으로, 모델 전도는 복원된 특성을 원본과 비교해 평가합니다. 모델 추출은 노린 구조나 파라미터를 얼마나 알아냈는지 별도로 평가합니다.
3. 필요한 출력만 제공하고 반복 질의와 접근 권한을 제한합니다.
4. 대응이 서비스의 유용성에 미친 영향과 남은 위험을 측정합니다.

**결과·해석:** 공격마다 알아내려는 정보가 다릅니다. 목적에 맞는 평가 기준으로 대응 효과와 한계를 확인합니다.

**전제·주의:** 공격 분류는 문헌마다 다를 수 있습니다. 대응 효과는 시험한 위협 모델 안에서 해석합니다.

### 답안 골격과 혼동 방지

위험 범주 → 공격이 일어나는 단계 → 공격 네 가지 비교 → 모델 전도와 멤버십 추론의 차이 → 여러 대응 수단의 조합

- AI 오류를 적대적 공격으로 판단하려면 공격 행위의 근거가 필요합니다.
- 모델 전도와 모델 파라미터 추출은 알아내려는 정보가 다릅니다.

### 내용을 가리고 회상

1. 오염과 회피는 각각 어느 단계에서 일어납니까?
2. 멤버십 추론과 모델 전도는 각각 무엇을 알아내려 합니까?
3. 하나의 사례에서 보안·프라이버시·사회적 위험을 구분해 보세요.
