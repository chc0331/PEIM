# 소프트웨어 품질과 ISO/IEC 25010 판본

## 서브노트

### 한눈에 이해

품질 모델을 쓰면 ‘좋은 소프트웨어’를 기능 적합성, 응답 시간, 복구 능력처럼 구체적으로 평가할 수 있습니다.

### 정의와 핵심 원리

소프트웨어 품질은 명시·묵시적 필요와 사용 맥락을 만족하는 특성의 정도입니다. ISO/IEC 25010은 제품 품질의 특성과 부특성으로 요구·설계·측정·시험·인수 기준의 공통 틀을 제공합니다.

- 2011판의 제품 품질 주특성 8개는 기능적합성·성능효율성·호환성·사용성·신뢰성·보안성·유지보수성·이식성입니다. 예를 들어 기능적합성은 완전성/정확성/적절성, 성능효율성은 시간반응/자원사용/용량, 호환성은 공존성/상호운용성을 나눕니다.
- 2011판 신뢰성은 성숙성·가용성·결함허용성·회복성, 보안성은 기밀성·무결성·부인방지·책임성·인증성, 유지보수성은 모듈성·재사용성·분석성·변경성·시험성, 이식성은 적응성·설치성·대체성을 구분하는 고전 학습 틀입니다.
- 2023판 공식 초록은 9개 주특성 모델로의 개정을 확인시켜 줍니다. 기능적합성·성능효율성·호환성·상호작용역량·신뢰성·보안성·유지보수성·유연성·안전성으로 설명되는 최신 모델을 2011판 8특성과 혼합해서 쓰면 안 됩니다. 사용중 품질은 별도 ISO/IEC 25019와 구분해야 합니다.
- 품질 목표는 요구별로 측정조건과 기준에 연결합니다. “신뢰성이 좋다” 대신 고장 빈도·가용시간·복구 시간, 유지보수성은 변경 영향과 시험가능성을 측정합니다. 좋은 SW의 4가지 특징이라는 교재 분류는 유지보수성·신뢰성/보안·효율성·수용 가능성으로 쓰이지만 유일한 국제표준 4특성은 아닙니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 2011판 | 제품 품질 8특성 | 기출 당시의 구분·용어 유지 |
| 2023판 | 제품 품질 9특성 | 안전·상호작용·유연성 변경 확인 |
| 제품/사용중 품질 | 제품 속성 / 사용 맥락의 결과 | 표준 범위를 명확히 구분 |

### 적용 예제

**강사 창작 적용 예시: 장애 알림 서비스의 품질 목표**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 기능 요구는 알림 전달이며 사용자는 누락과 지연을 우려합니다.

1. 정확성은 대상·내용의 일치, 성능은 전달 지연, 신뢰성은 실패 시 재시도로 나눕니다.
2. 각 특성의 부특성에 시험과 측정조건을 연결합니다.
3. 보안·가용성을 동시에 높이는 설계의 비용과 절충을 검토합니다.

**결과·해석:** 품질 특성별로 요구사항을 작성하고 각 요구를 확인할 시험을 설계할 수 있습니다.

**전제·주의:** 2023판 부특성 전체 목록·정식 번역은 유료 원문 미열람으로 추가 대조가 필요합니다.

### 답안 골격과 혼동 방지

품질 정의와 모델의 용도 → 2011/2023 주특성·부특성 구분 → 측정·인수 적용과 판본 주의

- 140회에 구판 8특성을 최신이라고 단정하지 않습니다.
- 인증 획득과 모든 사용 환경에서의 품질 보장을 동일시하지 않습니다.

### 내용을 가리고 회상

1. 2023판의 품질 주특성은 몇 개이며, 2011판보다 몇 개 늘었습니까?
2. 제품 품질과 사용중 품질은 어떻게 다릅니까?
3. 가용성과 회복성의 차이를 예로 설명하십시오.

### 적용 기준과 근거

공식 초록으로 2023판·9특성은 확인했습니다. 2011/2023 세부 부특성 전체와 네 특징 교재 출전은 원문 추가 대조 필요합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [ISO/IEC 25010:2023 Product quality model](https://www.iso.org/standard/78176.html) — ISO/IEC; 2023-11; 확인 2026-11-05. 확인 범위: 공식 초록 및 판본 메타데이터 열람. 유료 표준 전체 본문 미열람. 9개 주특성과 부특성 상세는 공개 제공 범위에서만 확인하며 전 목록의 규범적 번역은 추가 확인 필요합니다.
- [Guide to the SWEBOK v4.0a](https://ieeecs-media.computer.org/media/education/swebok/swebok-v4.pdf) — IEEE Computer Society / Hironori Washizaki 편; 2026-08; 확인 2026-11-05. 확인 범위: 공개 PDF 열람. 요구사항·설계·테스트·유지보수·형상관리·품질 장의 해당 절을 참조. 기출 당시 판본과 현재 v4.0a를 구분합니다.
