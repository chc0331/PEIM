# 프로젝트 관리

## 서브노트

### 정의

프로젝트 관리는 한시적 목표와 산출물을 범위·일정·비용·품질·위험·이해관계자 제약 아래에서 달성하도록 통합·조정하는 활동이다. 예측형, 반복형, 적응형, 하이브리드 방식은 상황에 따라 선택·조합한다.

### 핵심 구조·도식

`착수 → 계획(범위·WBS·일정·위험) → 실행 → 감시·통제 → 종료·교훈`

### 답안 키워드·비교·적용

| 관리 항목 | 핵심 통제 |
| --- | --- |
| 범위 | 요구사항·WBS·변경 통제 |
| 일정·비용 | 기준선·진척·예측 |
| 품질 | 품질 기준·검증·결함 관리 |
| 위험 | 식별·분석·대응·모니터링 |
| 이해관계자 | 역할·의사소통·합의 |

워터폴은 계획 안정성이 높은 경우, 애자일은 요구 변화·학습이 큰 경우에 적합할 수 있다. 방법론보다 의사결정 주기와 통제 증거를 설계한다.

### 한계·리스크

일정표만 관리하면 범위와 위험이 누락된다. 과도한 보고는 실행 시간을 잠식하므로 핵심 지표·의사결정권·에스컬레이션 기준을 명확히 한다.

### 답안 골격

- **1교시:** 정의 → 생명주기 → 관리 대상 표 → 방법론 비교 → 성공 요인.
- **논술형:** 목표·범위 → WBS·일정·예산 → 위험·품질·변경 통제 → 보고·성과 → 종료·교훈.

### 회상 확인

1. WBS가 일정·비용·위험 관리에 주는 효과는 무엇인가?
2. 예측형과 애자일을 선택하는 기준을 비교하라.
3. 지연 프로젝트의 회복 계획에 포함할 항목은 무엇인가?
