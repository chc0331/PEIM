# PET 분류와 동형암호

## 서브노트

### 한눈에 이해

데이터를 원문으로 모으지 않고 계산하거나, 공개 결과에 서 개인의 영향을 줄이는 등 보호지점을 먼저 선택합니다.

### 정의와 핵심 원리

PET는 개인정보 침해 위험을 줄이면서정해진 데이터 활용을 가능하게하는기술군입니다. 동형암호는 암호문에 연산한결과를 복호하면 대응하는평문 연산 결과가 나오는암호 기법으로, 계산위탁자가원문을 보지않게할 수 있습니다.

- PET는 암호 기반 계산(HE/MPC), 분산학습(FL), 통계적공개 보호(DP), 데이터변환·합성등으로나눌수 있습니다. 보호 대상은 입력·중간계산·출력·모델중어디인지명확히하며 기술 이름만 으로법적익명성이나 정확한보호수준을보장하지 않습니다.
- PHE는 제한된연산 종류, SHE/leveled는 제한깊이, FHE는 부트스트래핑등으로일반 연산을 지속하도록설명합니다. 암호문잡음·곱셈깊이·회전·키교환·패킹이성능·정확도에 영향을 줍니다. SEAL의BFV/BGV는 암호화정수모듈러연산, CKKS는 근사실수/복소연산에 적합합니다.
- HE는 암호화된정확/근사계산을 하지만결과자체의개인정보 노출은 별도 입니다.DP는 분포 보호를 위해잡음을넣고합성데이터는 학습한분포를 모사해새자료를 만드나학습 원본을 기억할 수 있습니다. 계산 비용·공개수준·유용성·공모 가정으로 선택합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| HE | 암호문 계산;입력비공개 | 연산 비용·출력 누출 |
| DP | 개인영향제한;통계 보호 | ε·잡음·누적질의 |
| 합성데이터 | 분포를 모사한생성자료 | 품질·기억·재식별검사 |

### 적용 예제

**비공개 급여 합계**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 회사두곳이개별급여를서버에 노출하지 않고합계계산

1. 권한있는 집계자가공개 키를 제공합니다.
2. 각급여를암호화하고 서버는 암호문합을구합니다.
3. 집계자는결과만 복호하고 소집단 노출 위험을 검토합니다.
4. 필요시최소집계크기·DP등출력 보호를 추가 합니다.

**결과·해석:** 암호문 계산의 입력 보호와 최종통계 보호를 구분합니다.

**전제·주의:** 구체보안파라미터·키 관리와 성능 시험은 미수행입니다.합성자료를 자동익명으로간주하지 않습니다.

### 답안 골격과 혼동 방지

PET 보호지점 → HE식·유형 → 세기술상세비교 → 집계사례 → 성능·출력 한계

- FHE가 무제한무료계산을 뜻하지 않습니다.
- CKKS근사값을 회계정 수정확값과 혼동하지 않습니다.

**내용 검토 상태: 출처 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.
