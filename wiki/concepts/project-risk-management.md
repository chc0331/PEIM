# 프로젝트 위험관리·대응·ISO 31000

## 서브노트

### 한눈에 이해

위험은 이미 발생한 문제와 다릅니다. 앞으로 일어날지 모르는 일이 목표에 어떤 영향을 줄지 살핍니다. 납기 지연처럼 불리한 영향과 새 기회를 얻는 유리한 영향을 모두 고려합니다.

### 정의와 핵심 원리

위험관리는 목표에 대한 불확실성의 영향을 식별·분석·평가·처리·감시·소통하는 활동입니다. ISO31000은 이를 조직 의사결정·거버넌스와 통합하는 원칙·프레임워크·프로세스 지침입니다.

- 관리계획에서 위험 범주·확률/영향 척도·허용기준·소유자·보고주기를 정합니다. 워크숍·과거사례·가정/의존성 분석으로 원인→사건→결과 형태의 위험을 식별하고 등록부에 기록합니다. 발생한 이슈는 별도 조치와 변경을 관리합니다.
- 정성 분석은 확률·영향·긴급성 등으로 우선순위를 정하고, 필요하면 기대금액·민감도·시뮬레이션으로 일정·비용 범위를 분석합니다. 숫자는 자료·분포·가정을 밝혀야 하며 위험 점수는 객관적 확률 그 자체가 아닙니다.
- 위협은 회피(원인/노출 제거), 전가(보험·계약으로 부담 이전), 완화(가능성/영향 감소), 수용(능동적 예비·대기), 상위 이관으로 대응할 수 있습니다. 기회는 활용·증대·공유·수용·상위 이관을 상황에 맞게 씁니다.
- 대응안마다 소유자·기한·트리거·조치비·비상/대체계획·잔여/2차 위험을 기록합니다. 실행 후 효과를 점검하고 신규 위험을 갱신합니다. ISO31000의 가치창출·보호 목적 아래 통합·체계적/포괄적·맞춤형·포용적·역동적·최선 정보·인간/문화·지속 개선의 8원칙을 반영합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 위협 회피/완화 | 원인 제거 / 노출 감소 | 회피와 위험이 일부 남는 완화를 구분 |
| 전가/공유 | 위협 부담 이전 / 기회 공동 확보 | 계약으로 모든 책임이 사라지지 않음 |
| 수용 | 불확실성을 인지해 잔여 위험 유지 | 트리거·예비·승인 필요 |

### 적용 예제

**강사 창작 적용 예시: 외부 API 제공 지연 위험**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 연계기관 API가 준비되지 않으면 통합시험이 늦습니다.

1. 위험 등록부에 담당자, API 준비 기한, 대체 계획을 시작할 조건을 적습니다.
2. Stub 선행검증과 대체 일정으로 영향을 완화하고 계약상 협조를 합의합니다.
3. 정해 둔 조건에 이르면 비상계획을 실행하고 아직 해결하지 못한 연계 위험을 보고합니다.

**결과·해석:** 위험·대응·실행 증거가 연결됩니다.

**전제·주의:** 미확인 확률이나 손실 금액을 만들어 정량분석을 장식하지 않습니다.

### 답안 골격과 혼동 방지

위험/이슈·ISO 지침 정의 → 식별→분석→평가→대응→감시 → 위협/기회 전략·등록부·예시

- 리스크 대응을 전부 완화라고 부르지 않습니다.
- ISO31000을 인증 요구사항 표준으로 설명하지 않습니다.

### 내용을 가리고 회상

1. 잔여 위험과2차 위험은 어떻게 다릅니까?
2. 전가와 회피를 구분해 보십시오.
3. 기회의 활용과 증대는 어떤 차이가 있습니까?

### 적용 기준과 근거

고전 개념의 설명이며 2026-11-05 열람 원문을 기준으로 했습니다.

**내용 검토 상태: 출처 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [ISO31000:2018 공개 미리보기: 원칙](https://preview.sist.si/sist-preview/65694/60673072317a4b96bd36efb910b68926/ISO-31000-2018.pdf) — ISO / Slovenian Institute for Standardization(SIST) 공개 미리보기; 2018; 확인 2026-11-05. 확인 범위: 국가표준기관이 제공한 공개 미리보기의Figure2와8원칙 범위를 읽었습니다. 전체 표준 본문 열람·복제는 하지 않았습니다.
