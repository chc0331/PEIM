# 베이즈 정리와 기저율

## 서브노트

### 한눈에 이해

검사기가 불량을 잘 찾더라도 불량 자체가 매우 드물면 양성 가운데 정상 제품이 많을 수 있습니다. 양성이라는 관측 뒤에 불량일 가능성을 다시 계산하는 것이 베이즈 갱신입니다.

### 정의와 핵심 원리

관측 증거의 가능도와 사전확률을 결합하여 조건부 사후확률을 계산하는 확률 항등식입니다.

- P(H|E)=P(E|H)P(H)/P(E)이며 P(E)>0이어야 합니다. P(H)는 사전, P(E|H)는 가능도, P(H|E)는 사후입니다. P(E|H)와 P(H|E)는 분모가 다른 확률이므로 방향을 뒤집어 쓰지 않습니다.
- 상호배타적이고 전체를 나누는 가설 H_i이면 P(E)=ΣP(E|H_i)P(H_i)로 구합니다. 이 분모는 모든 경로로 증거가 발생한 확률입니다. 이진 검사에서는 true positive와 false positive가 함께 양성 분모를 이룹니다.
- 독립이라는 조건 없이도 베이즈 정리 자체는 성립합니다. 여러 증거의 likelihood를 곱하려면 해당 조건부 독립성이 필요합니다. 새로운 자료로 사후를 갱신할 수 있지만 잘못된 사전·표본 편향·변한 발생률은 결론을 바꾸므로 가정과 민감도를 함께 설명합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 사전 | 관측 전 가설 확률 | 기저율·배경정보 |
| 가능도 | 가설일 때 증거 확률 | P(E&#124;H) |
| 사후 | 증거 후 가설 확률 | P(H&#124;E), 정규화 필요 |

### 적용 예제

**불량 탐지의 양성 해석**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 제품 10,000개, 불량률1%, 민감도90%, 정상의 오탐률5%입니다.

1. 불량100개 중 양성90개, 정상9,900개 중 오양성495개입니다.
2. 양성 전체는 90+495=585개이고 실제 불량은90개입니다.
3. P(불량|양성)=90/585≈15.38%입니다. 식으로는 0.9×0.01/(0.9×0.01+0.05×0.99)입니다.

**결과·해석:** 민감도90%와 양성 후 불량 확률15.38%는 서로 다른 질문에 답합니다.

**전제·주의:** 정상 오탐률5%를 특이도95%와 혼동하지 않고 발생률이 바뀌면 다시 계산합니다.

### 답안 골격과 혼동 방지

정의·식 → 사전-가능도-증거-사후 → 총확률 분모 → 10,000개 빈도 표 → 가정·기저율 영향

- 민감도를 양성 예측도로 착각하지 않습니다.
- 베이즈 정리를 단순히 주관적 확률이라고 축소하지 않습니다.
