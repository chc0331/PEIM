# 가명처리·익명처리와 재식별 위험

## 서브노트

### 한눈에 이해

이름을 지워도 다른 자료와 합쳐 누군지 알 수 있으므로 식별정보·준식별자·추가 정보·이용 환경을 같이 평가합니다.

### 정의와 핵심 원리

가명처리는 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보 일부를 삭제·대체하는 처리이고 익명화는 합리적으로 고려할 수 있는 수단으로 개인을 알아볼 수 없는 수준을 목표로 합니다. 둘은 처리 기술뿐 아니라 재식별 가능성·법적 취급의 차이가 있습니다.

- 직접 식별자는 토큰 대체·삭제하고 생년월일·주소·희귀 직업 같은 준식별자는 범주화·일반화·억제·표본 추출·노이즈 등을 검토합니다. 일관된 가명은 분석 연결성을 유지하지만 연계 공격의 경로도 될 수 있습니다. 추가 정보와 매핑 키는 분리하여 접근을 통제합니다.
- 위험 평가는 목적·수신자·외부 자료·공격자 능력·희귀 값·조합 식별·반출 조건을 포함합니다. k-익명성은 동일 준식별 조합의 최소 집단 크기이지만 민감 값이 동질적이거나 배경 지식이 있으면 노출이 남습니다. 분석 유용성과 보호의 절충을 검증합니다.
- 준비 → 위험 검토 → 가명처리 → 적정성 검토 → 안전 관리의 흐름으로 설명할 수 있습니다. 재식별 시도를 금지하고 이용 목적과 보유 기간을 지킵니다. 접근 기록을 남기고 추가 정보는 분리해 관리합니다. 최신 가이드의 법정 절차·결합 전문 기관 요건 등은 해당 원문을 확인해야 합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 가명 | 추가 정보 없이 식별 곤란 | 추가 정보·목적·통제 필요 |
| 익명 | 합리적 수단으로 식별 곤란 | 환경 변화·외부 정보 재검토 |
| 마스킹 | 화면이나 필드의 표시 가림 | 데이터 전체 익명성 보장 아님 |

### 적용 예제

**소규모 진료 통계**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 이름을 삭제해도 정확한 나이·우편번호·희귀 질환 정보가 남아 있습니다.

1. 직접 식별자가 없어도 희귀 조합으로 개인이 드러날 수 있는지 평가합니다.
2. 나이는 연령대로, 지역은 넓은 권역으로 묶고 인원이 적은 셀은 공개하지 않습니다.
3. 질환 분포 보존과 재식별 위험을 함께 검사합니다.
4. 반출 대상·통제 환경에 맞춰 잔여 위험을 기록합니다.

**결과·해석:** 다른 자료와 결합해 개인을 식별할 수 있는지, 처리한 자료가 분석 목적에 맞는지 평가합니다.

**전제·주의:** 2026년 3월 공식 가명정보 가이드의 목록을 확인했습니다. 첨부 전문은 열람하지 못했습니다. 법정 익명성 판정이나 활용 승인 사례로 사용하지 않습니다.

### 답안 골격과 혼동 방지

정의·추가 정보 → 기법 분류 → 처리 절차 → 유용성·위험 평가 → 안전 운영

- 식별자 해시만으로 익명이라 선언하지 않습니다.
- k가 크면 모든 민감 속성이 보호된다고 하지 않습니다.

### 내용을 가리고 회상

1. 가명과 익명은 추가 정보에 대해 어떻게 다릅니까?
2. 준식별자 조합은 왜 위험합니까?
3. 마스킹과 가명처리의 범위 차이는 무엇입니까?
