# 이상치·노이즈·편향과 처리 판단

## 서브노트

### 한눈에 이해

폭염 날 전력사용량 급증은 중요한 사건일 수 있지만 센서 단선의 큰 값은 측정 오류일 수 있습니다. 값이 크다는 이유만으로 지우면 드문 고장 신호를 잃습니다.

### 정의와 핵심 원리

이상치는 정상으로 기대한 패턴에서 벗어난 관측이며 노이즈는 원 신호를 흐리는 우연 오차, 편향은 수집·측정·모형에서 체계적으로 치우치는 성질입니다.

- 전역 이상은 전체 분포에서 극단적인 점, 맥락 이상은 시간·장소·상태를 고려할 때 비정상인 점, 집단 이상은 개별 값보다 연속 구간/조합이 비정상인 경우입니다. 고장 탐지가 목적이면 이상치를 보존·라벨링할 수 있고 입력 오류이면 원인을 교정합니다.
- 탐지는 IQR·z/강건 점수·밀도(LOF/DBSCAN)·분리(IsolationForest)·예측/재구성 잔차로 할 수 있습니다. 필터링은 범위·형식·업무 조건·주파수/시간 평활 등 목적별 방법이며 통과·제외 조건과 원본을 남깁니다. 기준은 학습 자료에 맞추고 미래 자료를 보고 뒤늦게 조정한 시험 결과와 구분합니다.
- 이상치는 평균·분산·회귀 계수·거리/군집을 흔들 수 있고 편향은 특정 집단의 체계적 오차를 만듭니다. 처리에는 재측정·오류 교정·강건 추정·변환·대체·분리 모델·유지와 경고가 있으며 무조건 삭제는 해법이 아닙니다. 전처리 전후 분포·집단별 성능·오탐/미탐 비용을 비교합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 이상치 | 기대 패턴에서 이탈 | 사건·오류 모두 가능 |
| 노이즈 | 신호를 흐리는 오차 | 측정·전송 원인 점검 |
| 편향 | 체계적인 방향의 치우침 | 표집·측정·모형 각각 진단 |

### 적용 예제

**전력계 이상 판정**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 새벽 전력이 100kW라면 공장 휴무일에는 높지만, 정상 생산일에는 평소 수준일 수 있습니다.

1. 전체 IQR만으로 판정하지 않고 요일·가동상태·기온을 맥락으로 넣습니다.
2. 여러 번 측정한 값이 100kW에 고정되면 센서값이 멈췄는지, 실제로 부하가 일정했는지 확인합니다.
3. 원본·제외 사유를 보존하고 강건 모델/교정 후 정상·고장 집단의 성능을 다시 측정합니다.

**결과·해석:** 이상하다고 표시한 값을 바로 지우지 않습니다. 원인이 센서 오류라면 교정하고, 실제 고장 신호라면 보존합니다.

**전제·주의:** 모든 이상치를 노이즈로 지우면 사기·고장처럼 희귀하지만 중요한 양성이 사라집니다.

### 답안 골격과 혼동 방지

정의·3종 이상 → 노이즈·편향 비교 → 통계/밀도/분리/잔차 → 처리 대안·필터링 → 영향과 전후 검증

- 3σ 밖을 무조건 오류로 단정하지 않습니다.
- 편향된 자료를 단순 표준화만으로 고쳤다고 하지 않습니다.

### 적용 기준과 근거

탐지 알고리즘과 일반 품질 관리 근거를 확인했습니다. 전역/맥락/집단 분류와 필터링 범위는 질문 문맥에 맞춘 강사 정리입니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [scikit-learn: Novelty and Outlier Detection](https://scikit-learn.org/stable/modules/outlier_detection.html) — scikit-learn developers; 1.9.1 표시; 확인 2026-11-05. 확인 범위: 실제 열람: 오염 학습 표본의 outlier vs clean train의 novelty, IsolationForest의 무작위 분리와 LOF. 전역/맥락/집단 이상 구분은 시계열 예제에서 강사 분석으로 제시합니다.
- [Data quality use cases](https://legacy.docs.greatexpectations.io/docs/reference/learn/data_quality_use_cases/dq_use_cases_lp/) — Great Expectations; GX 1.23.2 표시; 확인 2026-11-05. 확인 범위: 실제 열람: distribution/freshness/integrity/missingness/schema/uniqueness/volume와 비정형 metadata 검사. 국내 공공 성숙도 모델 등급을 이 문서로 검증하지 않습니다.
