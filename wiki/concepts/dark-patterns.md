# 다크패턴 유형·예방/규제 대응

## 서브노트

### 한눈에 이해

사용자가 화면의 모든 정보를 살피기 어렵다는 점을 이용해 원치 않는 결제·동의·가입을 유도하거나 취소를 어렵게 만드는 설계입니다.

### 정의와 핵심 원리

다크패턴은 인터페이스의 정보·선택·순서·시각적 강조를 조작해 사용자의 자율적 판단을 흐리거나 방해하고 사업자에게 유리한 행동을 유도하는 방식입니다. 단순히 미적으로 나쁜 화면과는 구분합니다.

- 대표 유형은 광고를 독립 정보로 위장, 허위 희소성/타이머·사회적 압박, 주요조건·추가비용 은폐, 사전선택·장바구니 끼워넣기, 복잡한 취소/탈퇴, 동의 유도/거절 방해와 개인정보 과다 제공 유도입니다. 여러 패턴이 한 흐름에서 결합하면 한 화면만 검사해서는 문제를 놓칩니다.
- 국내에서 2025년에 신설한 6개 유형은 숨은 갱신(증액/무료→유료의 인지·동의 문제), 순차공개 가격책정(필수 총비용을 뒤늦게 공개), 특정옵션 사전선택(다른 구매를 미리 선택), 잘못된 계층구조(차별적 강조로 유인), 취소·탈퇴 방해, 반복간섭입니다. 유형 이름과 구체 행위·피해를 연결해 설명합니다.
- 개선은 총가격·기간/갱신·필수/선택의 명확한 표시, 구매/개인정보의 적극적 선택, 유사한 명확성의 수락/거절, 가입만큼 찾기 쉬운 취소, 실재하는 희소성·진실한 광고/후기, 동의 철회·완료 확인입니다. 불필요한 반복팝업·수치심 유발 문구와 방향을 바꾼 버튼을 피합니다.
- 조직 대응은 기획·UX·개발·법무의 흐름 검토, 취약 사용자·접근성 시험, 버전/동의·가격/갱신 기록, 민원/환불/탈퇴 성공률 감시, 제휴/광고와 실험의 감독입니다. 전환율만으로 성과를 보상하면 피해가 커질 수 있어 이해·실수/후회·구제 지표를 함께 봅니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 정보 왜곡 | 광고위장·가격/중요조건 은폐 | 진실한 정보·총비용·적시 고지 |
| 선택 유도 | 사전선택·시각차별·반복간섭 | 명확하고 자유로운 수락/거절 |
| 행동 방해 | 취소/탈퇴를 숨기거나 지연 | 쉽게 찾는 절차·완료/철회 확인 |

### 적용 예제

**강사 창작 적용 예시: 무료 체험 구독 화면 교정**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 가입 버튼만 크게 보이고 유료 전환·해지는 작은 글씨입니다.

1. 기간·전환일·금액·해지 조건을 결정 전에 명확히 제공합니다.
2. 적용 법률에 맞는 동의와 취소/철회·고지 기록을 설계합니다.
3. 취소까지 전체 흐름을 시험하고 성공률·민원·원치 않는 결제를 점검합니다.

**결과·해석:** 가입률과 함께 이용자가 유료 전환 조건을 이해했는지, 원할 때 구독을 취소할 수 있는지 확인합니다.

**전제·주의:** 창작 UX 사례입니다. 모든 갱신이 불법인 것은 아니며 법의 대상·예외·현행 가이드 해석을 확인합니다.

### 답안 골격과 혼동 방지

정의·인지편향·피해 → 세부 유형·구체 예 → UX·운영·법제·성과 통제

- 정당한 안내나 필요한 확인을 모두 다크패턴으로 단정하지 않습니다.
- 2025 개정6유형과 전체 분류 또는2026금융 가이드 유형 수를 섞지 않습니다.

### 내용을 가리고 회상

1. 사전선택과 잘못된 계층구조는 무엇이 다릅니까?
2. 화면 한 장이 아닌 전체 흐름을 봐야 하는 이유는 무엇입니까?
3. 전환율 외에 어떤 소비자 지표가 필요합니까?

### 적용 기준과 근거

기출 당시 일반 유형·2025-02-14 신설 규율을 구분했습니다. 2026-10-06 새 운영 가이드 배포를 확인했으나 별첨 전체·현행 법령의 후속 변경 대조는 추가 확인 필요합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [Bringing Dark Patterns to Light](https://www.ftc.gov/system/files/ftc_gov/pdf/P214800%20Dark%20Patterns%20Report%209.14.2022%20-%20FINAL.pdf) — US FTC Bureau of Consumer Protection; 2022-09; 확인 2026-11-05. 확인 범위: 공개 원 보고서의 정의·소비자 선택 침해·대표 유형과 대응 설명 열람. 미국 법집행을 국내 규정과 동일시하지 않습니다.
- [정기결제 대금 인상 또는 유료 전환 전30일 이내 소비자 동의받아야](https://m.korea.kr/news/policyNewsView.do?newsId=148939436) — 공정거래위원회; 2025-02-10; 확인 2026-11-05. 확인 범위: 2025-02-14 개정 시행에 대한 기관 공식 설명 열람. 선택 예외·정당한 사유 등 실제 적용은 법문·후속 지침을 확인해야 합니다.
- [온라인 다크패턴 규제 관련 가이드라인 배포](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156784349) — 공정거래위원회; 2026-10-06; 확인 2026-11-05. 확인 범위: 새 가이드라인 배포 사실과 공식 본문 열람. 별첨 지침 전체의 세부 해석은 미열람으로 종전 설명을2026최종 해석이라고 단정하지 않습니다.
