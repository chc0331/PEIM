# 개인정보 보호 법·내부 관리 계획·마이데이터 권리

## 서브노트

### 한눈에 이해

수집에 서 파기까지 누가 어떤 근거와 권한으로 처리하는지를 기록하고, 정보 주체가 이동·설명·거부 권리를 행사할 통로를 둡니다.

### 정의와 핵심 원리

개인정보 보호는 처리 목적·법적근거·최소수집·정확성·안전조치·보유 기간·권리행사를생애주기로 관리하는 활동입니다. 내부 관리 계획은 이를조직 내책임·절차·점검으로 실행하는관리 기준이며 전송 요구권과자동화 결정권리는적용 조건을 확인해야합니다.

- 내부 관리에 는 책임자·취급자역할, 권한부여/변경/말소, 접근 통제, 암호화, 접속기록, 악성코드 대응, 교육, 물리보호, 위탁·사고·재난·파기등을 연결합니다. 명목문서작성보다실제이행·점검·예외·개선증거가 중요하며 규모·처리 정보별적용 조건이 다릅니다.
- 암호화는 저장·전송·단말·백업과 키 접근·분리보관·회전·복구를 함께 설계합니다. 비밀번호는 복호형저장보다 적절한 일방향KDF가 필요합니다. 법정암호화 대상·보존 기간·점검 주기는 고시 원문을 판본과 대상에 맞게확인합니다.
- 2023개정맥락의전송 요구권은개인이자신의정보를 전송하도록요구하는권리이고자동화 결정은 완전자동화·권리의무중대영향·예외·설명등의 조건을 구분합니다. 2026현행제37조의2제3항은정당사유없이필요조치를거절하지못하는대응을 규정합니다. 마이데이터는 단순 복제 서비스보다 전송 인증·권한·철회·수신처보호가 필요합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 내부 계획 | 조직 통제·책임·점검 | 실제 증빙·범위·예외 |
| 전송 요구 | 정보 주체주도이동 | 대상·수신자·보안조건 |
| 자동화 결정권리 | 거부·설명·인적개입 | 적용 요건·예외 확인 |

### 적용 예제

**AI 신용심사 문의 처리**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 고객이자동심사 결과에 설명을 요청하는가정

1. 완전자동화와 영향·처리 근거등적용 조건을 검토합니다.
2. 설명·인적재처리·이의제기담당과응답 절차를 둡니다.
3. 모델 입력·판정·주요 기준·검토 증거의 보호·보존을 정합니다.
4. 처리 결과와 고객권리행사기록을 남깁니다.

**결과·해석:** 업무 프로세스와 정보 주체 권리·안전조치를연결합니다.

**전제·주의:** 2023개정전체·데이터3법·산업별제공범위·2023마이데이터보안안내서전문은 미열람.2026고시 부칙의 단계시행을일괄현재의무로 단정하지 않습니다.

### 답안 골격과 혼동 방지

처리 흐름·주체 → 내부 계획체계 → 암호화·접근·로그 → 전송·자동화권리 → 판본·조건

- 가명정보를 개인정보 보호 법밖의자료로 보지않습니다.
- 법정권리를모든 AI결과 의무 조건거부권으로확대하지 않습니다.

### 내용을 가리고 회상

1. 내부 계획이 행을어떤증거로 확인합니까?
2. 전송 요구권과열람권은무엇이다릅니까?
3. 자동화 결정권리의적용 조건은 무엇입니까?

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.
