# 개인정보 보호 법·내부 관리 계획·마이데이터 권리

## 서브노트

### 한눈에 이해

개인정보를 수집할 때부터 파기할 때까지 누가 어떤 근거와 권한으로 처리하는지 기록합니다. 정보주체가 전송·설명·거부 등 법이 정한 권리를 행사할 절차도 마련합니다.

### 정의와 핵심 원리

개인정보를 보호하려면 수집 목적과 법적 근거를 정하고 필요한 정보만 처리합니다. 정확성, 안전조치, 보유 기간과 권리 행사도 함께 관리합니다. 내부 관리계획에는 이 원칙을 조직에서 이행할 책임, 절차와 점검 방법을 담습니다.

- 내부 관리계획에는 책임자와 취급자의 역할, 권한 부여·변경·말소, 접근 통제, 암호화, 접속 기록과 악성코드 대응을 담습니다. 교육, 물리 보호, 위탁, 사고·재난, 파기에 관한 절차도 정합니다. 실제 이행과 점검·예외·개선 기록을 남기고, 조직 규모와 처리 정보에 따라 적용 요건을 확인합니다.
- 암호화는 저장·전송·단말·백업을 대상으로 설계하고, 키 접근 권한과 분리 보관·교체·복구도 정합니다. 비밀번호는 복호화할 수 있는 형태 대신 적절한 일방향 키 유도 함수(KDF)로 저장합니다. 법정 암호화 대상과 보존 기간·점검 주기는 해당 판본과 적용 대상에 맞춰 고시 원문에서 확인합니다.
- 2023년 개정의 전송요구권은 정보주체가 자신의 정보를 전송하도록 요구할 수 있는 권리입니다. 자동화된 결정에 대해서는 완전 자동화 여부, 권리나 의무에 미치는 중대한 영향, 법적 근거와 예외를 먼저 살핍니다. 2026년 현행 「개인정보 보호법」 제37조의2 제3항은 정당한 사유가 없을 때 필요한 조치를 하도록 규정합니다. 마이데이터 서비스는 전송 인증·권한·철회 절차와 수신처의 보호조치를 함께 설계합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 내부 관리계획 | 조직 내 책임과 통제·점검 | 실제 이행 기록, 적용 범위와 예외 |
| 전송 요구 | 정보주체가 자신의 정보 전송을 요청 | 대상 정보·수신자·보안 요건 |
| 자동화된 결정 관련 권리 | 거부·설명·사람의 개입 | 적용 요건과 예외 확인 |

### 적용 예제

**AI 신용심사 문의 처리**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 고객이 자동 신용심사 결과에 관해 설명을 요청했습니다.

1. 결정이 완전히 자동화됐는지, 권리나 의무에 어떤 영향을 미치는지, 어떤 근거로 정보를 처리했는지 확인합니다.
2. 설명과 사람에 의한 재처리를 담당할 사람을 정하고, 이의 제기 접수와 응답 절차를 마련합니다.
3. 모델 입력, 판정 결과, 주요 기준과 검토 기록을 보호하고 보존할 방법을 정합니다.
4. 처리 결과와 고객이 권리를 행사한 기록을 남깁니다.

**결과·해석:** 설명 요청 접수, 적용 조건 확인, 필요한 조치, 결과 기록을 하나의 업무 흐름으로 연결합니다.

**전제·주의:** 2023년 개정 내용 전체, 데이터 3법, 산업별 제공 범위와 2023년 마이데이터 보안 안내서 전문은 확인하지 못했습니다. 2026년 고시의 부칙에서 항목별 시행 시점을 확인합니다.

### 답안 골격과 혼동 방지

처리 과정과 담당자 → 내부 관리계획 → 암호화·접근 통제·기록 → 전송과 자동화된 결정 관련 권리 → 판본과 적용 요건

- 가명정보를 처리할 때도 「개인정보 보호법」의 적용 범위를 확인합니다.
- 자동화된 결정에 대한 거부권은 법이 정한 조건과 예외를 확인합니다.

### 내용을 가리고 회상

1. 내부 관리계획을 실제로 이행했는지는 어떤 자료로 확인합니까?
2. 전송요구권과 열람권은 어떻게 다릅니까?
3. 자동화된 결정 관련 권리의 적용 요건은 무엇입니까?

### 적용 기준과 근거

명시한 출처 판본의 원리를 설명하며 제품별 구현 차이는 별도 확인합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [개인정보보호법 제37조의2 조문정보](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335635) — 국가법령정보센터; 2026-09-11시행;법률21445호; 확인 2026-11-05. 확인 범위: 공식 조문 정보에 서 3항의대응 의무와 현행판표시직접 열람.제37조의2전체 및시행령은 미열람.
