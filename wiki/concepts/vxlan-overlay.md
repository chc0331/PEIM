# VXLAN 오버레이 네트워크

## 서브노트

### 한눈에 이해

IP 네트워크 위에 가상 이더넷 망을 얹어 같은 물리망에서도 여러 입주자의 통신을 나눕니다.

### 정의와 핵심 원리

VXLAN은 이더넷 프레임을 UDP/IP로 감싸 L3 물리망(언더레이) 위에 L2 가상망(오버레이)을 만듭니다. VXLAN 터널 끝점(VTEP)은 프레임을 감싸거나 풀고, 24비트 VNI는 가상 세그먼트를 구분합니다.

- 원래 프레임에는 내부 MAC 주소와 페이로드가 있습니다. 송신 VTEP가 외부 IP·UDP·VXLAN 헤더를 붙입니다. 중간 IP 라우터는 외부 주소를 보고 전달하고, 목적지 VTEP가 내부 프레임을 복원합니다. 가상망 식별과 물리망 경로 선택은 별도 과정입니다.
- 24비트 VNI는 약 1600만 개의 식별 공간을 제공합니다. 장비가 실제로 지원하는 규모와 예약·정책은 따로 확인합니다. 브로드캐스트·미지의 유니캐스트·멀티캐스트(BUM)는 멀티캐스트나 송신 끝점의 복제로 처리할 수 있습니다. MAC 학습과 위치 전달에는 EVPN 같은 제어 기능을 결합할 수 있습니다.
- 헤더를 추가하면 최대 전송 단위(MTU), 단편화와 성능에 영향이 생깁니다. 물리망의 경로 분산·지연·장애 수렴과 가상망의 MAC·ARP 상태를 함께 관찰합니다. VNI는 가상망을 구분하는 번호이므로 별도의 접근 통제, VTEP 신뢰 관리와 관리 경로 보호가 필요합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| VLAN | 12비트 태그로 L2를 구분 | 규모와 물리 L2 범위의 제약 |
| VXLAN | 24비트 VNI로 L3 위에 L2 구성 | 캡슐화, MTU와 상태 관리 |
| 언더레이 | VTEP 사이의 IP 통신 | 오버레이 정책과 별도 |

### 적용 예제

**두 테넌트의 같은 내부 주소**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 테넌트 A와 B가 모두 내부 주소 10.0.0.1을 사용합니다. A의 VNI는 100, B는 200입니다.

1. 송신 VTEP는 프레임이 속한 가상망에 따라 VNI 100 또는 200을 붙입니다.
2. 외부 IP망은 VTEP 주소로 전달합니다. 두 가상망에서 내부 주소가 같아도 외부 전달에는 영향이 없습니다.
3. 수신 VTEP는 VNI별로 분리된 브리지 도메인에 프레임을 전달합니다.
4. 두 VNI 사이에 통신이 필요하면 게이트웨이와 허용 정책을 따로 구성합니다.

**결과·해석:** 가상망을 구분하면 같은 내부 주소를 쓰는 테넌트의 통신을 분리할 수 있습니다.

**전제·주의:** VTEP나 관리 권한이 침해될 때를 대비해 가상망 식별 외의 보안 통제도 적용합니다.

### 답안 골격과 혼동 방지

필요성 → VTEP·VNI·헤더 도식 → VLAN 비교 → 전달 사례 → MTU와 보안

- VNI 24비트는 가상 세그먼트를 구분하는 값입니다.
- VXLAN 캡슐화와 전송 암호화는 별도 기능입니다.
