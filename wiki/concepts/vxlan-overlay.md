# VXLAN 오버레이 네트워크

## 서브노트

### 한눈에 이해

IP 네트워크 위에 가상 이더넷 망을 얹어 같은 물리망에서도 여러 입주자의 통신을 나눕니다.

### 정의와 핵심 원리

VXLAN은 Ethernet 프레임을 UDP/IP로 캡슐화하여 L3언더레이 위에L2오버레이를 제공하는 기법입니다. VTEP는 캡슐화·역캡슐화를 담당하고 24비트VNI로 가상세그먼트를 식별합니다.

- 원래프레임에 는 내부 MAC·페이로드가있고VTEP가 외부IP·UDP·VXLAN헤더를붙입니다.중간IP라우터는외부 주소로 전달하고 목적VTEP가 내부 프레임을 복원합니다.내부테넌트식별과외부 경로 선택을 분리합니다.
- 24비트VNI는 약1600만식별공간을제공하지만실제 장비 지원 규모·예약·정책은 별개입니다.BUM트래픽처리에 는 멀티캐스트나헤드엔드복제등구현이 있고MAC 학습·위치배포에 는 EVPN같은 제어면을결합할 수 있습니다.
- 캡슐화는추가 헤더를만들어MTU·단편화·성능에 영향을 줍니다.언더레이ECMP·지연·장애수렴과오버레이의MAC/ARP상태를 함께 관측해야합니다.VNI는 격리식별자이지암호화나인증 기능이 아니므로접근 통제·VTEP신뢰·관리면보호가 필요합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| VLAN | 12비트태그의L2구분 | 규모·물리L2범위제약 |
| VXLAN | 24비트VNI·L2overL3 | 캡슐화·MTU·상태 관리 |
| 언더레이 | VTEP간IP도 달성 | 오버레이정책과 별도 |

### 적용 예제

**두 테넌트의 같은 내부 주소**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 테넌트A와B가 모두10.0.0.1사용;VNI100/200

1. VTEP가 각프레임에 VNI100또는200을 부여합니다.
2. 외부IP망은VTEP주소로 전달하며 내부 주소 중복에 영향받지않습니다.
3. 수신VTEP는VNI별분리된브리지도메인으로전달합니다.
4. 다른 VNI로 통신하려면명시적게이트웨이·정책을 사용합니다.

**결과·해석:** 주소 공간중복을 테넌트문맥으로분리할 수 있습니다.

**전제·주의:** 식별자분리만 으로악성VTEP나관리 권한 침해를 방어할 수 없습니다.

### 답안 골격과 혼동 방지

필요성 → VTEP·VNI·헤더도식 → VLAN비교 → 전달 사례 → MTU·보안

- 24비트VNI를 24비트IP주소라쓰지않습니다.
- VXLAN자체가암호화라고하지 않습니다.
