# 양자키분배 QKD와 양자내성암호 PQC

## 서브노트

### 한눈에 이해

빛의 양자 상태로 키를 나누는 장치와, 양자컴퓨터에도 견디도록 설계한 고전 암호 알고리즘을 구분합니다.

### 정의와 핵심 원리

QKD는 양자채널의측정·교란특성을 활용하여 비밀키를 분배하고 고전인증채널의후처리로 키를 확정하는기술입니다. PQC는 고전컴퓨터에서실행하면 서양자공격에 대한내성을목표로 설계한키 설정·서명등암호 알고리즘입니다.

- QKD는 일반적으로양자상태 전송 → 기저등정보교환·sifting → 오류율추정 → 정보정합 → 프라이버시증폭의흐름으로 설명합니다. 도청은오류 통계에 나타날수 있지만인증없는 고전채널의중간자·장치부채널·구현결함·서비스거부는별도 문제입니다.
- QKD는 광장치·거리·손실·키 생성률·신뢰중계·위성경로와 환경 조건을 고려합니다. 분배된키로 데이터를 보호하는 대칭암호도 필요합니다. 도감청이 원천적으로어떤형태로도불가능한 완전체 계라는표현은부적절합니다.
- NISTFIPS203은 격자문제 기반ML-KEM을 표준화했으며512/768/1024파라미터를 제공합니다. KEM은 공유비밀을설정하고 본문암호는 별도 입니다. PQC도 파라미터·구현·부채널·업데이트와 인증서·프로토콜전환이필요합니다. 전환은자산·알고리즘 목록과 수명·민감기간에 서 시작합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| QKD | 양자물리·키분배 | 장치·광경로·인증고전채널 |
| PQC | 고전수학암호·키 설정/서명 | 소프트웨어·프로토콜전환 |
| 공통 | 키 관리·구현 안전성 | 인증·운영·검증필요 |

### 적용 예제

**장기 기밀문서 보호 전환**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 오래기밀유지할문서를 전송하는기관 가정

1. 현재 키교환·서명·인증서·장비를 목록화합니다.
2. 수집후미래복호 위험과 문서민감기간을 분석합니다.
3. 검증된PQC 지원과 호환성을시험하고 필요한 경우하이브리드전환을검토합니다.
4. QKD는 물리경로·운영비·인증 전제까지 별도로평가합니다.

**결과·해석:** 제품명보다위협 기간과 전환가능성으로우선순위를정합니다.

**전제·주의:** QKD원표준 전문은 미열람이며 FIPS203의ML-KEM정의·파라미터만 직접 확인했습니다.

### 답안 골격과 혼동 방지

양자위협 → 두원리도 식 → 인프라·용도비교 → 전환절차 → QKD 한계

- QKD와 PQC를 동의어로쓰지않습니다.
- ML-KEM을 데이터 암호화·전자서명알고리즘으로 쓰지않습니다.
