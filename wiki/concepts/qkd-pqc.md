# 양자키분배 QKD와 양자내성암호 PQC

## 서브노트

### 한눈에 이해

빛의 양자 상태로 키를 나누는 장치와, 양자 컴퓨터에도 견디도록 설계한 고전 암호 알고리즘을 구분합니다.

### 정의와 핵심 원리

QKD는 양자 채널에서 상태를 측정할 때 교란이 일어나는 성질을 이용해 비밀 키를 분배합니다. 인증된 고전 통신 채널에서 후처리를 거쳐 키를 확정합니다. PQC는 고전 컴퓨터에서 실행하며, 양자 공격에 견디도록 설계한 키 설정·서명 등의 암호 알고리즘입니다.

- QKD의 예에서는 양자 상태를 보내고, 기저 정보를 교환해 일치하는 결과를 추립니다. 이어 오류율을 추정하고 정보 정합과 프라이버시 증폭을 수행합니다. 도청은 오류 통계에 나타날 수 있습니다. 인증 없는 고전 채널의 중간자 공격, 장치 부채널, 구현 결함과 서비스 거부는 별도로 다룹니다.
- QKD를 적용할 때 광 장치·거리·손실·키 생성률·신뢰 중계·위성 경로 등 환경을 고려합니다. 분배된 키로 데이터를 보호하는 대칭 암호가 필요하며, 실제 구현의 도청 가능성은 장치와 통신 조건에 따라 판단합니다.
- NIST FIPS 203은 격자 문제에 기반한 ML-KEM을 표준화했습니다. 매개변수 집합은 ML-KEM-512·ML-KEM-768·ML-KEM-1024입니다. KEM으로 공유 비밀을 설정하고 별도의 대칭 암호로 본문을 보호합니다. 전환에 앞서 자산·알고리즘과 데이터의 기밀 유지 기간을 확인하고 구현의 부채널, 인증서와 프로토콜 호환성, 업데이트를 점검합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| QKD | 양자 물리로 키 분배 | 광 장치·전송 경로·인증된 고전 채널 |
| PQC | 고전 컴퓨터에서 키 설정·서명 | 소프트웨어·프로토콜 전환 |
| 공통 | 키 관리·구현 안전성 | 인증·운영·검증 |

### 적용 예제

**장기 기밀문서 보호 전환**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 오랫동안 기밀로 유지해야 할 문서를 전송하는 기관을 가정합니다.

1. 현재 사용하는 키 교환 방식, 서명, 인증서와 장비를 목록으로 정리합니다.
2. 공격자가 암호문을 지금 수집해 미래에 복호할 위험과 문서의 기밀 유지 기간을 비교합니다.
3. 검증된 PQC 지원과 호환성을 시험하고 필요한 경우 하이브리드 전환을 검토합니다.
4. QKD는 물리 경로·운영비·인증 전제까지 별도로 평가합니다.

**결과·해석:** 문서를 보호해야 하는 기간과 전환에 걸리는 시간을 비교해 우선순위를 정합니다.

**전제·주의:** FIPS 203의 ML-KEM 정의와 매개변수를 확인했습니다. QKD 원표준 전문은 확인이 남아 있습니다.

### 답안 골격과 혼동 방지

양자 위협 → QKD·PQC 원리 → 인프라와 용도 비교 → 전환 절차 → QKD 적용 한계

- QKD는 양자 상태로 키를 분배하고, PQC는 고전 컴퓨터에서 실행되는 암호 기법입니다.
- ML-KEM은 공유 비밀을 설정하는 데 사용합니다.

3. 문서의 기밀 유지 기간이 전환 우선순위에 영향을 주는 이유는 무엇입니까?
