# 버블·삽입·퀵 정렬의 원리와 수행 비교

## 서브노트

### 한눈에 이해

버블은 옆 값과 자리를 바꾸고, 삽입은 정렬된 앞부분에 새 값을 끼웁니다. 퀵은 기준값보다 작은 쪽과 큰 쪽으로 나눠 각각 다시 정렬합니다.

### 정의와 핵심 원리

정렬은 비교 기준에 맞춰 원소를 재배치하는 연산입니다. 버블·삽입은 점진적으로 정렬 영역을 만들고, 퀵은 피벗 기반 분할정복으로 정렬합니다.

- 버블 정렬은 왼쪽부터 인접 원소를 비교해 앞이 더 크면 교환합니다. 오름차순 한 패스 뒤 최댓값이 오른쪽 끝에 확정되므로 다음 비교 범위를 줄입니다. 교환이 없는 패스에서 종료하는 표식을 두면 정렬된 입력은 Θ(n)입니다.
- 삽입 정렬은 앞부분이 정렬됐다는 불변식을 유지합니다. key를 임시 보관하고 그보다 큰 앞 원소를 오른쪽으로 이동한 뒤 빈자리에 key를 넣습니다. 정렬된 입력은 n-1 비교, 역순 입력은 n(n-1)/2회 이동이 필요합니다.
- 퀵 정렬은 피벗 선정→분할→양쪽 재귀입니다. 균형 분할이면 T(n)=2T(n/2)+Θ(n)으로 Θ(n log n)이고, 매번 0 대 n-1이면 T(n)=T(n-1)+Θ(n)으로 Θ(n²)입니다. 무작위 피벗을 쓰면 평균적으로 한쪽으로 치우치는 분할을 줄일 수 있지만 최악의 시간 복잡도는 그대로입니다.
- 같은 키의 상대 순서를 보존하면 안정 정렬입니다. 버블·삽입은 큰 경우에만 교환·이동하면 안정적이고, 통상적인 제자리 퀵은 불안정합니다. 퀵의 배열 작업공간과 재귀 스택을 구분하고, 중복이 많으면 3-way 분할을 검토합니다.

### 구조·비교·판단

| 정렬 | 최선 / 평균 / 최악 시간 | 공간·적합성 |
| --- | --- | --- |
| 버블 | Θ(n) / Θ(n²) / Θ(n²) | 종료 표식 조건; O(1); 원리 단순 |
| 삽입 | Θ(n) / Θ(n²) / Θ(n²) | O(1); 작거나 거의 정렬된 입력 |
| 퀵 | Θ(n log n) / 기대 Θ(n log n) / Θ(n²) | 서로 다른 키의 일반 2방향 분할 기준. 재귀 스택 기대 O(log n), 최악 O(n) |

### 적용 예제

**[5,3,4,1]의 정렬 과정**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 오름차순, 버블은 왼쪽부터 비교하고 삽입은 앞부분을 확장합니다. 퀵은 분할 원리만 표시합니다.

1. 버블 패스: [3,4,1,5]→[3,1,4,5]→[1,3,4,5]. 비교 범위를 3·2·1로 줄이면 6회 비교, 실제 교환은 5회입니다.
2. 삽입: 3 삽입 [3,5,4,1]→4 삽입 [3,4,5,1]→1 삽입 [1,3,4,5]. 큰 원소 이동은 1+1+3=5회입니다.
3. 퀵에서 피벗 4로 나누면 [3,1] | 4 | [5]입니다. 왼쪽에서 피벗 3으로 [1] | 3을 얻어 합치면 [1,3,4,5]입니다.

**결과·해석:** 같은 결과라도 비교·교환·이동·분할 비용이 다릅니다. 입력 2배에서 이차 비용은 약 4배로 증가합니다.

**전제·주의:** 퀵의 중간 배열·비교 횟수는 피벗·분할 구현에 따라 달라집니다. 이 예시는 특정 Hoare/Lomuto 코드의 동일 추적이라고 주장하지 않습니다.

### 답안 골격과 혼동 방지

정렬 정의·기준 → 각 알고리즘의 불변식·절차 → 동일 입력 단계별 도식 → 시간·공간·안정성 비교 → 입력 특성별 선택·개선

- 종료 표식 없는 버블에 최선 Θ(n)을 무조건 적용하지 않습니다.
- 퀵 정렬의 기대 O(n log n)을 최악 보장 또는 항상 가장 빠르다는 뜻으로 쓰지 않습니다.
