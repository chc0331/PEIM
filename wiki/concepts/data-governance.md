# 데이터 거버넌스

## 서브노트

### 정의

데이터 거버넌스는 데이터를 전략 자산으로 활용하기 위해 의사결정권, 책임, 정책, 표준, 품질, 생명주기 통제를 정하는 체계다. 공공 데이터 관리에서는 관리체계·메타데이터·연계·공동활용과 책임관 체계가 제도적으로 다뤄진다.

### 핵심 구조·도식

`정책·원칙 → 데이터 오너/책임관 → 표준·메타데이터 → 품질·보안·생명주기 → 공유·활용·감사 → 개선`

### 답안 키워드·비교·적용

| 요소 | 답안 포인트 |
| --- | --- |
| 역할 | 오너·스튜어드·보안·현업의 책임 분리 |
| 표준 | 용어·코드·모델·메타데이터의 일관성 |
| 품질 | 기준·측정·정정·재발 방지 |
| 생명주기 | 생성·보유·공유·보존·파기 통제 |
| 활용 | 접근권한·연계·공동활용·이력 관리 |

데이터 거버넌스는 DB 운영이나 데이터 모델링보다 넓은 의사결정·책임 체계다. 공공 법령의 역할·절차를 민간 조직의 의무로 그대로 옮기지 않는다.

### 한계·리스크

데이터 오너의 권한 없이 품질 책임만 부여하면 실패한다. 전사 표준을 한 번에 강제하면 현업 저항과 우회 시스템이 생길 수 있다.

### 답안 골격

- **1교시:** 정의 → 역할·통제 도식 → 구성요소 → 데이터 관리와 차이 → 기대효과.
- **논술형:** 현황·문제 → 조직·R&R → 표준·품질·보안 정책 → 플랫폼·공유 → 성과·개선.

### 회상 확인

1. 데이터 오너와 데이터 스튜어드의 책임을 구분하라.
2. 데이터 품질을 통제하는 선행·결과 지표는 무엇인가?
3. 데이터 공동활용에서 품질·보안·책임을 함께 확보하는 방안은 무엇인가?
