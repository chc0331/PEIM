# GNN의 메시지 전달과 관계 기반 예측

## 서브노트

### 한눈에 이해

한 변전소의 수요는 자기 센서만이 아니라 연결된 지점의 부하와도 관련될 수 있습니다. GNN은 각 점의 특징과 주변 연결 정보를 반복 섞어 관계를 반영한 표현을 만듭니다.

### 정의와 핵심 원리

노드·엣지·그래프의 특징과 연결 구조를 이용해 표현을 학습하고 분류·회귀·연결 예측 등을 수행하는 신경망 계열입니다.

- 입력은 노드 특징 X, 인접 구조 A, 필요 시 엣지 특징·시간 정보입니다. message passing은 이웃별 메시지 생성→순서에 불변인 합/평균/attention 집계→자기 표현과 결합/갱신을 반복합니다. k층은 대체로 k-hop 주변 정보를 섞으므로 너무 깊으면 과도한 평활·정보 압축 문제가 생길 수 있습니다.
- GCN은 대표적으로 H^(l+1)=σ(D̃^(−1/2)ÃD̃^(−1/2)H^lW^l), Ã=A+I로 자기 연결을 포함합니다. GNN 전체를 GCN 하나와 동일시하지 않고 GAT의 이웃 가중·GraphSAGE의 표본/집계 등 변형은 목표와 규모에 따라 선택합니다.
- VPP 수요예측은 노드=발전/저장/부하 지점, 엣지=전력망 또는 검증된 상관 관계, 노드특징=과거수요·기온·SOC로 구성할 수 있습니다. 시간 모델과 결합해 공간·시간 의존을 학습하되 임의 상관 엣지를 물리 인과로 해석하지 않습니다. 새로운 노드·그래프 변화·시간 누출·집계 비용을 검증합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| MLP | 각 표본 특징 중심 | 연결 구조를 별도로 넣어야 함 |
| CNN | 규칙 격자의 국소 이웃 | 영상·고정 패턴 |
| GNN | 불규칙 그래프의 이웃 집계 | 관계·차수·동적 구조 |

### 적용 예제

**이웃 평균 집계**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 노드A 특징2, 이웃B 특징4, 이웃C 특징6이며 자기 자신까지 같은 가중 평균합니다.

1. 집계값은(2+4+6)/3=4입니다.
2. 이 값에 학습 가중치와 비선형을 적용해 다음 표현을 만듭니다.
3. 실제 GCN의 대칭 차수 정규화는 이 단순 평균과 다를 수 있으므로 예제와 정식 모델을 구분합니다.

**결과·해석:** 연결과 특징이 함께 표현을 바꾸는 원리를 작은 그래프로 설명할 수 있습니다.

**전제·주의:** 같은 이웃 multiset이면 집계가 같도록 설계하는 이유는 노드 나열 순서가 의미를 바꾸면 안 되기 때문입니다.

### 답안 골격과 혼동 방지

정의·노드/엣지/X/A → 메시지→집계→갱신 → GCN 식·자기 연결 → VPP 예시 → 과평활·규모·해석 한계

- 관계가 있다는 사실만으로 인과를 확정하지 않습니다.
- 단순 평균 예제를 GCN 정규화 식의 정확 계산이라고 쓰지 않습니다.

### 내용을 가리고 회상

1. 노드 번호 순서를 바꾸어도 결과가 일관되어야 하는 이유는 무엇입니까?
2. k층의 수용 범위는 무엇과 관련됩니까?
3. VPP 엣지는 어떤 근거로 정의하겠습니까?

### 적용 기준과 근거

GCN 원 논문 초록의 그래프 구조·노드 특징 표현 학습을 확인했습니다. 수식·GAT/GraphSAGE 상세는 논문 본문 추가 확인 대상이며 VPP는 강사 설계입니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [Semi-Supervised Classification with Graph Convolutional Networks](https://arxiv.org/html/1609.02907v4) — Thomas N. Kipf, Max Welling; 2017-02-22 v4, ICLR 2017; 확인 2026-11-05. 확인 범위: 실제 열람: 저자 초록과 HTML 본문의 GCN 국소 연결·노드 속성 표현, 표3의 전파식 D^(-1/2)(A+I)D^(-1/2)HW. VPP 적용은 강사 설계이며 GAT/GraphSAGE 상세 원 연구는 별도 확인 범위입니다.
