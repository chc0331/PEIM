# 정보화전략계획(ISP)

## 서브노트

### 정의

ISP는 경영·업무 목표에서 출발해 정보화 비전, 목표 아키텍처, 과제, 투자 우선순위와 이행계획을 정렬하는 중장기 계획이다. 산출물 자체보다 합의된 투자 의사결정과 실행 로드맵을 만드는 과정에 가치가 있다.

### 핵심 구조·도식

`환경·현황 분석 → 업무·정보화 요구 → 목표모델·전략 → 과제·우선순위 → 이행계획·성과관리`

### 답안 키워드·비교·적용

| 관점 | 점검 질문 |
| --- | --- |
| 업무 | 어떤 고객·현업 성과를 바꾸는가? |
| 정보·데이터 | 어떤 데이터를 표준화·공유하는가? |
| 응용·기술 | 어떤 시스템·플랫폼을 전환하는가? |
| 투자 | 편익·위험·의존성을 반영했는가? |
| 변화관리 | 소유자·교육·전환 계획이 있는가? |

EA는 정보자원을 일관되게 기술·관리하는 구조이고, ISP는 그 구조를 포함해 전략과 투자 로드맵을 결정한다.

### 한계·리스크

현황 조사만 길고 사업 의사결정이 없으면 보고서로 끝난다. 기술 유행을 목표로 삼거나 예산·조달·인력 제약을 누락하면 실행 가능성이 낮아진다.

### 답안 골격

- **1교시:** 정의 → 수립 절차 → 주요 산출물 → EA와 비교 → 성공 요건.
- **논술형:** 경영 목표 → 현황·갭 분석 → 과제 포트폴리오 → 투자·전환 로드맵 → KPI·거버넌스.

### 회상 확인

1. ISP의 과제 우선순위를 정하는 기준 세 가지는 무엇인가?
2. ISP와 EA의 목적·산출물·시간 관점을 비교하라.
3. ISP가 실행계획으로 이어지지 않는 원인과 보완책은 무엇인가?
