# 인공신경망·순전파·역전파·활성화

## 서브노트

### 한눈에 이해

신경망은 입력을 가중합하고 비선형 함수를 거치는 작은 계산을 여러 층 연결한 것입니다. 순전파로 답과 손실을 만들고 역전파로 어느 가중치가 손실을 얼마나 바꾸는지 계산합니다.

### 정의와 핵심 원리

가중치·편향·활성화로 구성된 층을 조합하여 함수 관계와 표현을 학습하는 모델이며 딥러닝은 여러 층의 표현 학습을 이용하는 기계학습 계열입니다.

- 뉴런은 z=Wx+b, a=φ(z)를 계산하며 입력층·은닉층·출력층이 합성됩니다. feedforward network는 입력에서 출력으로 순환 없이 흐릅니다. 손실함수는 예측 목표와 연결하고 데이터·모델·손실·optimizer를 구분합니다. 모든 기계학습이 신경망인 것은 아닙니다.
- 순전파에서 층별 중간값과 손실을 계산합니다. 역전파에서는 연쇄 법칙(chain rule)으로 미분을 재사용해 가중치가 손실에 미치는 영향 ∂L/∂W를 구합니다. SGD나 Adam 같은 최적화 알고리즘(optimizer)이 이 값으로 가중치를 갱신합니다.
- Sigmoid는0~1·포화, tanh는−1~1·포화, ReLU는 max(0,z)·음수 미분0, softmax는 여러 logit을 합1인 값으로 변환합니다. 비선형이 없으면 여러 선형층이 한 선형변환과 같아집니다. 소실/폭주 gradient·죽은 ReLU·초기화·정규화·과적합과 학습/검증 차이를 점검합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 전통 ML | 선형/나무/SVM 등 다양한 모델 | 특징 설계·자료규모별 선택 |
| 딥러닝 | 다층 표현 학습 | 자료·연산·해석 비용 |
| 순전파/역전파 | 예측·손실/gradient 산출 | 가중치 갱신은 optimizer |

### 적용 예제

**한 뉴런의 학습**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** x=2, y=10, w=3이며 b=0은 고정합니다. L=(wx−y)²/2, η=0.1입니다.

1. 예측값은 6, 오차는 −4, 손실은 8입니다.
2. ∂L/∂w=(wx−y)x=−4×2=−8입니다.
3. 가중치는 w_new=3−0.1×(−8)=3.8입니다. 다시 계산하면 예측값은 7.6, 손실은 (−2.4)²/2=2.88입니다.

**결과·해석:** 오차→기울기→갱신→손실 감소를 각 단계로 재현할 수 있습니다.

**전제·주의:** 교육용 선형 뉴런 예제이며 비선형 다층 문제에서 매 단계 손실 감소가 무조건 보장되지는 않습니다.

### 답안 골격과 혼동 방지

ANN 정의·구성·역할 → ML/DL 비교 → 순전파→손실→역전파→갱신 → 활성화 표 → 수치 예제·학습 한계

- 역전파를 정답을 뒤에서 전달하는 과정으로만 암기하지 않습니다.
- softmax 값이 자동으로 잘 보정된 확률이라고 단정하지 않습니다.
