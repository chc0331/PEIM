# NFC와 MODBUS·산업제어 보안

## 서브노트

### 한눈에 이해

근접 태그 통신과 산업 제어 통신은 사용 환경이 다르지만, 연결됐다는 사실만으로 신뢰해서는 안 됩니다.

### 정의와 핵심 원리

NFC는 13.56 MHz 기반의 근접 비접촉 통신으로 태그의 전력 공급·데이터 교환을 지원합니다. MODBUS는 장치 간 기능 코드와 데이터 모델로 읽기·쓰기 요청을 주고받는 산업용 응용 프로토콜입니다. 두 개념은 통신 기출의 독립 소단원으로 묶었습니다.

- NFC에는 리더·라이터와 카드 에뮬레이션 등의 사용 형태가 있습니다. NDEF는 공통 메시지 형식입니다. 유도 결합으로 수동 태그에 전력을 전달할 수 있습니다. 도청·릴레이·악성 태그·분실 기기의 위험도 남습니다.
- Modbus 데이터 모델은 코일(coil), 이산 입력(discrete input), 입력 레지스터(input register), 홀딩 레지스터(holding register)를 구분합니다. RTU와 TCP의 전송 형식이 달라도 읽기·쓰기 기능은 기능 코드로 설명합니다. 주소 표기·엔디언·레지스터 조합은 장비 명세를 확인합니다.
- 평문 통신과 내부망 신뢰를 전제로 만든 산업망에는 추가 보호가 필요합니다. 자산과 통신 흐름을 파악한 뒤 구역과 통로를 나누고, 필요한 기능 코드와 출발지만 허용합니다. 원격 접속을 인증하고 변경을 관리합니다. ISA/IEC 62443은 산업 제어 시스템의 역할·생애주기·구역과 통로를 다루며, 세부 요구는 해당 판본을 확인합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| NFC | 근접·태그·유도 전력 | 릴레이·위조 태그·사용자 고지 |
| MODBUS | 기능 코드·레지스터 | 평문·쓰기 권한·장비 특성 |
| 산업보안 | 구역·통로·생애주기 | 가용성·안전성·변경 위험 |

### 적용 예제

**공장 계측값 조회**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** MES에는 온도 레지스터 읽기만 필요합니다. 제어용 쓰기는 PLC만 할 수 있습니다.

1. 장비별 레지스터 맵과 통신 필요성을 기록합니다.
2. 조회 서버에서 읽기 기능만 허용하고 제어 쓰기를 차단합니다.
3. 원격 유지 보수는 승인·시간 제한·기록을 적용합니다.
4. 패치·차단 변경은 공정 안전에 미치는 영향을 검증 후 적용합니다.

**결과·해석:** 업무 최소 권한과 산업 가용성을 같이 확보합니다.

**전제·주의:** Modbus 공식 문서 목록을 확인했습니다. 기능 코드 원문과 ISA/IEC 62443 전문은 확인이 남아 있습니다.

### 답안 골격과 혼동 방지

NFC 원리와 위험 → Modbus 데이터와 요청 흐름 → ISA/IEC 62443의 범위 → 안전한 접근 통제 예

- 근거리라서 인증이 불필요하다고 쓰지 않습니다.
- IT 보안 스캔을 무조건 가동 중 PLC에 적용하지 않습니다.
