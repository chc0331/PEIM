# NFC와 MODBUS·산업제어 보안

## 서브노트

### 한눈에 이해

근접 태그 통신과 산업 제어 통신은 사용 환경이 다르지만, 연결됐다는 사실만으로 신뢰해서는 안 됩니다.

### 정의와 핵심 원리

NFC는 13.56MHz기반의 근접비접촉통신으로 태그의전력공급·데이터교환을지원합니다. MODBUS는 장치간기능 코드와 데이터 모델로 읽기·쓰기 요청을 주고받는산업용응용 프로토콜입니다. 두개념은 통신기출의독립소단원으로묶었습니다.

- NFC는 리더/라이터·카드에뮬레이션등의 이용형태가있고NDEF는 공통메시지표현입니다.유도결합으로수동태그에도전력을 전달할 수 있습니다.짧은거리라는특성이 도청·릴레이·악성태그·분실기기 위험을 제거하지는않습니다.
- MODBUS 데이터 모델은 coil·discreteinput·inputregister·holdingregister등을 구분합니다.RTU등직렬방식과 TCP 방식의 전달형식이달라도응용 기능의 역할은구분하여 설명합니다.주소 표현·엔디언·레지스터조합은장비명세를따릅니다.
- 전통산업망은평문·신뢰망전제를 보완해야합니다.자산·통신 흐름식별 → 구역과통로 분리 → 필요기능 코드·출발지허용 → 원격접속인증 → 수동모니터링·변경 관리순으로설계합니다.ISA/IEC62443은 산업 자동화제어보안의역할·생애주기·구역과통로등을 다루는 표준군이며 세부조항은 판본별확인합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| NFC | 근접·태그·유도전력 | 릴레이·위조태그·사용자 고지 |
| MODBUS | 기능 코드·레지스터 | 평문·쓰기 권한·장비 특성 |
| 산업보안 | 구역·통로·생애주기 | 가용성·안전성·변경 위험 |

### 적용 예제

**공장 계측값 조회**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** MES는 온도레지스터조회만필요;제어쓰기는 PLC만허용

1. 장비별레지스터맵과통신필요성을기록합니다.
2. 조회서버에 서 읽기 기능만 허용하고 제어쓰기를 차단합니다.
3. 원격유지보수는승인·시간제한·기록을 적용합니다.
4. 패치·차단 변경은 공정안전에 미치는영향을 검증후적용합니다.

**결과·해석:** 업무최소 권한과 산업 가용성을 같이확보합니다.

**전제·주의:** MODBUS 공식 목록은 열람했으나기능 코드 원문과 ISA62443전문은 미열람입니다.

### 답안 골격과 혼동 방지

각통신정의 → NFC 동작·위험 → MODBUS 데이터·흐름 → 62443범위 → 안전한 통제예

- 근거리라서인증이 불필요하다고쓰지않습니다.
- IT보안스캔을무조건가 동중PLC에적용하지 않습니다.
