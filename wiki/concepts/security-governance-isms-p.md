# 정보보호 거버넌스와 ISMS-P

## 서브노트

### 정의

정보보호 거버넌스는 사업 목표·위험·법규 요구에 맞춰 보안 의사결정, 책임, 투자, 성과를 지시·감시하는 체계다. ISMS-P는 정보보호와 개인정보보호를 위한 일련의 조치·활동이 공개 인증기준에 적합함을 인증하는 국내 제도다.

### 핵심 구조·도식

`경영진·CISO → 정책·조직·자산 → 위험관리 → 보호대책 → 사고·복구 → 점검·개선`

### 답안 키워드·비교·적용

| 요소 | 답안 포인트 |
| --- | --- |
| 관리체계 | 기반 마련·위험관리·운영·점검·개선 |
| 보호대책 | 인적·물리·기술·운영 보안의 균형 |
| 개인정보 | 수집·보유·이용·제공·파기 단계 통제 |
| 사고 대응 | 탐지·분석·격리·복구·복기 |
| 증적 | 정책·로그·점검·교육·개선 이력 |

정보보호 거버넌스는 조직의 통제 체계이고, ISMS-P는 국내 인증기준을 적용하는 제도다. 인증 취득 여부와 실제 위험 감소를 동일시하지 않는다.

### 한계·리스크

심사 시점의 문서만 갖추면 운영 실효성이 낮다. 기술 통제만 강화하고 자산 분류·권한·교육·협력사 관리를 빠뜨리면 우회 경로가 생긴다.

### 답안 골격

- **1교시:** 정의 → 거버넌스 흐름 → ISMS-P 구성 → 보호대책·개인정보 구분 → 기대효과.
- **논술형:** 자산·위험 진단 → 조직·정책 → 보호대책·개인정보 통제 → 사고·복구 → 점검·개선·증적.

### 회상 확인

1. 정보보호 거버넌스와 ISMS-P 제도의 관계를 설명하라.
2. 위험관리 결과가 보호대책으로 연결되는 과정을 말하라.
3. 인증 준비가 실효성 없는 문서 작업이 되는 것을 막을 방법은 무엇인가?
