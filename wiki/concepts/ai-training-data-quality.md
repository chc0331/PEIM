# AI 학습데이터 생애주기·품질·어노테이션

## 서브노트

### 한눈에 이해

이미지가 많아도 밤 장면이 빠져 있거나 사람의 경계를 잘못 표시하면 야간 탐지 성능이 낮을 수 있습니다. 파일 형식, 라벨의 정확성, 실제 과업에서의 성능을 각각 확인합니다.

### 정의와 핵심 원리

AI 과업에 필요한 원천 자료·정제 자료·라벨·데이터셋의 적합성과 구축 과정을 전 생애 주기에 걸쳐 측정·보증·개선하는 활동입니다.

- 학습 데이터는 모델의 목적에 맞아야 합니다. 필요한 환경과 사례를 얼마나 잘 대표하는지, 원본과 라벨을 추적할 수 있는지 살핍니다. 계획부터 수집·정제·라벨링·검수·공개·운영까지 관리하고, 학습·검증·시험을 나눌 때 같은 사람·장소·시간대의 중복으로 정보가 새지 않도록 합니다.
- 품질은 사례의 다양성과 분포, 구문(스키마·자료형·범위), 라벨의 의미 정확성(클래스·경계), 모델의 실제 과업 성능으로 나누어 봅니다. 과업과 버전별로 지표 이름·계산식·분모·허용치·표본 추출 방법을 정합니다. 중복과 손상 자료는 따로 처리하고 검수 책임도 정합니다.
- 이미지는 classification·bounding box·polygon/segmentation·keypoint, 음성은 전사/화자/구간, 텍스트는 개체/관계/감정 등 방식이 있습니다. 라벨 지침·gold set·이중 라벨·전문가 조정·버전 이력을 두고 오류를 원천 단계까지 환류합니다. NIA v1.0의 실제 확인 내용과 128회 지정 v2.0의 미열람 세부는 구분합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| 구문 | JSON 구조·자료형·범위 | 자동 검사 가능 범위 큼 |

### 적용 예제

**보행자 박스 라벨 검수**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 이미지 100장에 실제 보행자 120명이 있습니다. 라벨 상자 110개 중 100개가 정해 둔 클래스와 위치 기준을 충족하며, 실제 보행자와 하나씩 대응합니다.

1. 교집합을 합집합으로 나눈 값(IoU)의 기준을 적용합니다. 올바르게 대응한 상자는 TP 100개, 잘못 대응한 상자는 FP 10개, 놓친 보행자는 FN 20명입니다.
2. 정밀도는 100/110≈90.91%, 재현율은 100/120≈83.33%입니다.
3. 밤/비/가림 집단별 누락을 따로 보고 라벨 지침 수정·재검수 후 holdout 모델 성능을 확인합니다.

**결과·해석:** 형식 통과와 의미 정확성·대표성·모델 유효성을 별개로 측정합니다.

**전제·주의:** 지표 임계값은 예제 가정이며 모든 AI 데이터의 공식 합격 기준이 아닙니다.

### 답안 골격과 혼동 방지

정의·특성 → 생애주기·원칙 → 품질 모델·지표·분모 → 수집/정제/라벨 방식 → 검수·학습·피드백

- 라벨을 붙인 작업자들의 일치도가 높아도 모두 같은 잘못된 지침을 따를 수 있습니다.
- v1.0 항목을 지정 v2.0과 대조 없이 동일 목록으로 외우지 않습니다.

### 내용을 가리고 회상

1. 구문과 의미 정확성의 검사는 어떻게 다릅니까?
2. 원천자료·라벨·가공 이력을 어떻게 연결합니까?
3. 정확한 라벨만 있는데 특정 환경 성능이 나쁜 이유는 무엇입니까?
