# Mirai·IoT·드론·NFT·메타버스 보안

## 서브노트

### 한눈에 이해

기기가 인터넷에 연결되고 가상세계가 실물 권리와 결합하면 계정·펌웨어·센서·거래의 신뢰 경로가 넓어집니다.

### 정의와 핵심 원리

Mirai는 기본 자격증명등취약한IoT 장치를 감염시켜DDoS 자원으로 활용한봇넷악성코드 사례입니다. IoT보안은설계부터 폐기까지 기기·연결·플랫폼·데이터를 보호하며 드론·가상플랫폼은 고유한물리·사회 위험을 추가 합니다.

- IoT는 고유 신원·안전한 초기설정·최소서비스·서명업데이트·지원 기간·비밀보호·취약점 대응·안전 폐기를 설계합니다. 기본 암호 변경과 원격관리제한·패치·망분리·이상송신탐지가 Mirai류위험을 줄입니다. 재부팅만으로재감염조건까지 제거되지는않습니다.
- 드론은명령링크가로채기·GNSS기만·센서교란·펌웨어변조·촬영정보 유출·분실위험이 있어명령인증·무결성·센서교차검증·업데이트서명·비상동작을 결합합니다. 암호화가 전파방해나위치기만을단독해결하지 않습니다.
- NFT마켓은피싱서명·과다토큰 승인·스마트계약·웹프론트·보관키를 보호합니다. NFT식별이저작권소유를자동증명하지 않습니다. 메타버스는아바타사칭·괴롭힘·생체/행동추적·미성년자보호·디지털격차를신고·차단·동의·최소수집·권리구제와연결합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| IoT | 기기·계정·업데이트 | 생애주기·지원 종료 |
| 드론 | 통신·위치·물리안전 | 안전 상태·다중센서 |
| NFT/메타버스 | 키·서명·플랫폼·사용자 | 거래권한·권리·피해 구제 |

### 적용 예제

**기본 암호 카메라의 봇넷 감염**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 외부 노출카메라에기본 계정잔존가정

1. 장비를 격리하고 관리 접근·펌웨어·설정을 점검합니다.
2. 고유한자격증명과 필요한 연결만 허용합니다.
3. 지원 종료 제품은 대체·격리정책을 정합니다.
4. 비정상외부접속·송신량을감시하고 복구후재감염을확인합니다.

**결과·해석:** 기술조치와제품 지원·운영 책임을 수명 주기에 연결합니다.

**전제·주의:** IoT 공통보안7대원칙 원문과 OpenSea특정 사건원자료는 미열람.위일반 통제를 해당7원칙·사건확인으로 대체하지 않습니다.

### 답안 골격과 혼동 방지

Mirai사례 → 수명 주기 위협·통제 → 드론물리위험 → NFT서명권한 → 가상공간사회 대응

- NFT원본성 표시를완전한법적권리로쓰지않습니다.
- IoT재부팅을근본원인 제거로판단하지 않습니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.
