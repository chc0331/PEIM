# 다자간 안전 계산 MPC와 임계 인증

## 서브노트

### 한눈에 이해

서로 입력을 공개하지 않고 합의한 결과만 계산하거나, 한 장치가 전체 서명키를 갖지 않게 나눠 보관합니다.

### 정의와 핵심 원리

MPC는 여러 참여자가 각자의입력을 비공개로 유지하며 정해진 함수를 공동 계산하는프로토콜군입니다. 보안은정확성·입력 기밀성·허용누출과 공모·악의성·통신·가용성 가정에 따라 정의합니다.

- 대표구성은비밀분산, 가블드회로, OT, 동형암호 기반등입니다. 비밀분산은 한값을 여러 share로나눠일정수준이모여야복원하게하며 단순가산분산과임계분산의복원 조건은 다릅니다. MPC는 분산저장만 하는것이아니라share상태의 안전한 연산과 검증을 포함합니다.
- semi-honest는 규칙은 따르되관측으로추론하는상대, malicious는 임의로행동하는상대를가정합니다. 정직다수·비동기·참여자탈락·결과 공개 범위에 따라 비용과 보장이바뀝니다. 결과가 소집단의 민감값을 드러내는위험은 입력 암호화만 으로없어지지않습니다.
- 임계인증은 개인키를 분산한여러 주체가 부분연산을 통해 표준서명을만들도록할 수 있습니다. NIST다자임계암호프로젝트는서명·복호·키 생성등의 분산 신뢰를 다룹니다. 정책 승인·share갱신·백업·공모 한계·감사를함께 설계합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 비밀분산 | 입력을 share로분할 | 그자체가전체 MPC는 아님 |
| 안전 계산 | share·회로등으로공동연산 | 공모·악의모델명시 |
| 임계서명 | 키전체 복원없이공동서명 | 승인·가용성·복구 |

### 적용 예제

**가산분산 합계의 장난감 예**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** mod 101에서 A의 입력은 7, B의 입력은 9입니다. 두 서버는 공모하지 않는다고 가정합니다.

1. 각 입력 x마다 r을 0~100에서 독립적으로 균등 무작위 선택하고 (r, (x-r) mod 101)을 만듭니다. 첫 share는 서버1에, 둘째 share는 서버2에 비공개로 전달합니다. 아래 20과 30은 이번 예시에서 선택된 난수이며 고정·재사용하는 값이 아닙니다.
2. A는7을20과88로분산합니다:20+88=108≡7.
3. B는9를30과80으로분산합니다:30+80=110≡9.
4. 서버1합50, 서버2합168≡67입니다.
5. 50+67=117≡16으로7+9의합계가복원됩니다.

**결과·해석:** 개별share와 합계결과의 관계를 모듈러계산으로 확인합니다.

**전제·주의:** 이예는합계만의교육예시이며 악의서버·인증·공모·중단을처리하는완성프로토콜이 아닙니다.

### 답안 골격과 혼동 방지

정의·보안모델 → 기술 종류 → 분산합예 → 임계인증 → 성능·공모 한계

- MPC를 모든 참여자가 데이터를 합쳐암호화하는방식으로 쓰지않습니다.
- 결과 누출을 무시하지 않습니다.
