# 다자간 안전 계산 MPC와 임계 인증

## 서브노트

### 한눈에 이해

서로 입력을 공개하지 않고 합의한 결과만 계산하거나, 한 장치가 전체 서명키를 갖지 않게 나눠 보관합니다.

### 정의와 핵심 원리

MPC는 여러 참여자가 각자의 입력을 비공개로 유지하며 정해진 함수를 공동 계산하는 프로토콜군입니다. 보안은 정확성·입력 기밀성·허용 누출과 공모·악의성·통신·가용성 가정에 따라 정의합니다.

- 비밀 분산, 가블드 회로, 망각 전송(OT), 동형암호 등을 사용합니다. 비밀 분산은 값을 여러 몫(share)으로 나누고 필요한 수가 모였을 때 복원합니다. 단순 가산 분산과 임계 분산은 복원 조건이 다릅니다. MPC는 분산된 몫으로 안전하게 연산하고 결과를 검증하는 데 쓰입니다.
- 준정직(semi-honest) 모델은 프로토콜을 따르면서 관찰한 정보로 입력을 추정하는 상대를 가정합니다. 악의적(malicious) 모델에서는 상대가 임의로 행동할 수 있습니다. 정직한 참여자의 비율, 비동기 통신, 참여자 이탈과 결과 공개 범위에 따라 비용과 보장이 달라집니다. 입력을 보호하더라도 작은 집단의 결과로 개인 값을 추정할 가능성은 남습니다.
- 임계 인증에는 개인 키를 나눠 가진 여러 주체가 부분 연산으로 표준 서명을 만드는 방식이 있습니다. NIST 다자 임계 암호 프로젝트는 서명·복호·키 생성의 신뢰를 나누는 방법을 다룹니다. 승인 정책과 몫 갱신·백업, 공모 한계와 감사도 설계합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 비밀 분산 | 입력을 share로 분할 | 그 자체가 전체 MPC는 아님 |
| 안전 계산 | share·회로 등으로 공동 연산 | 공모·악의 모델 명시 |
| 임계 서명 | 키 전체 복원 없이 공동 서명 | 승인·가용성·복구 |

### 적용 예제

**가산분산 합계의 장난감 예**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** mod 101에서 A의 입력은 7, B의 입력은 9입니다. 두 서버는 공모하지 않는다고 가정합니다.

1. 각 입력 x마다 r을 0~100에서 독립적으로 균등 무작위 선택하고 (r, (x-r) mod 101)을 만듭니다. 첫 share는 서버1에, 둘째 share는 서버2에 비공개로 전달합니다. 아래 20과 30은 이번 예시에서 선택된 난수이며 고정·재사용하는 값이 아닙니다.
2. A는 7을 20과 88로 나눕니다. 20 + 88 = 108이고, 101로 나눈 나머지는 7입니다.
3. B는 9를 30과 80으로 나눕니다. 30 + 80 = 110이고, 101로 나눈 나머지는 9입니다.
4. 서버 1의 합은 50, 서버 2의 합은 168 ≡ 67입니다.
5. 50 + 67 = 117 ≡ 16으로 7 + 9의 합계가 복원됩니다.

**결과·해석:** 개별 share와 합계 결과의 관계를 모듈러 계산으로 확인합니다.

**전제·주의:** 이 예는 합계만의 교육 예시이며 악의 서버·인증·공모·중단을 처리하는 완성 프로토콜이 아닙니다.

### 답안 골격과 혼동 방지

정의·보안 모델 → 기술 종류 → 분산 합 예 → 임계 인증 → 성능·공모 한계

- MPC를 모든 참여자가 데이터를 합쳐 암호화하는 방식으로 쓰지 않습니다.
- 결과 누출을 무시하지 않습니다.

### 내용을 가리고 회상

1. 두 서버가 공모한다고 가정하면 각자의 입력이 보호되는 조건은 어떻게 달라집니까?
2. 값을 나눠 저장하는 비밀 분산과 나눈 값으로 계산하는 MPC는 어떻게 다릅니까?
3. 임계 인증의 키 복구·가용성 위험은 무엇입니까?
