# IT 거버넌스

## 서브노트

### 정의

조직 목적과 이해관계자 요구에 맞게 현재·미래 IT 사용을 **평가·지시·감시**하는 조직 거버넌스의 한 영역이다. IT 운영을 직접 수행하는 관리와 달리, 의사결정 권한·책임·성과의 방향과 통제를 다룬다.

### 핵심 구조·도식

`이사회·경영진 → Evaluate(평가) → Direct(지시) → Monitor(감시) → 경영진·IT 조직의 실행·보고`

### 답안 키워드·비교·적용

| 키워드 | 답안 포인트 |
| --- | --- |
| 전략 정렬 | 사업 목적과 IT 투자·우선순위를 연결 |
| 가치·성과 | KPI·편익 실현을 감시 |
| 위험·준수 | 보안·법규·감사 요구를 통제 |
| 책임성 | 의사결정권자와 보고 체계 명확화 |
| 자원 | 인력·예산·정보자산의 배분 감시 |

관리(계획·구축·운영)는 거버넌스가 정한 방향과 한도 안에서 실행한다. 적용 전에는 조직의 의사결정권, 성과지표, 위험 허용 수준을 함께 정한다.

### 한계·리스크

위원회·문서만 늘리고 실제 권한이 없으면 형식화된다. 과도한 중앙 통제는 현업의 민첩성을 저해할 수 있어 위임 범위와 보고 주기를 설계해야 한다.

### 답안 골격

- **1교시:** 정의 → 평가·지시·감시 도식 → 핵심 원칙 → 관리와 차이 → 기대효과.
- **논술형:** 경영 이슈 → 의사결정 구조·R&R → 성과·위험 지표 → 운영·개선 방안.

### 회상 확인

1. IT 거버넌스와 IT 관리의 책임 범위는 어떻게 다른가?
2. IT 투자 안건을 감시할 지표 세 가지를 제시하라.
3. 분권 조직에서 거버넌스를 형식화하지 않을 장치는 무엇인가?
