# UI와 UX 설계 기초

## 한눈에 이해

사용자가 일을 마치는 과정에 불편이 있으면 화면을 꾸미는 것만으로 해결하기 어렵습니다. **사용자 경험(UX)**은 과업을 수행하면서 겪는 경험을, **사용자 인터페이스(UI)**는 그 과정에서 조작하는 화면과 요소를 가리킵니다.

### 원리와 답안 흐름

먼저 사용자가 하려는 일과 막히는 지점을 조사합니다. 필요한 정보를 묶고 이름을 붙인 뒤, 사용자가 어느 화면에서 다음 행동을 할지 정합니다. 간단한 시제품으로 과업을 시켜 보고, 걸린 시간이나 실패 지점에 따라 화면과 흐름을 고칩니다.

답안에는 **사용자·과업 → 정보 구조와 화면 흐름 → 관찰 결과와 개선**을 연결합니다.

### 적용 예제

교육용 예입니다. 도서 대출 연장 화면에서 사용자가 반납일을 찾지 못한다고 가정합니다. 내 대출 목록에 반납일과 연장 가능 여부를 함께 표시하는 시제품을 만들고, 사용자에게 특정 책의 연장 가능 여부를 확인해 달라고 요청합니다. 완료 여부와 어디서 망설였는지 기록한 뒤 정보 위치와 버튼 설명을 조정합니다.

### 회상과 답안 확인

- 버튼 색을 바꾸기 전에 어떤 정보를 확인하겠습니까?
- 사용자 과업, 막힌 위치, 시제품에서 관찰할 행동을 연결하면 됩니다.
