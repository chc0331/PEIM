# ECB·CBC·CFB·OFB 블록 암호 모드

## 서브노트

### 한눈에 이해

같은 블록 암호도 이전 암호문이나 키스트림을 연결하는 방법에 따라 패턴노출·오류전파·병렬성이 달라집니다.

### 정의와 핵심 원리

운영 모드는 고정 크기블록 암호를 여러 블록메시지에적용하는방법입니다. SP800-38A의ECB/CBC/CFB/OFB는 기밀성 모드이며 변조검출을단독제공하지 않으므로무결성 보호를 별도로결합해야합니다.

- ECB는C_i=E_K(P_i)로같은 평문 블록이 같은 암호문이 되어 패턴이노출됩니다.CBC는C_i=E_K(P_i XOR C_(i-1)), C_0=IV이며 암호화는 연쇄의존하고 복호 블록 연산은 병렬화가능합니다. 패딩과예측불가능한 IV등규격 조건이 중요합니다.
- CFB는 이전암호문또는IV를 암호화한출력과 평문을 XOR합니다. OFB는 이전암호기출력을 반복암호화하여 평문과 독립적인 키스트림을 만듭니다. 두 방식은 암호기의정방향연산을 활용하나상태피드백대상·오류전파·동기성이다릅니다.
- OFB의동일키·IV재사용은같은 키스트림을 반복하여 C XOR C′=P XOR P′를노출합니다.CBC의IV·CFB세그먼트크기·패딩규칙을 생략하지 않습니다. 현대프로토콜의 AEAD는 암호화와 태그를결합하며 nonce규칙위반에도주의합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| ECB | 블록독립 | 패턴노출;일반 메시지부적합 |
| CBC | 이전암호문XOR | IV·패딩·오류반응 |
| CFB | 암호문피드백 | 세그먼트·동기·전파 |
| OFB | 출력피드백키스트림 | 키/IV재사용금지 |

### 적용 예제

**OFB 재사용의 XOR 누출**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 한바이트장난감예:P=0x12, P′=0x34, 키스트림0xAA재사용

1. C=0x12 XOR0xAA=0xB8입니다.
2. C′=0x34 XOR0xAA=0x9E입니다.
3. C XOR C′=0x26이며 P XOR P′도0x26입니다.
4. 평문하나를알면다른 평문을 복구할 수 있어같은 키스트림재사용이위험합니다.

**결과·해석:** 모드운용조건의 실패가알고리즘강도와별개로정보를 노출합니다.

**전제·주의:** 한바이트예는XOR원리 설명이며 실제 AES의 블록 크기는 128비트입니다.
