# ECB·CBC·CFB·OFB 블록 암호 모드

## 서브노트

### 한눈에 이해

같은 블록 암호도 이전 암호문이나 키스트림을 연결하는 방법에 따라 패턴 노출·오류 전파·병렬 처리 가능 여부가 달라집니다.

### 정의와 핵심 원리

운영 모드는 고정 크기 블록 암호를 여러 블록으로 된 메시지에 적용하는 방법입니다. NIST SP 800-38A의 ECB·CBC·CFB·OFB는 기밀성 모드입니다. 변조까지 검출하려면 별도로 무결성을 보호해야 합니다.

- ECB는 `C_i = E_K(P_i)`로 같은 평문 블록을 같은 암호문으로 바꿔 반복 패턴이 드러납니다. CBC는 `C_i = E_K(P_i XOR C_(i-1))`, `C_0 = IV`입니다. 암호화는 앞 블록의 결과가 필요하지만 복호의 블록 연산은 병렬화할 수 있습니다. 패딩과 예측 불가능한 IV 등 해당 규격의 조건을 확인합니다.
- CFB는 직전 암호문이나 초기화 벡터(IV)를 암호화한 출력과 평문을 XOR합니다. OFB는 앞서 만든 암호기의 출력을 다시 암호화해 평문과 독립적인 키스트림을 만듭니다. 두 방식 모두 암호기의 정방향 연산을 사용하며 피드백 대상, 오류 전파와 동기 방식이 다릅니다.
- OFB에서 같은 키와 IV를 재사용하면 같은 키스트림이 반복되어 `C XOR C′ = P XOR P′` 관계가 드러납니다. CBC의 IV, CFB의 세그먼트 크기와 해당 패딩 규칙을 확인합니다. 인증 암호(AEAD)는 암호화와 태그를 결합하며 정해진 nonce 사용 규칙을 따라야 합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| ECB | 블록별 독립 처리 | 반복 패턴이 드러나므로 일반 메시지에 부적합 |
| CBC | 이전 암호문과 XOR | IV·패딩·오류 처리 조건 확인 |
| CFB | 암호문 피드백 | 세그먼트 크기·동기·오류 전파 |
| OFB | 출력 피드백 키스트림 | 키/IV 재사용 금지 |

### 적용 예제

**OFB 재사용의 XOR 누출**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 한 바이트 예에서 평문 `P = 0x12`, `P′ = 0x34`에 키스트림 `0xAA`를 재사용합니다.

1. `C = 0x12 XOR 0xAA = 0xB8`입니다.
2. `C′ = 0x34 XOR 0xAA = 0x9E`입니다.
3. `C XOR C′ = 0x26`이고 `P XOR P′`도 `0x26`입니다.
4. 평문 하나를 알면 다른 평문을 복구할 수 있어 같은 키스트림 재사용이 위험합니다.

**결과·해석:** 강한 블록 암호를 사용해도 키스트림을 재사용하면 평문 사이의 관계가 드러납니다.

**전제·주의:** 한 바이트는 XOR 원리를 설명하기 위한 예입니다. AES의 블록 크기는 128비트입니다.

### 답안 골격과 혼동 방지

모드가 필요한 이유 → 네 모드의 식과 도식 → IV·패딩·병렬성 비교 → 재사용 계산 → AEAD

- 기밀성 모드로 변조까지 확인하려면 별도의 무결성 보호가 필요합니다.
- OFB 피드백을 암호문이라고 그리지 않습니다.
