# 딥페이크의 생성·평가·탐지 한계

## 서브노트

### 한눈에 이해

얼굴을 바꾸거나 입술 움직임·음성을 합성하면 실제 사람이 하지 않은 행동처럼 보일 수 있습니다. 한 프레임의 경계가 자연스러워도 시간 흐름·소리·출처까지 일관된지는 별도로 확인해야 합니다.

### 정의와 핵심 원리

학습 기반 합성·변환으로 사람의 얼굴·표정·음성 등 신원 관련 표현을 실제처럼 생성/조작하는 기술과 결과물을 가리킵니다.

- 핵심 기술에는 autoencoder 계열 얼굴 표현·재구성, GAN 생성/판별의 적대 학습, 얼굴/pose 정렬·reenactment·신경 렌더링, 음성 합성과 시각-음향 정렬 등이 있습니다. 딥페이크가 전부 GAN이거나 모든 합성영상이 타인 사칭이라는 뜻은 아닙니다.
- 조작 유형은 신원 교체(face swap), 표정/행동 재연(reenactment), 전체 생성, 음성/입술 합성 등으로 구분할 수 있습니다. 생성 품질은 공간·시간 일관성과 신원/표정 보존을, 탐지는 원본/조작·압축·재촬영·새 생성기에서의 일반화와 오탐/미탐을 평가합니다.
- 문제는 허위정보·신원 오용·동의 없는 사용·증거 신뢰 훼손이며 대응은 탐지·원본 출처/이력·표시·검토 절차를 결합해야 합니다. FaceForensics++는 여러 조작기와 압축 조건의 benchmark 사례이지 모든 새 생성물을 식별하는 보장이 아닙니다. 특정 감지 흔적 하나나 모델 score만으로 진위를 확정하지 않습니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·주의 |
| --- | --- | --- |
| Face swap | 신원 표현 교체 | 얼굴 정렬·경계·시간 일관성 |
| Reenactment | 표정·pose/행동 재현 | 원 신원·동작 구분 |
| 탐지·출처 | 조작 징후/생성 이력 검증 | 압축·새 모델·오탐 한계 |

### 적용 예제

**영상 감지기의 일반화 시험**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 생성기A 자료로 학습한 감지기를 생성기B와 재촬영 영상에 적용합니다.

1. 동일 사람·원본 clip이 train/test에 섞이지 않도록 분리합니다.
2. 새 생성기·압축률·해상도·음성 불일치 조건에서 FPR/TPR와 보정·집단별 오류를 봅니다.
3. 검출 결과와 원본 출처·편집 이력을 함께 검토하며 미탐 가능성과 확인 한계를 기록합니다.

**결과·해석:** 표본 내부 정확도와 새로운 조작에 대한 신뢰를 구분할 수 있습니다.

**전제·주의:** 국내 법적 책임·구제·플랫폼 의무의 세부는 해당 현행 원문을 별도 확인해야 합니다.

### 답안 골격과 혼동 방지

정의·허용/오용 문맥 → 기술·유형 → 생성/탐지 평가 → 문제·다층 대응 → 일반화·출처·한계

- 눈 깜빡임 같은 낡은 단일 징후를 확정 판별법으로 쓰지 않습니다.
- 감지 score가0/1의 진실 확률이라고 단정하지 않습니다.

### 내용을 가리고 회상

1. 신원 교체와 표정 재연은 무엇이 다릅니까?
2. train/test의 동일 원본 clip 혼입은 왜 문제입니까?
3. 탐지와 출처 확인을 함께 해야 하는 이유는 무엇입니까?

### 적용 기준과 근거

GAN 원 연구·FaceForensics++ 조작/탐지 범위를 실제 확인. 음성/신경 렌더링 원 논문과 현행 법/플랫폼 의무는 별도 검증 범위입니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [Generative Adversarial Networks](https://arxiv.org/abs/1406.2661) — Ian J. Goodfellow 외; 2014-06-10 v1; 확인 2026-11-05. 확인 범위: 실제 열람: 생성기G·판별기D의 적대적 두 모형 학습·minimax와 gradient 학습. 모든 딥페이크가 GAN이라는 주장의 근거는 아닙니다.
- [FaceForensics++: Learning to Detect Manipulated Facial Images](https://arxiv.org/abs/1901.08971) — Andreas Rössler 외; 2019-08-26 v3, ICCV 2019; 확인 2026-11-05. 확인 범위: 실제 열람: DeepFakes/Face2Face/FaceSwap/NeuralTextures 조작 유형·압축 조건별 탐지 benchmark·hidden test. 당시 실험 정확도를 최신 모든 딥페이크의 검출 보장으로 옮기지 않습니다.
- [Auto-Encoding Variational Bayes](https://arxiv.org/abs/1312.6114) — Diederik P. Kingma, Max Welling; 2013 원 논문; 2022-12-10 v11; 확인 2026-11-05. 확인 범위: 실제 열람: 연속 잠재변수·approximate posterior·reparameterization·variational lower bound 요약. ELBO의 재구성/KL 분해는 원 이론을 교육용으로 설명합니다.
