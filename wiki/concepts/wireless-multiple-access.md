# CSMA/CA·TDMA·CDMA·NOMA

## 서브노트

### 한눈에 이해

여러 단말이 같은 전파 자원을 나눠 쓰는 방식은 기다리기, 시간 나누기, 코드 나누기, 겹쳐 보내고 분리하기로 구분할 수 있습니다.

### 정의와 핵심 원리

다중접속은 제한된 무선매체를 여러 사용자가 공유하는 규칙입니다. CSMA/CA는 경쟁접근과 회피를, TDMA는 시간슬롯을, CDMA는 확산코드를, NOMA는 비직교중첩과 수신분리를 활용하는 접근입니다.

- CSMA/CA는 매체감지후대기·무작위백오프를수행하고 ACK로성공을확인합니다.무선송신중충돌검출이어려우므로충돌 회피를 사용하지만충돌이 0이라는 보장은없습니다.RTS/CTS는 숨은단말 문제를 완화하는선택 기법이며 오버헤드가 있습니다.
- TDMA는 시간슬롯과동기·가드시간이 필요합니다.CDMA는 사용자별확산코드와 상관검출로분리하며 코드직교성·전력제어·near-far문제가 중요합니다.시간·주파수·코드 자원은 실제 시스템에 서 결합될수 있습니다.
- 전력 영역 NOMA예에서는서로 다른 전력으로 신호를중첩하고 SIC로강한간섭을 순차소거합니다.다른 NOMA유형도있으므로SIC하나로전체를정의하지 않습니다.채널추정오차·소거오류전파·단말 복잡도와 공정성에 따라 이득이달라집니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| CSMA/CA | 감지·백오프·ACK | 유동접속;충돌·변동지연 |
| TDMA | 슬롯분할 | 동기·가드시간·유휴낭비 |
| CDMA | 확산코드 | 전력제어·코드상관 |
| NOMA | 비직교중첩·분리 | SIC복잡도·채널추정 |

### 적용 예제

**동일 슬롯의 전력 중첩**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 기지국이근거리·원거리단말에 동시송신;교육용개념

1. 원거리단말에 상대적으로큰전력을 배정합니다.
2. 근거리단말은 먼저 큰전력성분을복호하고 소거한뒤자기신호를복호합니다.
3. 원거리단말은 다른성분을간섭으로 보고 복호합니다.
4. 채널상태·전력할당·오류율을함께 평가합니다.

**결과·해석:** 직교자원 분할과 비직교간섭 처리의 차이를설명합니다.

**전제·주의:** CSMA/CA·CDMA·NOMA의 원표준 전문은 이번조사에서미확인입니다.이론개요이며 특정5G·6G필수규격으로 단정하지 않습니다.

### 답안 골격과 혼동 방지

자원공유문제 → 네방식도 식 → 비교표 → 숨은단말·SIC사례 → 절충

- CSMA/CA를 충돌검출이라쓰지않습니다.
- NOMA를 6G최종필수규격이라 확정하지 않습니다.
