# 차분 프라이버시와 프라이버시 예산

## 서브노트

### 한눈에 이해

한 사람의 포함 여부가 발표 결과를 크게 바꾸지 않게 만들어 참여자의 추가 노출을 제한합니다.

### 정의와 핵심 원리

차분프라이버시는 한개인의기록이 차이나는인접데이터셋에 서 확률적알고리즘의 출력 분포가 가깝도록제한하는보호정의입니다. ε는구별가능성의한계를 조절하며(ε, δ)-DP는 추가 실패허용항δ를가집니다.

- 순수ε-DP는 모든 출력사건S에대해Pr[M(D)∈S]<=exp(ε)Pr[M(D′)∈S]를요구합니다. ε가작을수록강한보호가 될수 있지만유용성과 절충됩니다. ε를실제 재식별확률로 번역하거나출력오차율과같다고하면 안됩니다.
- 질의민감도는 한기록 변경이 결과에 미치는최대차이입니다. Laplace기법은 일반적으로척도Δf/ε의잡음을추가 합니다. 합계에서는개인값 범위를 clipping하지 않으면민감도가 무한정커질수 있어범위·인접성정의가필수입니다.
- 반복질의는 정보를 누적하므로 프라이버시 회계와예산관리가 필요합니다. 순차합성의기본 상한은ε들의합이며 사후처리는 추가 정보 접근이 없으면 보호를 악화시키지않습니다. 중앙형은신뢰집계자가원자료를 보고, 로컬형은각단말이 출력전섭동하여 신뢰·정확도 조건이 다릅니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 중앙DP | 원자료를 신뢰집계자가처리 | 신뢰·접근 통제필요 |
| 로컬DP | 각단말에 서 섭동 | 강한원자료분산·오차증가 |
| 출력 관리 | 예산·민감도·반복질의 | 회계와유용성 검증 |

### 적용 예제

**인원수 질의의 잡음 척도**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 포함/미포함인접성;개인당1기록;count민감도1

1. ε=0.5이면 Laplace척도b=1/0.5=2입니다.
2. 이는항상 정확히2만큼더한다는뜻이아니라확률 분포척도입니다.
3. 같은 대상에ε0.5질의를세번하면 기본순차상한은 1.5입니다.
4. 필요정확도·표본수·발표 정책에 맞춰예산을배분합니다.

**결과·해석:** 수학적보호정의와실제 확률오차·질의 운영을 분리합니다.

**전제·주의:** 예제는단순 count와 기본합성조건입니다.임의의 학습 알고리즘을 그대로DP라부를수 없습니다.

### 답안 골격과 혼동 방지

인접성·정의식 → ε·δ의미 → 민감도·Laplace → 합성·회계 → 신뢰 모델

- ε를익명성보장퍼센트로쓰지않습니다.
- 노이즈를넣었다는이유만으로DP라하지 않습니다.
