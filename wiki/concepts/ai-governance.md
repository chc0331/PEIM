# AI 거버넌스

## 서브노트

### 정의

AI 거버넌스는 AI의 기획·개발·도입·운영·중단 전 생명주기에서 책임성, 안전성, 공정성, 투명성, 보안·개인정보 위험을 관리하는 의사결정·통제 체계다. NIST AI RMF 1.0은 Govern, Map, Measure, Manage 기능으로 AI 위험관리 활동을 설명한다.

### 핵심 구조·도식

`Govern(전 영역) ⟲ Map(맥락·위험 식별) → Measure(평가·추적) → Manage(우선순위·대응) → 개선`

### 답안 키워드·비교·적용

| 요소 | 답안 포인트 |
| --- | --- |
| Govern | 정책·역할·책임·문서화·문화 |
| Map | 사용 목적·이해관계자·영향·위험 식별 |
| Measure | 성능·편향·안전성·보안·불확실성 평가 |
| Manage | 위험 우선순위·대응·중단·사고 소통 |
| 생명주기 | 데이터·모델·프롬프트·변경·운영 모니터링 |

AI 거버넌스는 일반 IT 거버넌스의 대체물이 아니라 AI 특유의 데이터·모델·사회기술적 위험을 추가로 다룬다. 프레임워크는 자발적 참고 기준이므로 산업·법규·서비스 영향에 맞게 적용한다.

### 한계·리스크

단일 정확도 지표만 보면 편향·오남용·설명 가능성 위험을 놓친다. 문서화만 하고 배포 후 모니터링·중단 권한이 없으면 통제가 작동하지 않는다. NIST AI RMF는 개정 중이므로 버전을 답안에 명시한다.

### 답안 골격

- **1교시:** 정의 → G-M-M-M 도식 → 핵심 통제 → IT 거버넌스와 관계 → 유의사항.
- **논술형:** AI 사용 사례·영향 → 역할·위험 식별 → 측정·검증 → 대응·모니터링·중단 → 감사·개선.

### 회상 확인

1. Govern·Map·Measure·Manage의 역할을 각각 말하라.
2. AI 모델 성능 외에 관리해야 할 위험은 무엇인가?
3. 고위험 AI 서비스의 배포 중단 기준을 어떻게 설계할 것인가?
