# AI 메타모픽·뉴런 커버리지·안전 반경 테스트

## 서브노트

### 한눈에 이해

정답 하나를 알기 어려우면 입력을 바꿨을 때 출력 사이에 성립해야 할 관계를 시험할 수 있습니다.

### 정의와 핵심 원리

메타모픽 테스트는 원본·후속 입력과 출력 사이의 필수 관계로 오류를 찾는 기법입니다. 뉴런 커버리지는 시험 입력이 활성화한 신경망 내부 뉴런 범위를, 안전 반경은 정한 거리 안 변화에서 예측·안전속성이 유지되는 범위를 다룹니다.

- 오라클 문제는 특정 입력의 올바른 출력을 얻거나 판정하기 어렵다는 뜻입니다. 메타모픽 관계(MR)는 예컨대 정렬 입력의 순서를 바꿔도 정렬 결과가 같아야 한다는 관계입니다. 학습 시스템은 의미를 보존하는 변환이 라벨을 보존하는지 도메인 근거를 먼저 검토해야 합니다.
- 절차는 대상 속성·관계 정의→원본 입력 선정과 실행→변환으로 후속 입력 생성→후속 실행→출력 관계 검증→위반 원인 분석입니다. MR 위반은 결함 후보이며 관계 자체의 오류·부동소수 오차·확률적 출력도 점검합니다.
- 뉴런 커버리지는 정해진 활성화 임계값을 넘은 뉴런 수/대상 뉴런 수로 정의할 수 있습니다. DeepXplore는 다중 모델의 차등 출력과 커버리지 목표를 결합해 입력을 찾았습니다. 뉴런 활성화가 높다는 사실은 의미 있는 동작이나 강건성의 충분조건은 아닙니다.
- 안전 반경 관점은 입력 x 주변 ||δ||≤ε에서 허용 속성이 유지되는지 탐색·최적화·검증하는 것입니다. 반례를 찾으면 범위를 줄이거나 학습을 보완합니다. 경험적 적대적 탐색의 실패와 형식적 검증의 보장을 구분하고 거리·모델·입력 제약을 명시합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 전통 오라클 시험 | 입력별 기대 출력과 비교 | 정답이 있는 기능에 직접적 |
| 메타모픽 | 변환 전후 필수 관계 확인 | 정답 개별 생성 부담 완화 |
| 뉴런/안전반경 | 내부 실행 범위 / 지역 강건성 | 커버리지 지표와 보장 범위를 구분 |

### 적용 예제

**강사 창작 적용 예시: 교통표지 인식의 밝기 변환**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 표지 내용과 가시성이 유지되는 약한 밝기 조절을 가정합니다.

1. 원본과 변환 이미지의 클래스가 같아야 한다는 MR을 정합니다.
2. 밝기 범위를 제한하고 결과·신뢰도·활성 뉴런을 기록합니다.
3. 라벨이 달라지는 반례를 찾으면 실제 의미 변화인지 모델 결함인지 검토합니다.

**결과·해석:** 오라클 문제·관계·커버리지·강건성의 역할을 구분할 수 있습니다.

**전제·주의:** 과도한 어두움·가림은 의미 보존 가정이 깨지므로 무조건 같은 라벨을 요구하지 않습니다.

### 답안 골격과 혼동 방지

오라클 문제와 등장 배경 → MR·절차·전통시험 비교 → 뉴런 커버리지·안전반경 원리와 한계

- 메타모픽 관계를 근거 없이 정하면 정상 동작을 결함으로 오인합니다.
- 안전 반경 최대화라는 기출 용어의 특정 국내 가이드 출전은 추가 확인 필요합니다.

### 내용을 가리고 회상

1. 정렬 함수의 MR을 하나 더 만드십시오.
2. 뉴런100%가 안전100%가 아닌 이유는 무엇입니까?
3. 반례 탐색과 형식적 지역 강건성 보장의 차이는 무엇입니까?

### 적용 기준과 근거

각 원 논문은 확인했습니다. 135회 안전 반경 최대화의 정확한 출전·번역과 국내 가이드 절차는 추가 대조가 필요합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [Metamorphic Testing: A New Approach for Generating Next Test Cases](https://www.cse.ust.hk/faculty/scc/publ/CS98-01-metamorphictesting.pdf) — T. Y. Chen, S. C. Cheung, S. M. Yiu; 1998; 확인 2026-11-05. 확인 범위: HKUST-CS98-01 원 논문 공개 PDF 열람. 변환 전후 관계에 의한 오류 탐지 근거입니다.
- [DeepXplore: Automated Whitebox Testing of Deep Learning Systems](https://arxiv.org/abs/1705.06640) — Kexin Pei, Yinzhi Cao, Junfeng Yang, Suman Jana; 2017; 확인 2026-11-05. 확인 범위: 본문 또는 해당 절을 실제 열람했습니다. 자체 요약만 저장하며 외부 원문 전체는 보관하지 않습니다.
- [DeepSafe: A Data-driven Approach for Checking Adversarial Robustness in Neural Networks](https://arxiv.org/abs/1710.00486) — Divya Gopinath, Guy Katz, Corina Pasareanu, Clark Barrett; 2017; 확인 2026-11-05. 확인 범위: 원 논문 초록 열람. 기출의 안전 반경 최대화라는 번역이 이 특정 논문만을 지칭한다고 확정하지 않습니다.
