# 클라우드 컴퓨팅

## 서브노트

### 정의

클라우드 컴퓨팅은 공유된 구성 가능 컴퓨팅 자원 풀에 편리한 온디맨드 네트워크 접근을 제공하고, 적은 관리 노력으로 신속하게 자원을 할당·회수하는 모델이다. NIST는 5가지 필수 특성, 3가지 서비스 모델, 4가지 배치 모델로 설명한다.

### 핵심 구조·도식

`SaaS(응용 사용) ← PaaS(응용 배포) ← IaaS(처리·저장·네트워크) ← 물리 자원`

### 답안 키워드·비교·적용

| 모델 | 소비자 통제 범위 | 적합한 경우 |
| --- | --- | --- |
| SaaS | 설정·데이터 일부 | 표준 업무를 빠르게 도입 |
| PaaS | 애플리케이션·데이터 | 개발·배포 생산성 향상 |
| IaaS | OS·미들웨어·응용 | 인프라 구성 유연성 필요 |

필수 특성은 온디맨드 셀프서비스, 광범위한 네트워크 접근, 자원 공유, 신속한 탄력성, 측정 서비스다. 도입 시 업무 중요도·데이터 분류·성능·가용성·비용·종속성으로 워크로드를 분류한다.

### 한계·리스크

사용량 기반 비용은 통제 없으면 증가한다. 책임공유 모델을 명확히 하지 않으면 계정·구성·데이터 보호 책임이 누락되며, 이식성·계약·장애 대응도 검토해야 한다.

### 답안 골격

- **1교시:** 정의 → IaaS/PaaS/SaaS 도식·표 → 5대 특성 → 장점·유의사항.
- **논술형:** 워크로드 분류 → 목표 아키텍처 → 보안·운영·비용 통제 → 전환 계획 → KPI·복구 전략.

### 회상 확인

1. IaaS·PaaS·SaaS의 통제 범위를 비교하라.
2. 클라우드의 5가지 필수 특성을 말하라.
3. 기업의 클라우드 전환에서 비용·보안·종속성을 통제하는 방법은 무엇인가?
