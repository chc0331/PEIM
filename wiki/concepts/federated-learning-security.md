# 연합학습·FedAvg와 프라이버시 보완

## 서브노트

### 한눈에 이해

원자료는 각 장치에 남기고 모델의 변경값만 모읍니다. 변경값에서도 학습에 사용한 정보가 드러날 수 있어 별도의 보호가 필요합니다.

### 정의와 핵심 원리

연합학습은 여러 클라이언트가 각자 보유한 데이터로 모델을 학습한 뒤, 변경값을 모아 공유 모델을 개선하는 방식입니다. FedAvg는 참여한 클라이언트의 모델 값을 표본 수에 따라 가중 평균합니다.

- 서버가 초기 모델과 참여자를 정합니다. 모델 배포 → 각 클라이언트에서 학습 → 변경값 전송 → 집계의 과정을 반복합니다. 원자료를 중앙으로 옮기는 부담이 줄지만, 서버와 클라이언트를 어디까지 신뢰할지와 업무상 처리 근거는 확인해야 합니다.
- 데이터 분포가 서로 다르거나(Non-IID) 표본 수가 고르지 않으면 수렴과 공정성이 달라질 수 있습니다. 장치 성능, 통신 비용, 연결이 끊기거나 응답이 늦는 장치도 영향을 줍니다. FedSGD는 기울기를 자주 집계합니다. FedAvg는 각 장치가 여러 번 갱신한 모델을 평균해 통신 횟수를 줄일 수 있습니다. FedProx 등 변형은 각 원문에서 목적과 동작을 확인합니다.
- 변경값에서 기울기를 역추정하거나, 특정 표본이 학습 데이터에 포함됐는지 추정하는 멤버십 추론(membership inference)이 가능합니다. 악성 클라이언트가 백도어를 심을 수도 있습니다. 안전한 집계(secure aggregation)는 개별 변경값의 노출을 줄이고, 차분 프라이버시(DP)는 출력에 대한 한 사람의 영향을 제한합니다. 동형암호(HE)와 다자간 계산(MPC)은 계산의 기밀성을 높이는 데 쓰입니다. 클라이언트 인증, 강건한 집계와 감사도 함께 검토합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 중앙 학습 | 원자료를 한곳에 모아 학습 | 데이터 이동과 접근 권한 |
| FedAvg | 각 장치에서 학습한 뒤 가중 평균 | 데이터 분포 차이, 통신과 참여자 이탈 |
| 보호 기술 | 안전한 집계·DP·HE·MPC | 정확도·공모·성능의 장단점 |

### 적용 예제

**데이터 수에 따른 가중 평균**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** A에는 표본 100개가 있고 학습한 모델의 값은 2입니다. B에는 표본 300개가 있고 모델의 값은 4입니다. 모델 값이 하나인 예제입니다.

1. 전체 표본은 400입니다.
2. 표본 수를 가중치로 쓴 집계값은 (100 × 2 + 300 × 4) / 400 = 3.5입니다.
3. 클라이언트별 값에 같은 비중을 주면 (2 + 4) / 2 = 3입니다.
4. 표본의 불균형이나 악성 변경값이 집계 결과를 얼마나 바꾸는지 평가합니다.

**결과·해석:** 표본이 많은 B가 집계값에 더 큰 영향을 줍니다. 이 계산만으로 기밀성·강건성·공정성을 판단할 수는 없습니다.

**전제·주의:** 가중 평균의 원리를 설명하는 예제입니다. 가중치와 참여 정책은 알고리즘마다 다를 수 있습니다.

### 답안 골격과 혼동 방지

학습 라운드의 흐름 → 알고리즘 비교 → 데이터 분포와 통신 → 정보 유출과 오염 → 보호 기술

- 원자료를 보내지 않아도 모델 변경값에서 정보가 드러날 수 있습니다.
- 변경값을 암호화해 집계해도 악성 입력을 막는 검증은 필요합니다.

### 내용을 가리고 회상

1. FedAvg에서 표본 수를 가중치로 쓰는 이유는 무엇입니까?
2. 원자료를 보내지 않아도 모델 변경값에서 무엇을 추론할 수 있습니까?
3. 안전한 집계와 차분 프라이버시는 각각 어떤 위험을 줄입니까?
