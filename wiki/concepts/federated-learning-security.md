# 연합학습·FedAvg와 프라이버시 보완

## 서브노트

### 한눈에 이해

원자료를 현장에 남기고 모델 갱신을 모으지만, 갱신값 자체에 남은 정보를 별도로 보호합니다.

### 정의와 핵심 원리

연합학습은 여러 클라이언트가 로컬 데이터로 모델을 학습하고 업데이트를 집계하여 공유모델을 개선하는방식입니다. FedAvg는 클라이언트의 로컬학습 결과를 데이터 양등으로가중평균하는대표 알고리즘입니다.

- 서버가 초기모델·참여자를 선택하고 모델 배포 → 로컬최적화 → 업데이트업로드 → 집계 → 다음라운드를 반복합니다. 데이터를 중앙에직접 수집하지 않아전송·거버넌스부담을줄일수 있지만서버와 클라이언트의 신뢰·업무 근거는 여전히필요합니다.
- Non-IID데이터·불균등표본·시스템 성능·연결단절·통신 비용·straggler가 수렴과공정성에 영향을 줍니다. FedSGD는 기울기를빈번히집계하고 FedAvg는 여러로컬업데이트후평균하여 통신을 줄일수 있습니다. FedProx등변형의목적과 원문은 별도 확인합니다.
- 업데이트로 부터기울기역추정·회원추론이 가능하고 오염 클라이언트가 백도어를주입할 수 있습니다. secure aggregation은 개별업데이트관측을줄이고DP는 출력의 개인영향을 제한하며 HE/MPC는 계산 기밀성을 돕습니다. 클라이언트 인증·강건 집계·감사·검증과 결합합니다.

### 구조·비교·판단

| 구분 | 핵심 원리 | 적용·한계 |
| --- | --- | --- |
| 중앙학습 | 원자료중앙집중 | 데이터 이동·권한 |
| FedAvg | 로컬학습후가중집계 | Non-IID·통신·이탈 |
| 보호 기술 | SecureAgg·DP·HE/MPC | 정확도·공모·성능 절충 |

### 적용 예제

**데이터 수에 따른 가중 평균**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** A표본100/가중치2, B표본300/가중치4;단일스칼라모델예

1. 전체 표본은 400입니다.
2. 집계값=(100×2+300×4)/400=3.5입니다.
3. 클라이언트단순 평균3과 다름을확인합니다.
4. 비균등데이터·악성업데이트에 의한집계왜곡을평가합니다.

**결과·해석:** 가중규칙을 명시하고 기밀성·강건성·공정성을 별도로검토합니다.

**전제·주의:** 예제는원리 검산이며 모든 알고리즘이 같은가중치·참여정책을 사용하는 것은아닙니다.

### 답안 골격과 혼동 방지

라운드도 식 → 알고리즘비교 → Non-IID·통신 → 누출·오염 위협 → 보완기술

- 원자료 미전송을 완전한프라이버시보장으로쓰지않습니다.
- 암호화집계가악성입력까지 정상화한다고하지 않습니다.
