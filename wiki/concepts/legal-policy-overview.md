# 정보통신 법규와 정책 확인 기초

## 한눈에 이해

법규 문제를 읽을 때는 먼저 무엇을 다루는지 나눕니다. 개인정보 처리라면 개인정보 보호법, 공공 소프트웨어 사업이라면 소프트웨어 진흥법과 관련 하위 규정을 우선 찾아볼 수 있습니다. 사업이 두 영역에 걸치면 각각 확인해야 합니다.

### 원리와 답안 흐름

문제에 나온 행위와 주체를 적고, 국가법령정보센터에서 법령명·시행일·조문을 확인합니다. 과거 기출의 기준일과 현재 적용 기준이 다르면 각각의 연혁을 찾아 비교합니다. 법률, 시행령·시행규칙, 행정규칙이나 정책 자료는 유형과 근거를 따로 적습니다. 적용 여부가 불명확하면 어떤 사실이나 조문이 더 필요한지 명시합니다.

| 사진에서 읽은 범주 | 원문에서 확인할 질문 |
| --- | --- |
| 전자정부 | 어떤 기관의 어떤 행정서비스나 정보 공동 이용에 관한 규정인가요? |
| 개인정보 | 누가 어떤 목적으로 개인에 관한 정보를 처리하나요? |
| 소프트웨어 | 사업의 발주·수행·검수 중 어느 단계의 요구인가요? |
| 데이터 | 데이터의 개방·공유·활용 중 어떤 행위와 주체가 대상인가요? |
| 지식재산 | 무엇을 사용·수정·배포하며 어떤 권리나 허락을 확인해야 하나요? |
| AI | 누가 어떤 AI 서비스를 개발·제공·이용하나요? |
| 클라우드 | 어떤 기관이 어떤 데이터와 업무를 어떤 서비스에 맡기나요? |

답안에는 **사례의 주체와 행위 → 자료의 유형과 기준일 → 확인할 적용 조건**을 씁니다.

### 적용 예제

교육용 예입니다. 공공기관이 민원 처리 시스템을 구축하면서 민원인의 연락처를 받으려 합니다. 사업 발주·수행에 관한 쟁점과 연락처의 수집·이용 쟁점을 나눕니다. 두 범주에서 각각 필요한 조문과 시행일을 찾아 기록합니다. 이 자료에서는 특정 계약이나 연락처 수집의 적법성을 판단하지 않습니다.

### 회상과 답안 확인

- 2026년 기출을 현재 기준으로 다시 설명할 때 어떤 원문을 각각 찾아야 하나요?
- 기출 기준일과 현재 기준일의 본문, 적용 대상, 관련 하위 규정 또는 정책 자료를 구분하면 됩니다.
