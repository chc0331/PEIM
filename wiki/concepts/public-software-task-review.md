# 공공SW 과업 확정·기간·변경 심의

## 서브노트

### 한눈에 이해

사업을 시작하기 전에 과업 범위를 정합니다. 요구가 바뀌면 비용과 일정에 어떤 영향이 있는지 심의합니다.

### 정의와 핵심 원리

과업심의는 공공 SW 사업의 내용·범위·대가·기간과 변경의 적정성을 검토하는 절차입니다. 발주자가 요구를 명확히 하고 정당한 변경의 계약 조정을 다룰 수 있도록 합니다.

- 계획/확정 단계는 목적·필요성·범위·기능과 비기능 요구·산출물·검증기준의 명확성, 예산 산정 근거·기능규모·누락 과업, 타 사업/시스템 중복·연계와 상용 SW 직접구매 적용 등을 검토합니다.
- 적정기간은 요구·규모·생산성·조직·자원·기술 난이도·연계·데이터 이관·시험·발주/협의 절차를 반영합니다. 총 개발기간에서 법정/행정 절차와 사용자 인수·안정화 시간을 누락하지 말고 근거를 문서화합니다. 특정 금액·사업 유형의 의무·간소화 요건은 현행 지침을 대조합니다.
- 변경 심의는 변경 사유·발주/사업자 책임·당초 범위와의 차이·필요성·기술 가능성, 기능/작업의 증가·감소, 일정·비용·품질·보안·기존 연계 영향, 대안과 미변경 위험을 평가합니다. 계약금액·기간 조정과 변경된 인수 기준을 함께 결정해야 합니다.
- 사업자 요청을 포함해 변경 요청서·원래/변경 과업 비교·규모/공수·일정 영향·견적과 시험 근거를 제출하고 심의·결정·계약변경·형상/추적 갱신으로 연결합니다. 단순 오류수정·하자와 추가 과업을 근거 없이 혼동하면 분쟁을 유발합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 확정 | 발주할 범위·대가·기간 | 명확성·완전성·산정 근거 |
| 변경 | 새 요구·환경 변화의 영향 | 책임·필요·추가/감소·계약 조정 |
| 인수 | 합의한 결과의 검증 | 원/변경 기준선과 증거 일치 |

### 적용 예제

**강사 창작 적용 예시: 신규 법정 보고서 추가**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 개발 중 당초 없던 월간 집계보고서가 필요해졌습니다.

1. 원 요구와 비교해 신규 기능·데이터·시험 범위를 적습니다.
2. 기간·비용·연계 영향과 대안을 평가해 과업심의를 요청합니다.
3. 승인된 금액·기간·인수 기준과 RTM을 갱신합니다.

**결과·해석:** 추가 과업의 근거, 심의 결과, 계약에 반영한 변경을 함께 확인할 수 있습니다.

**전제·주의:** 구체적 위원 구성·간소화 조건과 기한은 해당 시점 법령·고시를 확인해야 합니다.

### 답안 골격과 혼동 방지

계획 확정 검토항목 → 적정기간 산정의 요소 → 변경 적정성·계약·기준선 조정

- 모든 요구 변경을 하자로 분류하지 않습니다.
- 예산이 그대로라는 이유만으로 추가 과업의 비용이 0이 되지 않습니다.

### 내용을 가리고 회상

1. 과업 확정과 인수는 어떤 차이가 있습니까?
2. 적정기간에서 시험·이관을 별도로 확인하는 이유는 무엇입니까?
3. 변경 요청에 필요한 증거를 세 가지 말하십시오.

### 적용 기준과 근거

공공기관 공식 운영안내·지정 법 원문을 확인했습니다. 128회 당시 과업심의 가이드의 정식 평가 항목명 및 현행 고시 조문별 대조는 추가 확인이 필요합니다.

**내용 검토 상태: 부분 확인**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [소프트웨어사업 과업심의위원회](https://fund.hknu.ac.kr/icc/5447/subview.do) — 한경국립대학교; 지속 갱신 페이지; 확인 2026-11-05. 확인 범위: 공공기관의 실제 운영안내 열람. 해당 기관의 운영 범위나 내부 기준을 전국 공통 법령으로 일반화하지 않습니다.
- [소프트웨어 진흥법 [시행 2023.10.19] ](https://www.law.go.kr/LSW/lsPdfPrint.do?ancYnChk=0&bylChaChk=N&efGubun=Y&efYd=20231019&joAllCheck=Y&joEfOutPutYn=on&lsiSeq=249973&mokChaChk=N) — 국가법령정보센터 / 과학기술정보통신부; 법률 제19349호; 확인 2026-11-05. 확인 범위: 기출 지정 판본 PDF 본문 제5조·제30조 등 열람. 법령 조문은 출처를 밝히고 간추렸습니다.
- [ISP·ISMP 수립 공통가이드 제9판](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=28088&cbIdx=99835) — 기획재정부 / NIA; 2025-05-19 / 첨부 2025-12 일부개정; 확인 2026-11-05. 확인 범위: 공식 첨부 PDF 실제 열람. 본문 p.40~44 ISP/ISMP 기본 구성 및 산출물, 세부 요건 분석을 참조했습니다. 129회 지정 6판과 세부 개정 차이는 추가 대조 필요합니다.
