# SW 안전진단의 기능동작 정확성

## 서브노트

### 한눈에 이해

안전 기능이 있다는 문서만 보지 않고 위험 조건에서 실제로 올바른 반응을 하는지 증거로 확인해야 합니다.

### 정의와 핵심 원리

기능동작 정확성 진단은 안전 관련 요구가 명확하고 설계·코드·시험·실행 동작에 일관되게 반영되는지를 확인하는 안전성 검증 활동으로 설명할 수 있습니다.

- 중요한 확인 한계: 126회가 명시한 「소프트웨어 안전진단 가이드(공통분야)」 원문을 확보하지 못했습니다. 아래는 NASA·SWEBOK에 근거한 일반 안전 진단 틀이며 해당 가이드의 공식 단계명·순서로 제시하지 않습니다.
- 준비에서는 대상 기능·운영환경·진단 경계·안전 중요도·자료·도구·판정기준을 정합니다. 요구 검토는 위험분석에서 도출된 안전 요구, 금지 동작, 안전 상태, 타이밍·오류 대응과 양방향 추적을 확인합니다.
- 설계·코드 검토는 상태전이·제어/데이터 흐름·경계·예외·동시성·초기화·오류전파·방어 동작을 정적 분석과 인스펙션으로 점검합니다. 사용하지 않는 코드·도달 불가 상태·미정의 입력이 안전 동작을 방해하는지 살핍니다.
- 동적 검증은 정상·경계·비정상·고장주입·실제 타이밍을 포함하고 기대 안전반응과 실제 결과를 대조합니다. 결과 분석에서 결함의 위험·원인·수정·재검증과 잔여 위험·미검증 범위를 기록하며 기준선과 진단 버전을 고정합니다.

### 구조·비교·판단

| 구분 | 원리·특징 | 적용·판단 |
| --- | --- | --- |
| 요구/추적 검토 | 무엇이 안전한 동작인가 | 위험→안전요구→시험의 연결 |
| 정적 검토 | 실행 전에 논리·구조 결함 탐지 | 상태·예외·동시성 분석 |
| 동적 검증 | 조건별 실제 반응·시간 확인 | 고장주입·타깃·회귀 시험 |

### 적용 예제

**강사 창작 적용 예시: 과열 방지 제어의 진단**

강사 생성 학습 예제입니다. 공식 기준답안이 아닙니다.

**조건:** 온도 임계 초과 시 히터 차단과 경보를 요구한다고 가정합니다.

1. 요구에서 임계값·허용 지연·센서 단선 시 안전 상태를 확인합니다.
2. 코드의 경계 비교와 경보·차단 경로를 추적합니다.
3. 정상·임계 전후·센서 고착·재시작을 시험하고 결함을 수정·재검증합니다.

**결과·해석:** 안전 요구의 명확성에서 실행 증거까지 연결하는 연습입니다.

**전제·주의:** 이는 강사 창작 일반 예시입니다. 지정 가이드 단계별 절차의 답안 충족 증거로 사용하지 않습니다.

### 답안 골격과 혼동 방지

지정 원문 확보 여부를 먼저 명시 → 일반 안전 기능 진단의 입력·활동·증거 → 미확인 공식 단계명 재대조 과제

- 일반 V&V 순서를 지정 가이드의 공식 단계로 사칭하지 않습니다.
- 미확인 항목을 충족으로 표시하지 않습니다.

### 내용을 가리고 회상

1. 안전 상태를 요구에 명시해야 하는 이유는 무엇입니까?
2. 정적 검토와 고장주입은 어떻게 보완합니까?
3. 이 노트에서 아직 확인하지 못한 원문 범위는 무엇입니까?

### 적용 기준과 근거

지정된 SW 안전진단 가이드(공통분야)의 기능동작 정확성 단계명·순서·주요 활동 원문 미확보. 일반 공학 설명만 부분 제공했습니다.

**내용 검토 상태: 확인 필요**. 출처 확인은 공식 정답이나 학습 성취를 뜻하지 않습니다.

- [NASA-STD-8739.9 Software Formal Inspections Standard](https://standards.nasa.gov/sites/default/files/standards/NASA/Baseline/1/nasa-std-87399_with_change_1.pdf) — NASA; 2013 / Change 1; 확인 2026-11-05. 확인 범위: 공개 PDF의 요구사항 인스펙션 체크리스트와 절차를 열람했습니다. NASA 적용 기준을 국내 사업의 의무로 일반화하지 않습니다.
- [Guide to the SWEBOK v4.0a](https://ieeecs-media.computer.org/media/education/swebok/swebok-v4.pdf) — IEEE Computer Society / Hironori Washizaki 편; 2026-08; 확인 2026-11-05. 확인 범위: 공개 PDF 열람. 요구사항·설계·테스트·유지보수·형상관리·품질 장의 해당 절을 참조. 기출 당시 판본과 현재 v4.0a를 구분합니다.
