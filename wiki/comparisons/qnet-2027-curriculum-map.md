# 2027~2030 출제기준 사진과 학습 과정 대조

## 범위와 판정 방법

[사용자 제공 사진 출처](../sources/qnet-criteria-2027-photos.md)의 뷰어 표시 1~4/8쪽을 대상으로 읽히는 내용을 강사가 간단히 바꿔 적고 기존 위키 노트와 대조한 학습 설계다. 4쪽 일부는 판독 보류하고 5~8쪽은 확인하지 못했다. 공식 안내는 적용기간을 확인했지만 원본 파일 전체는 독립적으로 확인하지 못했으므로 이 대조표는 미검증이다. 공식 기준의 전 범위, 기출 빈도, 향후 출제를 뜻하지 않는다.

- **연결 확인**: 제시한 노트에서 설명란에 적은 특정 요소를 확인했다는 뜻이다. 해당 기준 전체의 완전한 충족이나 노트의 기술적 정확성 보증은 아니다.
- **부분 연결**: 노트가 기준의 일부 또는 관련 관점을 다룬다. 표에 적은 나머지를 수업 시 보완한다.
- **자료 미연결**: 현재 224개 토픽에서 직접 대응하는 전용 기초 자료를 확인하지 못한 상태다. 새 기본 목표에 맞는 근거를 찾을 때 다시 검색한다.
- **판독 미확인**: 사진만으로 정확한 문구를 결정하지 않는다. 문서의 검토 상태와 사용자 학습 상태는 위 연결 판정과 별개다.

노트 아래의 예시 기출은 기존 노트에 연결된 과거 공식 문항이다. 그 문항의 모든 요구가 2027 기준 항목에 일치하거나 기준이 이전과 동일하다는 뜻은 아니다. 문항과 기술 근거·적용 시점은 수업에서 각각 확인한다. 주차와 기본/선택은 강사의 계획이며 [커리큘럼](../../study/curriculum.md)에 있는 단 하나의 토픽·목표 체크만 사용한다.

## 원문 확인 후 해야 할 일

1. 정식 Q-Net 첨부 원문 8쪽 전체와 적용기간을 확보해 사진 판독·누락을 대조한다. 특히 3~4쪽의 이어지는 작은 글씨는 추측해 확정하지 않는다.
2. 수업 주차에 도달하기 전 자료가 부족한 목표의 공식 표준·기관 자료를 확인해 실질적인 설명과 회상 문제를 준비한다. 빈 개념 페이지나 확인하지 않은 기출을 만들지 않는다.
3. 법령·정책은 해당 학습 시점과 응시 시점에 공식 법령과 기관 원문에서 명칭·시행일·적용 대상을 확인한다. 과거 기출의 시점은 별도다.
