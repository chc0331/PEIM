# RAFT: Adapting Language Model to Domain Specific RAG

## 확인 범위와 수집 형태

실제 열람: HTML 3절의 질문·golden/distractor 문서·근거 포함 응답, 일부 학습 표본의 golden 문서 제외, 도메인 RAG 적응. RAFT는 supervised fine-tuning이며 RLHF와 같은 강화학습 정렬 기법이 아닙니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
