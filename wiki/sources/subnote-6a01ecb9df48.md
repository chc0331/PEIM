# Model Context Protocol Architecture

## 확인 범위와 수집 형태

실제 열람: host-client-server, client:server 1:1, JSON-RPC·상태 세션·resources/tools/prompts. 최신 명세임을 주장하지 않고 고정 버전으로 설명합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
