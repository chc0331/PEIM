# Dictionary of Algorithms and Data Structures: binary search tree

## 확인 범위와 수집 형태

실제 열람: 왼쪽·오른쪽 전체 서브트리의 키 순서 조건, AVL 등 하위 구조와 treesort 연결. 비교·삭제 및 계산 예시는 Princeton 본문과 강사 생성 사례로 보완합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
