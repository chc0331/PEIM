# Graphify 공식 프로젝트와 Codex 의미 추출 절차

## 확인한 내용

공식 패키지는 graphifyy이며 CLI 이름은 graphify다. 문서에서 개념과 관계를 의미 추출하고 그래프 JSON, HTML 시각화, 보고서를 생성한다. query, path, explain으로 그래프를 탐색한다. Codex용 스킬은 세션의 추출 에이전트를 활용하는 절차를 제공한다.

## 학습·운영에 적용

이 프로젝트는 0.9.55를 고정하고 추가 API 없이 세션으로 추출한다. 추출·추론 신뢰 태그는 사실 검증이나 정확도 확률과 다르다. 성능 홍보 수치를 우리 자료에 대한 측정값으로 사용하지 않는다.
