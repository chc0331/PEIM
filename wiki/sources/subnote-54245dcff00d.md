# NIST SP800-145: Definition of Cloud Computing

## 확인 범위와 수집 형태

공식 게재 페이지 열람. 5특성·3서비스·4배포 모델을 확인하되 제품별 책임은 계약 확인.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
