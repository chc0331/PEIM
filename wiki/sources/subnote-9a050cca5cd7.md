# Embedded Data in Your MongoDB Schema

## 확인 범위와 수집 형태

실제 열람: 문서·배열·내장, 한 번 조회/단일 문서 원자성, 16 MiB 제한, 내장/참조 선택 조건. NoSQL 전체가 동일한 일관성·트랜잭션 기능을 가진다는 주장은 하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
