# 생체정보 보호 가이드라인(2021.9.)

## 확인 범위와 수집 형태

공식 포털의 PDF 첨부(FileDown.do?atchFileId=FILE_000000000843177&fileSn=1)를 직접 다운로드·텍스트 열람. PDF pp.15~16 대체수단/PbD, pp.19~24 특징정보 별도 동의·위변조 탐지·다중 인증, pp.26~32 목적 제한·암호화·원본 파기 원칙, pp.51~56 FAQ/용어를 확인했습니다. 2021년 판본의 권고·당시 법령 인용이며 2026 현행 조문 전부를 검증한 문서로 취급하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
