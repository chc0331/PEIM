# Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

## 확인 범위와 수집 형태

실제 열람: parametric generator와 nonparametric dense index 결합, sequence/token별 근거 사용. 모든 RAG가 학습 필요 또는 환각을 제거한다는 주장은 하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
