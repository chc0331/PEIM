# Lights-out factory

## 확인 범위와 수집 형태

제공자의 공식 공개 본문에서 자동화 셀·MOM·원격 감독·고정 일정 표준제품의 적합성을 확인했습니다. 검색에서 본문을 읽었으며 직접 open은 타임아웃이었습니다. 특정 공장의 인력·생산량 성과는 사용하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
