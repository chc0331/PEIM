# 토스페이 연동가이드: 페이스페이

## 확인 범위와 수집 형태

실제 열람: 사전 얼굴 등록·유사 얼굴의 추가 인증·라이브니스·암호화 관리·FDS·취소 절차. 운영사 자체 설명이며 모든 공격 방어 또는 독립 성능 검증의 증거로 보지 않습니다. 속도·정확도·이용자·가맹점·보상한도 수치는 사용하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
