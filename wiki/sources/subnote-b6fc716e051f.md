# Auto-configuration

## 확인 범위와 수집 형태

현재 문서 열람. 기출 당시 Spring Boot 세대와 차이가 있으므로 특정 Java 최소버전·패키지명을 일반화하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
