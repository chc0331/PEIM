# Data quality use cases

## 확인 범위와 수집 형태

실제 열람: distribution/freshness/integrity/missingness/schema/uniqueness/volume와 비정형 metadata 검사. 국내 공공 성숙도 모델 등급을 이 문서로 검증하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
