# CFS Scheduler

## 확인 범위와 수집 형태

CFS 가상 실행 시간 원리와 EEVDF로 이행 중임을 알리는 문구 확인. SJF를 Linux 현행 기본 정책이라 주장하지 않음.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
