# NIST SP800-38A: Block Cipher Modes

## 확인 범위와 수집 형태

ECB/CBC/CFB/OFB/CTR 원문과 식 열람. 기밀성 모드이 므로 단독 무결성 보장 없음.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
