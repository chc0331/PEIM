# Data governance with Microsoft Purview

## 확인 범위와 수집 형태

실제 열람: 중앙 data office·domain stewards 연합 운영, catalog/data map·metadata와 원데이터 권한의 차이. 거버넌스의 실무 예이며 법정 표준이라고 표현하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
