# AWS DMS data validation

## 확인 범위와 수집 형태

실제 열람: full-load 후 행 단위 비교, CDC 변경 검증, mismatch 보고와 검증 부하. DB 전환 전체 프로젝트 절차는 이 원리를 바탕으로 한 강사 설계입니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
