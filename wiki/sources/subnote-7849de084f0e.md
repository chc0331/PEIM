# The Istio service mesh

## 확인 범위와 수집 형태

공식 문서에서 서비스 메시 기능과 ambient/sidecar 두 배포 모드 확인. 모든 메시가 sidecar만 사용한다고 설명하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
