# Dictionary of Algorithms and Data Structures: graph

## 확인 범위와 수집 형태

실제 열람: G=(V,E), 방향·무방향·가중 그래프와 인접 리스트/인접 행렬 연결. |V|·|E|는 문자열 그대로 보존하며 메모리 차이는 교과적 계산 예시로 설명합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
