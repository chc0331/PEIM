# PL/SQL Dynamic SQL

## 확인 범위와 수집 형태

실제 열람: 실행 시 SQL 생성, compile 시 텍스트/타입 불명확한 경우, static SQL의 객체 검증과 dependency, EXECUTE IMMEDIATE/DBMS_SQL. 바인드와 식별자 구분은 예제의 핵심입니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
