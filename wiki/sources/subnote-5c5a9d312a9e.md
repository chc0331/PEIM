# NIST/SEMATECH e-Handbook: Check of assumptions

## 확인 범위와 수집 형태

실제 열람: 고전 회귀 잔차 독립성·평균0·등분산·정규성 및 잔차 그림. 정규성은 모든 예측 모델의 필수 조건이라고 일반화하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
