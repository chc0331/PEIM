# 공공기관의 데이터베이스 표준화 지침

## 확인 범위와 수집 형태

실제 열람은 지침명·시행일·개정번호 메타데이터에 한정. 본문/별지는 웹 도구에서 빈 UI여서 현행 의무나 별지 세부 항목의 근거로 사용하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
