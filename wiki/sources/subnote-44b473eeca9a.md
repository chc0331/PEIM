# Technical Debt

## 확인 범위와 수집 형태

최초 open 본문과 기술부채 의미를 확인했습니다. 뒤의 find 재요청은 오류였으므로 사분면 세부는 별도 원문 확인이 필요합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
