# PostgreSQL 18: Using EXPLAIN

## 확인 범위와 수집 형태

실제 열람: plan tree·scan/join/sort 노드·추정 행수/비용, 통계의 표본성, EXPLAIN ANALYZE와 주의점 구성. 예시 비용을 성능 보장 수치로 전용하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
