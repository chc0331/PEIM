# scikit-learn: Metrics and scoring

## 확인 범위와 수집 형태

실제 열람: 분류·회귀 지표 구성, confusion matrix·precision/recall/F1·ROC·PR, MSE. 계산 예제 TP=100/FP=5/FN=7/TN=9는 기출 입력으로 직접 재계산합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
