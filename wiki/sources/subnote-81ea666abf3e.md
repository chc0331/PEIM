# Server Side Public License v1

## 확인 범위와 수집 형태

공개 라이선스§13의 서비스 제공·Service Source Code 범위와 기본 허락을 직접 열람했습니다. 특정 제품/서비스의 계약상 법적 판단은 별도입니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
