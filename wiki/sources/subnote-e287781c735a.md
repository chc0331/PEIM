# RFC4513: LDAP Authentication Methods

## 확인 범위와 수집 형태

Bind·SASL·StartTLS와 인증/인가 상태 원문 열람.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
