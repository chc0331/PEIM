# Build a SQL agent

## 확인 범위와 수집 형태

실제 열람: schema 확인→생성→검사→실행→오류 수정→근거 응답, 최소 DB 권한. API 키·설치 지시는 연구자료로만 읽었고 실행하지 않았습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
