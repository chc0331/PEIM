# 소프트웨어 진흥법 현행 및 예정법령 검색

## 확인 범위와 수집 형태

2026-11-05 현재 검색 화면은 제20476호 현행, 제21865호 2027-02-12 시행 예정법령을 구분해 표시합니다. 현행 전 조문과 2023판의 세부 대조는 추가 확인 필요합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
