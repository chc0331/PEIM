# SDMetrics: Privacy

## 확인 범위와 수집 형태

실제 열람: disclosure protection, real/synthetic 거리 기반 overfitting·random baseline. 통계 프라이버시 지표가 법적 익명성을 자동 보장한다는 주장은 하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
