# How do I use spatial indexes?

## 확인 범위와 수집 형태

실제 열람: geometry의 GiST 기반 R-tree, USING GIST, 공간 인덱스 인식 함수·사전 필터. KD/Quad-tree의 일반 구조까지 이 문서가 모두 검증하는 것은 아닙니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
