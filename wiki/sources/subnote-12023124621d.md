# Business Source License 1.1

## 확인 범위와 수집 형태

사용권·Additional Use Grant·Change Date/Change License·판본별 적용을 실제 열람했습니다. 개별 제품의 추가 사용허락을 일반 BSL의 일률 조건으로 해석하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
