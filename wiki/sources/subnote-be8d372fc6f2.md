# About Snowflake Marketplace

## 확인 범위와 수집 형태

실제 열람: 공급자 listing, 소비자 검색·시험·접근·조합, 유료 listing·복제 없는 live sharing. 모든 거래소가 동일 제공 모델이라는 뜻은 아닙니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
