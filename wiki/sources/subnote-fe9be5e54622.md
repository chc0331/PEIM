# Semi-Supervised Classification with Graph Convolutional Networks

## 확인 범위와 수집 형태

실제 열람: 저자 초록과 HTML 본문의 GCN 국소 연결·노드 속성 표현, 표3의 전파식 D^(-1/2)(A+I)D^(-1/2)HW. VPP 적용은 강사 설계이며 GAT/GraphSAGE 상세 원 연구는 별도 확인 범위입니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
