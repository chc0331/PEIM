# ISO 31000:2018 Risk management — Guidelines

## 확인 범위와 수집 형태

공식 공개 설명과 판본 확인. 인증 요구사항 표준이 아닌 지침입니다. 유료 전체 본문은 미열람입니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
