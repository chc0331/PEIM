# PostgreSQL 18: Constraints

## 확인 범위와 수집 형태

실제 열람: CHECK·NOT NULL·UNIQUE·PRIMARY KEY·FOREIGN KEY 절 목록과 예시. SQL 제약은 DB 내 규칙 강제이며 현실 사실의 진실성까지 자동 검증하지 않습니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
