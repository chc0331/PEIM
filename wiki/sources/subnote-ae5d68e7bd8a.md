# Internet Security Glossary, Version 2

## 확인 범위

독립 검수에서 falsification 항목의 유효 자료 변경·대체와 허위 자료 삽입 구분을 읽었습니다. 용어집이며 별도 의무 표준으로 해석하지 않습니다.

독립 검수의 강사 생성 요약과 URL 참조입니다. 외부 원문 전체 보관은 아닙니다.
