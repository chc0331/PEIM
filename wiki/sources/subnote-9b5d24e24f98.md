# Dictionary of Algorithms and Data Structures: big-O notation

## 확인 범위와 수집 형태

실제 열람: 양의 상수 c,k의 점근 상한 정의, Θ와의 차이·계산모형에 대한 의존·절댓값을 사용하는 대안 표기. 자료의 예제 수치를 복제하지 않고 자체 n=10·20, 1000·2000 계산을 작성합니다.

강사 생성 조사 요약과 URL 참조를 보관했습니다. 외부 원문 전체 보관이 아닙니다. 기술 주장은 연결된 서브노트의 적용 범위·검토 상태를 함께 확인합니다.
