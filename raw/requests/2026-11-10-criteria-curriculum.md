# 사용자 요청 기록: 출제기준 사진을 반영한 과정 보강

- 요청일: 2026-11-10
- 사용자 요청: 2027~2030 세부계획서 사진을 확인하여 기존 학습 계획을 보강·상세화하고, 합의한 계획을 구현한다.
- 사용자 제공물: 8쪽 중 1~4쪽의 화면 사진. [사진 보관과 해시](../sources/2026-11-10-qnet-criteria-2027-photos.md).
- 합의: 기존 10과목·48주·주 15시간과 1일차를 유지한다. 읽히는 범위를 기존 토픽·기출과 대조하고, 기초 공백은 빈 위키 페이지 없이 고유 학습 목표로 등록한다. 항목별 학습 체크는 한 곳에만 두며 자료 연결 상태와 학습 상태를 구분한다. 확인되지 않은 쪽과 작은 글씨는 보류한다.
- 이 문서는 강사 작성 요청 요약이며 실제 학습·회상·답안 수행 기록이 아니다.
