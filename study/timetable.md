# 정보관리기술사 학습 로드맵과 일별 체크리스트

**상태: 계획만 준비됨 · 실제 수업 시작 전.** 1일차는 첫 실제 수업을 시작하는 날입니다. 아직 시작일, 수행 시간, 제출 답안, 회상 결과는 확인되지 않았으며 아래 체크는 모두 미완료입니다.

- 진행: Codex의 설명·힌트·첨삭과 학습자의 직접 회상·답안 작성을 병행합니다. 하루 계획은 실제 학습 3시간이며 중간 휴식은 별도입니다.
- 표기: 1일차부터 **휴식일을 포함한 경과일**입니다. 매주 5일 학습하고 이어서 2일 쉽니다. 실제 시작일은 첫 수업에서 [진도 기록](progress.md)에 남기되 시간표에는 특정 날짜를 미리 넣지 않습니다.
- 근거: [과목별 커리큘럼 요청](../raw/requests/2026-11-10-subject-curriculum.md), [기존 시간표 선택](../raw/requests/2026-11-09-roadmap-timetable.md), [학습 전략](../wiki/comparisons/study-strategy.md), [정규화 파일럿 수업안](lessons/normalization-pilot.md). 순서는 학습 설계이며 출제 빈도 순위가 아닙니다.
- 전체 토픽과 기준 체크: [과목별 학습 커리큘럼](curriculum.md). 일별 활동 체크와 토픽 체크는 각각 수행 근거가 확인될 때 기록합니다.

## 체크하고 다음 활동으로 가는 방법

1. 학습자는 “1일차 시작해줘”라고 말합니다. Codex는 이 문서와 진도 기록을 읽고, 실제 경과일·미완료 활동을 확인한 뒤 현재 활동을 안내합니다. 첫 수업에는 목표 회차·응시자격 확인 여부·주력 분야·경력 연수 등 아직 모르는 사항을 확인하되 답을 수업 시작의 조건으로 삼지 않습니다.
2. 활동을 실제로 마치면 학습자가 대화로 알려 주거나 답안을 제출합니다. Codex는 확인 가능한 제출물 또는 **사용자 수행 보고**를 구분해 해당 `- [ ]`를 `- [x]`로 바꾸고 다음 활동을 안내합니다. 사용자가 실제로 보고하지 않은 시간과 결과는 적지 않습니다.
3. [과목별 커리큘럼](curriculum.md)의 기본 토픽은 개념 학습과 짧은 회상 수행이 모두 확인되면 그 토픽의 기준 체크 한 곳을 기록합니다. 여러 내용을 묶은 토픽은 수행한 기본 범위와 남은 부분도 진도 기록에 남깁니다. 일별 체크는 활동 수행을 나타내며, 토픽의 수행 근거 없이 일별 체크만으로 토픽을 자동 완료하지 않습니다. 심화 토픽은 선택입니다.
4. 체크는 **수행 여부**입니다. 정확성·숙련도·점수와 별개이며, 오답은 첨삭과 복습에 남깁니다. 작성만 보고된 미제출 답안에는 채점하지 않고, 실제 제출과 첨삭이 필요한 항목은 처리될 때까지 미완료로 둡니다. 평가할 문제는 답안 제출 전에 훈련용 기준을 공개합니다: 요구 충족 25점, 기술 정확성 30점, 논리·구조 20점, 적용·판단 15점, 표현·도식 10점. 공식 채점 기준이 아닙니다.
5. 그날 필수 체크를 모두 마치면 해당 계획을 완료로 표시합니다. 막히면 언제든 설명이나 힌트를 요청할 수 있습니다. 사용자가 보류를 원하면 미완료 체크를 유지하고 보류 사유를 남긴 뒤 선택한 다음 활동을 안내합니다. 보류한 날을 모두 완료한 것으로 표시하지 않습니다.
6. 체크만으로 시간이 지난 것으로 처리하지 않습니다. 다음 날 계획은 미리 볼 수 있지만 경과일과 예정된 휴식일은 유지합니다. 못 마친 활동은 다음 학습일에 먼저 이어가고 그날 3시간 안에서 새 진도를 미룹니다. 예를 들어 2일차 과제를 3일차에 마쳤다면 실제 수행은 3일차에 기록합니다. 휴식일 자체에는 필수 체크가 없습니다.
7. 이 문서는 대화에서 확인한 내용을 기록하는 체크리스트입니다. 클릭 감지·자동 타이머·앱 종료 후 알림은 실행되지 않습니다. 완료를 알려 주시면 Codex가 기록합니다.

### 복습과 주간 점검

- 각 수업을 **실제로 마친 날**부터 1·3·7·14일 뒤를 초기 복습 목표로 잡고 수행 결과에 따라 조정합니다. 휴식일에 걸린 복습은 다음 학습일로 옮깁니다. 여러 복습이 같은 날로 이동하면 하나의 실제 회상으로 기록하고 두 번 수행한 것처럼 세지 않습니다.
- 회상 시간에는 그날 예정된 복습과 해당 주의 실제 학습 주제를 우선합니다. 3시간을 넘겨 밀어 넣지 않고, 필요한 경우 신규량을 줄이거나 다음 학습일로 이월합니다. 예정된 복습의 실제 수행 여부는 별도로 기록합니다.
- 주 1회 해당 주에 학습한 주제 10개를 자료 없이 점검하고, 10개 미만이면 전부 점검합니다. 주제마다 핵심 질문과 통과 기준을 미리 밝히며, 요구한 핵심을 충족하고 중대한 개념 오류가 없으면 통과로 봅니다. 정해진 대상의 확인이 끝나기 전에는 주간 비율을 만들지 않습니다. 80% 미달이면 신규량을 줄이고 취약점을 복습합니다.
- 주 1회 본인이 이해한 내용을 구술로 설명합니다. 구술 결과를 실제 확인할 수 없다면 사용자 수행 보고로만 남깁니다. 확인된 실무 사례가 있다면 출처를 구분해 축적합니다. 필기 합격을 확인한 뒤에는 경력 기반 꼬리질문·기술 판단·모의면접 중심으로 전환합니다.

## 48주 과목별 로드맵

아래 과목은 학습용 분류입니다. 224개 기존 토픽과 출제기준 사진 대조 후 추가한 11개 기초 목표의 단원·주차·검토 상태와 유일한 수행 체크는 [과목별 커리큘럼](curriculum.md)에 있습니다. 각 주차는 최초 배정 또는 재방문 계획이며 실제 수행 결과와 취약점에 따라 조정합니다. 주차와 일차는 휴식일을 포함한 계획 범위입니다.

- 1~2주 진단과 DB 기초, 3~12주 나머지 과목의 기본기와 주당 단답 4·논술 1부터 시작합니다. 13~24주는 과목별 적용과 주 1회 100분 훈련입니다.
- 25~44주는 10과목을 두 차례 순환하고, 45~48주는 여러 과목을 결합합니다. 4주마다 처음 보는 변형 문제로 점검하며, 25주부터 4주마다 전 교시 훈련을 합니다.
- 전 교시 400분 훈련이 있는 주에는 답안 4시간에 개념·기출 등 기존 활동에서 2시간 40분을 재배정해 **총 15시간 안에서** 진행합니다. 기존 과제를 대체하며 실전 이후 첨삭·회상도 남깁니다.
- 24주부터 최근 3회의 시간제한 평가가 각각 훈련용 70점 이상이고 요구한 답안을 완성했으며 중대한 개념 오류가 없는 상태가 유지되면 응시 가능한 가까운 회차를 집중 목표로 검토합니다. 공식 합격권 판정이 아닙니다.
- 48주는 초기 학습 예산이지 합격기간 예측이 아닙니다. 실제 회차의 출제기준 원문과 공고는 별도로 확인합니다.
- [출제기준 사진 대조표](../wiki/comparisons/qnet-2027-curriculum-map.md)는 제공된 사진 1~4쪽 중 판독 가능한 범위에 한정합니다. 새 기초 목표는 공식 자료와 설명을 수업 전에 준비합니다. 26·30·31주의 신규 기본 학습은 그 주의 기존 개념·기출 시간에 넣고 복습량을 조정합니다. 처리하지 못한 항목은 다음 해당 과목 주로 이월합니다.

### 주간 시간 배분

기본 주간의 실제 학습 15시간은 개념·기출 5시간, 회상 3시간, 답안 4시간, 첨삭 반영 2시간, 동향·점검 1시간입니다. 전 교시 훈련 주에는 위 로드맵에 적은 재배정을 적용해 총 15시간을 유지합니다. 추가 가용 시간이 있으면 최대 5시간은 취약점 보완에 쓰고, 모의시험은 기존 과제를 대체합니다. 매일 항목을 위에서부터 진행하되 1일차 파일럿처럼 항목을 나누어야 할 때는 기재된 순서를 따릅니다.

| 학습일 | 개념·기출 | 회상 | 답안 | 첨삭 | 동향·점검 | 합계 |
|---|---:|---:|---:|---:|---:|---:|
| 1·8일차 | 60분 | 30분 | 45분 | 30분 | 15분 | 180분 |
| 2·9일차 | 60분 | 45분 | 45분 | 15분 | 15분 | 180분 |

15일차 이후에는 사용자가 다음 수업을 요청할 때 해당 주차의 기본 토픽·밀린 활동·실제 복습을 확인해 다음 학습일의 체크리스트를 이 문서에 이어 붙입니다. 활동별 시간을 합쳐 180분으로 계획하고 수행 확인 전에는 체크하지 않습니다. 이미 작성한 체크와 실제 기록은 보존합니다.

13~24주의 100분 훈련은 하루에 연속 배치하고 다른 날에서 답안 시간을 조정합니다. 다음은 학습일 기준 예시이며, 합계는 기본 주간의 활동별 5·3·4·2·1시간과 같습니다.

## 첫째 주

### 1일차 — 정규화 파일럿 시작

**목표:** 별도 예제로 중복·이상현상을 이해하고 정규화 기출에 처음 답합니다. [129회 4교시 2번](../wiki/questions/qnet-129-p4.md#q2)을 이미 보거나 풀이를 본 적이 있다면 알리고, [파일럿 수업안](lessons/normalization-pilot.md)의 강사 생성 변형으로 별도 확인합니다. 두 문제를 모두 보았다면 새 변형을 요청합니다.

- [ ] 개념·기출 45분: 첫 진단에서 아직 확인되지 않은 목표·경력·응시자격을 확인하고, 릴레이션·속성·기본키·복합키의 기초 설명을 듣습니다. 미답변 정보가 있어도 수업을 진행합니다.
- [ ] 개념·기출 15분: 기출과 다른 주문 예제로 함수종속·중복·이상현상 설명을 듣고, 답안 작성 전에 위 훈련용 첨삭 기준을 확인합니다.
- [ ] 답안 25분: 위 기출 또는 대체 훈련 문제의 요구를 나누어 타이핑하고 제출합니다. 시간은 참고값이며 막히면 한 단계씩 힌트를 요청합니다.
- [ ] 첨삭 15분: 제출한 답안에 대한 훈련용 기준과 감점 근거·우선 수정점을 확인합니다. 기출 답안 제출 뒤 [정규화 인쇄 노트](../output/pdf/subnotes/topics/relational-normalization.pdf)를 열 수 있습니다.
- [ ] 회상 30분: 자료를 가리고 이상현상 세 가지와 중복이 생긴 이유를 자기 말로 설명합니다. 막힌 부분을 적습니다.
- [ ] 답안 20분: 기출과 다른 설명 예제를 사용해 이상현상 한 가지와 이유를 손글씨로 씁니다. 사진을 제출하면 판독 가능한 부분을 확인받을 수 있습니다.
- [ ] 첨삭 15분: 실제로 확인받은 교정 내용 중 우선할 것을 정리합니다. 손글씨를 제출하지 않았다면 자체 점검으로 표시합니다.
- [ ] 동향·점검 15분: 실제 수행과 남은 질문을 확인하고, 목표 회차의 응시자격·출제기준 확인이 필요한 항목을 기록합니다.

주문 예제 설명 15분 → 타이핑 답안 25분 → 첨삭 15분이 연속된 **55분 파일럿**입니다. 실제 시간이 보고되지 않았다면 위 참고 시간을 수행 시간으로 기록하지 않습니다.

### 2일차 — 정규화 복습과 적용

**토픽:** [정규화와 이상현상](curriculum.md#course-db). 관련 [129회 4교시 2번](../wiki/questions/qnet-129-p4.md#q2)은 1일차에 다뤘다면 복습이며 처음 보는 독립 평가가 아닙니다.

- [ ] 개념·기출 60분: 함수종속·키·이상현상과 분해의 이유를 설명받고 1일차에서 부족했던 전제를 확인합니다. 정규화 노트는 첫 기출 답안 제출 또는 풀이 공개 요청 뒤에 확인합니다.
- [ ] 회상 45분: 예정된 1일차 복습으로 자료 없이 이상현상과 분해 목적을 설명합니다. 확인된 수행을 [토픽 체크](curriculum.md#course-db)에 연결합니다.
- [ ] 답안 45분: 다음 **강사 생성 훈련 문제**의 이상현상, 분해 관계의 키·연결 방법과 원래 행의 복원 가능성을 설명합니다.

  사원역할(사번, 사원명, 역할코드, 역할명)의 기본키는 (사번, 역할코드)입니다. 사번 하나에 사원명 하나, 역할코드 하나에 역할명 하나가 대응합니다. 이름과 역할명은 각각 반복될 수 있고 값은 원자값입니다. 예시 행은 (E01, 이도, R1, 운영), (E01, 이도, R2, 분석), (E02, 민지, R1, 운영)입니다. 삽입·갱신·삭제 이상과 이를 줄일 분해를 제시하세요.

- [ ] 첨삭 15분: 제출한 답안의 가정과 분해 근거를 검토하고 우선 교정점을 반영합니다.
- [ ] 동향·점검 15분: 실제 복습과 미완료 사항을 기록하고 다음 자료 확인 항목을 정합니다.

### 3일차 — 관계형 데이터 모델링

**토픽:** [관계형 모델링](curriculum.md#course-db). [133회 4교시 4번](../wiki/questions/qnet-133-p4.md#q4)은 모델링 단계·식별/비식별 관계·고려사항을 묻습니다.

- [ ] 개념·기출 60분: 강사가 기출과 다른 주문·상품 예제로 모델링 단계, 엔터티·관계와 키를 설명합니다.
- [ ] 회상 30분: 예정된 정규화 복습을 하고 모델링에서 무엇을 구분하는지 자기 말로 설명합니다.
- [ ] 답안 60분: 133회 문제의 가·나·다 요구를 나누어 작성하고 제출합니다. 이미 풀이를 본 적이 있으면 별도 훈련 문제를 요청합니다.
- [ ] 첨삭 15분: 제출한 답안의 누락과 가정을 검토합니다. 제출 후 [모델링 인쇄 노트](../output/pdf/subnotes/topics/relational-data-modeling.pdf)를 참고합니다.
- [ ] 동향·점검 15분: 이해가 불확실한 관계와 다음 복습 항목을 기록합니다.

### 4일차 — 모델링 검증과 CRUD

**토픽:** [관계형 모델링](curriculum.md#course-db). 관련 기출은 [133회 1교시 7번](../wiki/questions/qnet-133-p1.md#q7)입니다.

- [ ] 개념·기출 60분: 모델링 단계, 키·무결성·CRUD 매트릭스의 목적을 사례로 복습합니다. 필요한 부분은 [모델링 노트](../wiki/concepts/relational-data-modeling.md)를 참고합니다.
- [ ] 회상 30분: 예정된 복습을 수행하고 식별·비식별 관계를 도식 또는 말로 구분합니다.
- [ ] 답안 45분: 133회 CRUD 매트릭스 문제를 풀고, 간단한 주문 업무에서 업무와 데이터의 연결 예를 작성해 제출합니다.
- [ ] 첨삭 30분: 제출한 비교와 예시를 점검해 누락된 업무·데이터 또는 이유를 보완합니다.
- [ ] 동향·점검 15분: 토픽 학습·회상의 실제 수행과 다음 복습을 기록합니다.

### 5일차 — 트랜잭션의 특징

**토픽:** [트랜잭션과 병행제어](curriculum.md#course-db). 관련 기출은 [129회 1교시 6번](../wiki/questions/qnet-129-p1.md#q6)입니다.

- [ ] 개념·기출 60분: 강사가 별도 이체 사례로 트랜잭션의 특징과 오류 상황을 설명합니다. 자료의 검토 상태가 부분 확인인 항목은 공식 원문에서 해당 사실을 확인합니다.
- [ ] 회상 45분: 예정된 복습과 첫 주에 실제 학습한 토픽 전부를 자료 없이 점검합니다. 구술 설명 한 번을 포함합니다.
- [ ] 답안 45분: 129회 문제에 트랜잭션 특징과 사례를 작성해 제출합니다. 풀이를 이미 보았다면 별도 훈련 문제를 요청합니다.
- [ ] 첨삭 30분: 제출한 답안의 정확성과 사례를 교정합니다. 제출 뒤 [트랜잭션 인쇄 노트](../output/pdf/subnotes/topics/transaction-concurrency-control.pdf)를 참고합니다.

## 둘째 주

### 8일차 — 트랜잭션과 병행제어

**토픽:** [트랜잭션과 병행제어](curriculum.md#course-db). 관련 기출은 [130회 1교시 2번](../wiki/questions/qnet-130-p1.md#q2)입니다.

- [ ] 개념·기출 60분: 별도 예제로 병행 수행의 문제와 제어 필요성을 설명받습니다. 미완료 활동이 있으면 먼저 이어가고 새 진도를 조정합니다.
- [ ] 회상 30분: 휴식일에서 이동한 복습과 예정된 복습을 점검합니다. 겹친 회상은 실제 수행 한 번으로 기록합니다.
- [ ] 답안 45분: 130회 문제의 필요성과 제어 기법을 작성해 제출합니다. 실제 업무 규칙과 추가 가정은 구분합니다.
- [ ] 첨삭 30분: 제출한 답안에서 문제 상황과 제어 방식의 연결을 교정합니다. 검토가 부족한 기술 사실은 공식 원문에서 확인합니다.
- [ ] 동향·점검 15분: 수행·미수행과 첫 주 점검 결과를 확인합니다. 80% 미달이면 신규량을 줄여 복습합니다.

### 9일차 — 정적 SQL과 동적 SQL

**토픽:** [정적 SQL과 동적 SQL](curriculum.md#course-db). 관련 기출은 [134회 1교시 7번](../wiki/questions/qnet-134-p1.md#q7)입니다.

- [ ] 개념·기출 60분: 강사가 별도 조회 사례로 SQL 실행 방식과 비교 관점을 설명합니다. 구체 제품의 구현 차이는 가정과 함께 구분합니다.
- [ ] 회상 45분: 예정된 정규화·모델링·트랜잭션 복습을 확인하고 오늘 배운 비교 관점을 자료 없이 설명합니다.
- [ ] 답안 45분: 134회 문제의 비교 기준과 적용 시 고려점을 작성해 제출합니다. 이미 풀이를 본 경우 알려 주고 별도 훈련 문제를 요청합니다.
- [ ] 첨삭 15분: 제출한 비교를 검토하고, 제출 뒤 [SQL 인쇄 노트](../output/pdf/subnotes/topics/static-dynamic-sql.pdf)와 대조합니다.
- [ ] 동향·점검 15분: 실제 수행과 모호했던 용어를 기록합니다.

### 10일차 — SQL 적용 판단

**토픽:** [정적 SQL과 동적 SQL](curriculum.md#course-db). 관련 기출은 [134회 1교시 7번](../wiki/questions/qnet-134-p1.md#q7)입니다.

- [ ] 개념·기출 60분: [SQL 노트](../wiki/concepts/static-dynamic-sql.md)를 사용해 쿼리 형태가 고정된 경우와 실행 조건에 따라 달라지는 경우를 비교합니다.
- [ ] 회상 30분: 예정된 복습을 하고 두 방식의 비교 기준과 적용상 제약을 자료 없이 설명합니다.
- [ ] 답안 60분: **강사 생성 훈련 문제** — A 업무는 미리 정한 조회 형식을 반복하고, B 업무는 사용자가 고른 검색 조건에 따라 조회 구조가 달라집니다. 각각 검토할 SQL 방식과 선택 이유·보안·성능 확인 사항을 제시하고, 제품별로 달라지는 조건을 가정으로 밝히세요.
- [ ] 첨삭 15분: 제출한 답안의 선택 근거와 보안·성능 판단을 검토합니다.
- [ ] 동향·점검 15분: 제품별 동작처럼 추가 원문 확인이 필요한 부분을 기록합니다.

**토픽:** [데이터베이스 인덱스](curriculum.md#course-db). 관련 기출은 [136회 2교시 5번](../wiki/questions/qnet-136-p2.md#q5)입니다.

- [ ] 개념·기출 60분: 강사가 별도 검색 사례로 인덱스의 목적과 비교 관점을 설명합니다. 특정 DBMS의 저장 방식을 모든 제품에 일반화하지 않습니다.
- [ ] 회상 30분: 예정된 복습을 수행하고 데이터 검색에서 인덱스를 검토하는 이유를 말합니다.
- [ ] 답안 45분: 136회 문제의 인덱스 설명과 두 방식의 비교를 작성해 제출합니다.
- [ ] 첨삭 30분: 제출한 답안의 비교 기준과 적용 가정을 검토합니다. 제출 뒤 [인덱스 인쇄 노트](../output/pdf/subnotes/topics/database-index-structures.pdf)를 참고합니다. 이 노트는 부분 확인이므로 필요한 원문·제품 판본을 추가 확인합니다.
- [ ] 동향·점검 15분: 검증이 필요한 제품별 동작과 다음 복습을 기록합니다.

### 12일차 — 인덱스 적용과 2주 점검

**토픽:** [데이터베이스 인덱스](curriculum.md#course-db). 관련 기출은 [136회 2교시 5번](../wiki/questions/qnet-136-p2.md#q5)입니다.

- [ ] 개념·기출 60분: [인덱스 노트](../wiki/concepts/database-index-structures.md)의 확인 범위를 살피고, 검색과 변경 비용을 함께 판단하는 예제를 검토합니다.
- [ ] 회상 45분: 둘째 주에 실제 학습한 토픽을 자료 없이 점검하고 구술 설명 한 번을 포함합니다. 수행하지 않은 항목은 미확인으로 둡니다.
- [ ] 답안 45분: **강사 생성 훈련 문제** — 주문 테이블은 날짜 범위 조회가 잦고 신규 주문도 계속 들어옵니다. 사용할 인덱스를 검토할 때 필요한 정보, 예상 이점과 변경 비용, 실제 검증 방법을 설명하고 DBMS·데이터 분포에 관한 가정을 밝히세요.
- [ ] 첨삭 30분: 제출한 답안과 2주간 실제 수행 근거를 검토합니다. 지식·회상·질문 오독·구조·시간 중 확인된 취약점을 바탕으로 3주차 이후 계획을 조정합니다.
