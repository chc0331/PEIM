# 진도와 복습

실제 수업은 아직 시작하지 않았다. 자료 등록과 그래프 구축은 학습 성취가 아니다.

| 대상 | 상태 | 수행 근거 | 마지막 확인 | 다음 복습 |
|---|---|---|---|---|
| 초기 출처 및 학습 전략 | 미학습 | 제출 답안·회상 평가 없음 | — | 첫 진단 후 설정 |

## 이번 주

- 시작 주차: 미정
- 완료 시간: 미기록 (0시간으로 추정하지 않음)
- 첫 과제: 진단 수업에서 확정
- 미완료 과제: 아직 배정하지 않음
- 다음 단계: 목표/경력 확인 → 기초·답안 진단 → 개인별 첫 주 계획

상태는 미학습 → 학습 중 → 회상 확인 → 시간제한 답안 확인으로 구분한다. 각 승급에는 제출물 또는 실제 회상 결과와 확인일이 필요하다.

## 자료 준비 기록

- 2026-11-01: Q-Net 제126~140회 공식 PDF 15개·465문항을 수집하고 [기출·개념 탐색 지도](../wiki/comparisons/qnet-exam-map.md)를 작성했다.
- 2026-11-05: 465문항에 연결한 [인쇄 서브노트 224개](../docs/subnotes/topics.md)·[통합 PDF 472쪽](../output/pdf/subnotes/정보관리기술사_기출서브노트_통합.pdf)·개별 PDF 모음과 요구사항 대응표를 준비했다. 문서 검토 상태와 실제 학습 상태는 별개다.
- 이 기록은 자료 준비다. 회상·답안 제출·학습시간의 증거가 없으므로 학습 상태와 실제 시작일을 변경하지 않는다.
- 다음 사용 단계: 선택한 토픽의 설명·예제를 확인하고 회상 질문과 관련 기출의 손글씨 답안을 제출한다. 확인이 필요한 판본·범위는 해당 노트에서 확인한다. 훈련 과제는 실제 수업에서 정한다.
