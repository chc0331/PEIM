# 회차·종목·교시 공식 기출

원문 문구를 보존하고 기계 추출의 표·그림·기호는 PDF와 대조한다. 기출과 강사 생성 해설을 구분한다.

<a id="q1"></a>

## 1번

원문과 원본 PDF 페이지 링크를 기록한다. 추가 문항은 questions 메타데이터와 본문 앵커를 함께 추가한다.

## 관련 개념과 탐색 질문

정의·정답을 문제지에서 검증했다고 표시하지 않는다. 관련 개념과 연결한 이유는 원문 근거 또는 강사의 추론으로 구분한다.
