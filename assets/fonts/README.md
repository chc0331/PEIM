# 인쇄 글꼴

프로젝트의 PDF가 시스템 글꼴 설치 없이 한글·수식·외국어 출처명을 표시하도록 원본 TTF를 보관합니다. PDF에는 사용한 글리프를 포함합니다. 배포 원문 확인일은 2026-11-05이며 라이선스 원문은 각 폴더에 있습니다.

| 글꼴 | 공식 배포 위치 | 라이선스 |
| --- | --- | --- |
| Nanum Gothic Regular·Bold | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanumgothic) | `nanum-gothic/OFL.txt` |
| Noto Sans Math Regular | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansmath) | `noto-sans-math/OFL.txt` |
| Noto Sans Regular | [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans) | `noto-sans/LICENSE` |

원본의 출처명·저작권·SIL Open Font License를 유지합니다. 글꼴 자체를 수정하거나 다른 이름으로 재배포하지 않았습니다.
